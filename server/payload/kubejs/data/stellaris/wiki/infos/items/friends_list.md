Список друзей отслеживает игроков, которым вы доверяете.

[item=stellaris:friends_list]

Щелкните правой кнопкой мыши по игроку, чтобы добавить его в список друзей. 
Если вы уже дружите с этим игроком, повторный щелчок правой кнопкой мыши удалит его из списка. 

Список делает частную [ref=stellaris:machines/antenna]Антенну[ref] доступной для общего доступа: щелкните правой кнопкой мыши антенну со списком друзей в руке, и всем, кто в ней находится, будет разрешено приземлиться там.
