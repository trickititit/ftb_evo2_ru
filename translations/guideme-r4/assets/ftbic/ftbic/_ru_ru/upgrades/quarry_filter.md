# <Color id="gold">Обновление Карьерного Фильтра</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="quarry_filter_upgrade" scale="2" />

  Заставляет <ItemLink id="quarry" /> добывать выбранные блоки, оставляя ненужные блоки в мире.
</Column>

<RecipeFor id="quarry_filter_upgrade" />

Установите **один** в слот улучшения Карьера. Откройте кнопку **F** рядом с экраном «Карьер», чтобы выбрать образцы блоков или теги блоков, выбрать белый или черный список и при необходимости включить режим только руды. Перетащите элементы блока из JEI в слоты для образцов или щелкните элемент блока на курсоре. Нажмите Enter после ввода тега блока.

В режиме «Только руда» используется `#c:ores`. Пропущенные блоки не используют энергию майнинга. Карта конфигурации может скопировать настройки фильтра в другой карьер. Подробности смотрите на странице <ItemLink id="quarry" />.
