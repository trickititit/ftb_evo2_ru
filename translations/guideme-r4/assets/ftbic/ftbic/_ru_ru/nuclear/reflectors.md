# <Color id="gold">Отражатели нейтронов</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="iridium_neutron_reflector" scale="2" />

  Отражатели считаются **действительным соседом стержня** для выходных расчетов: стержень, находящийся рядом с отражателем, ведет себя так, как если бы там находился другой стержень. Каждый отражатель имеет ограниченный срок службы, за исключением иридиевого.
</Column>
