# <a name="recursive-ae2-pattern-provider" />Рекурсивный поставщик шаблонов AE2

## <a name="🎮-how-to-use" />🎮 Как использовать

### <a name="step-1:-encode-a-recursive-pattern" />Шаг 1. Закодируйте рекурсивный шаблон

Есть **два способа** создать рекурсивный шаблон:

#### <a name="method-a:-direct-pattern-encoding-terminal-toggle-(recommended)" />Метод A: переключение терминала кодирования прямого шаблона (рекомендуется)
1. Откройте **Терминал кодирования шаблонов**.
2. Выберите вкладку **Выкройка**.
3. Рядом с кнопками замены переключите кнопку **Рекурсивный шаблон** в положение **ВКЛ** (зеленая галочка).
4. Вставьте свой рецепт в сетку крафта и нажмите **Закодировать шаблон**.
5. Закодированный шаблон автоматически получит флаг рекурсивности!

> 💡 **Примечание**. Кнопку переключения графического пользовательского интерфейса в терминале кодирования шаблонов можно включить или отключить в файле конфигурации с помощью `enableEncodingGuiToggle` (по умолчанию: `true`).

#### <a name="method-b:-crafting-table-recipe" />Метод Б: Рецепт верстака
1. Поместите стандартный, уже закодированный шаблон AE2 в верстак.
2. Добавьте настроенный элемент рецепта (по умолчанию: **Железный слиток**).
3. Создайте рекурсивную версию (`[AE2 Pattern] + [Recipe Item] → [Recursive Pattern]`).

*(Чтобы удалить рекурсию с помощью верстак, создайте только рекурсивный шаблон: `[Recursive Pattern] → [Normal Pattern]`)*.

### <a name="step-2:-install-in-pattern-provider" />Шаг 2. Установите в поставщике шаблонов
Поместите рекурсивный шаблон в любой **Поставщик шаблонов**, подключенный к молекулярному ассемблеру.

### <a name="step-3:-automatic-magic!-✨" />Шаг 3: Автоматическое волшебство! ✨
Мод автоматически генерирует шаблоны зависимостей для отсутствующих промежуточных компонентов в режиме реального времени:
- **Палки** (если они нужны железной кирке)
- **Деревянные доски** (при изготовлении палок из цельных бревен)
- **Любые недостающие зависимости крафта в цепочке!**

## <a name="🔄-pattern-re-encoding-&amp;-persistence" />🔄 Перекодирование и сохранение шаблонов

Когда вы помещаете существующий рекурсивный шаблон обратно в терминал кодирования шаблонов для редактирования его рецепта или настроек:
- **Рекурсивный тег сохраняется автоматически** при перекодировании.
- Вам не нужно заново создавать шаблон или вручную переключать флаг, если вы не хотите его отключить.
