# <a name="terminal-interactions" />Терминальные взаимодействия

Терминалы будут отображать накопленную энергию в виде *зеленой жидкости*.

![FE_GUI](../pic/fe_terminal.png)

Это не настоящая жидкость, и вы не можете использовать ведра, чтобы наполнить ее.

Вы можете использовать энергетический контейнер, например батарейки, электроинструменты, для наполнения/отвода энергии в него или из него.

![FE_GUI2](../pic/fe_terminal2.png)
