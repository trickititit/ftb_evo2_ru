# <a name="wireless-universal-terminal" />Беспроводной универсальный терминал

<ItemImage id="ae2wtlib:wireless_universal_terminal" scale="3" />

<ItemLink id="ae2wtlib:wireless_universal_terminal" /> — это комбинация нескольких [Беспроводные терминалы](wireless_terminals.md) в один элемент.

Все [Беспроводные терминалы AE2WTLib](wireless_terminals.md) можно объединить в один терминал.

<ItemLink id="ae2:wireless_terminal" /> из AE2 ***НЕ*** может быть объединено в <ItemLink id="ae2wtlib:wireless_universal_terminal" />.


## <a name="the-ui" />Пользовательский интерфейс

<ItemLink id="ae2wtlib:wireless_universal_terminal" /> добавляет кнопку в пользовательский интерфейс терминала, которую можно щелкнуть левой кнопкой мыши (и щелкнуть правой кнопкой мыши), чтобы перейти к следующему (или последнему) [Беспроводной терминал](wireless_terminals.md).


## <a name="upgrades" />Обновления

<ItemLink id="ae2wtlib:wireless_universal_terminal" /> поддерживает те же обновления, что и установленный [Беспроводные терминалы](wireless_terminals.md). Каждый установленный терминал добавляет 2 слота обновления.

## <a name="energy-storage" />Хранение энергии

Добавление терминалов объединяет их запасы энергии, поэтому <ItemLink id="ae2wtlib:wireless_universal_terminal" /> с двумя терминалами имеет вдвое больший запас энергии, чем [Беспроводной терминал](wireless_terminals.md).
