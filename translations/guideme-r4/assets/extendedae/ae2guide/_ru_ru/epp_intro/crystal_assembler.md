# <a name="crystal-assembler" />Кристальный Ассемблер

<Row>
<BlockImage id="extendedae:crystal_assembler" scale="8"></BlockImage>
</Row>

Большинство устройств ExtendedAE слишком сложны для их изготовления на верстаке, поэтому для их изготовления вам понадобится Crystal Assembler.

**Примечание: экран не может подключиться к сети.**

Он также может выполнять определенные рецепты трансформации в мире, такие как трансформация Fluix.
