# <a name="quartz-blend" />Кварцевая смесь

<Row>
<ItemImage id="extendedae:quartz_blend" scale="4"></ItemImage>
</Row>

Смесь кварца, угля и песка. При его плавке получается больше <ItemLink id="ae2:silicon" />, чем при прямой плавке пыли цертусового кварца.
