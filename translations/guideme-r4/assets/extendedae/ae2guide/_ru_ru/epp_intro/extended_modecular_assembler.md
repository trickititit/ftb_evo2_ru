# <a name="extended-molecular-assembler" />Расширенный молекулярный ассемблер

<Row gap="20">
<BlockImage id="extendedae:ex_molecular_assembler" scale="8"></BlockImage>
</Row>

Расширенный молекулярный ассемблер — это усовершенствованная версия <ItemLink id="ae2:molecular_assembler" />.

Он может одновременно выполнять восемь крафтовых задач (при условии, что ваша сеть ME содержит <ItemLink id="ae2:crafting_accelerator" />) и работает в два раза быстрее, чем стандартный молекулярный ассемблер.

Однако он поддерживает только задания по созданию из <ItemLink id="ae2:pattern_provider" />, поэтому вы не можете вставить узор напрямую.
