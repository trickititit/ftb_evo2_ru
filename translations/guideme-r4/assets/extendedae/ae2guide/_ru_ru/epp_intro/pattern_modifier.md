# <a name="pattern-modifier" />Модификатор узора

Модификатор шаблона — это инструмент для массового изменения шаблонов.

<ItemImage id="extendedae:pattern_modifier" scale="4"></ItemImage>

Щелкните его правой кнопкой мыши, чтобы открыть графический интерфейс.

## <a name="multiply-mode" />Режим умножения

Вы можете умножить или разделить входные и выходные количества шаблонов обработки на x, нажав соответствующую кнопку.

![ПМ](../pic/pm.png)

Оригинальный узор:

![ПМ1](../pic/pm1.png)

После х10:

![ПМ2](../pic/pm2.png)

Вы также можете очистить содержимое всех шаблонов и превратить их в пустые шаблоны, нажав кнопку «Очистить».

### <a name="notes" />Примечания

- Кнопка деления работает только тогда, когда сумма делится без остатка. Например, кнопка ÷2 не работает, если для шаблона требуется 3
булыжник в качестве входных данных, потому что 3÷2 равно 1,5.

- Кнопка умножения имеет ограничение на 999999. Она не может увеличить количество одного ингредиента сверх этого числа.

## <a name="replace-mode" />Режим замены

Замените конкретный входной или выходной ингредиент в шаблонах другим элементом.

![ПМ3](../pic/pm4.png)

В слоте A находится заменяемый ингредиент, а в слоте B — его замена.

Например, в следующей настройке доска заменяется углем.

![ПМ4](../pic/pm6.png)

![ПМ5](../pic/pm5.png)

Нажмите кнопку «Заменить», чтобы выполнить замену.

![ПМ6](../pic/pm7.png)

## <a name="property-mode" />Режим свойств

Измените настройки «Замены» и «Замены жидкости» в выкройках крафта.

![ПМ8](../pic/pm8.png)

## <a name="clone-mode" />Режим клонирования

В этом режиме вы можете скопировать любой шаблон.

![ПМ7](../pic/pm3.png)
