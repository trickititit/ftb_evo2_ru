# <a name="network-tool" />Сетевой инструмент

<ItemImage id="network_tool" scale="4" />

Network Tool — это модифицированный [гаечный ключ](wrench.md), который также отображает диагностическую информацию сети и может хранить [карты обновления](upgrade_cards.md). Хотя он сохраняет способность гаечного ключа быстро разбирать предметы и снимать [подразделы](../ae2-mechanics/cable-subparts.md) с троса, он не может вращать предметы.

У него есть 9 слотов для хранения [карты обновления](upgrade_cards.md), и они будут доступны в любом пользовательском интерфейсе устройства AE2, если инструмент находится где-нибудь в вашем инвентаре.

Если щелкнуть правой кнопкой мыши любую часть сети, откроется окно диагностической информации, аналогично щелчку правой кнопкой мыши по <ItemLink id="controller" />. В этом окне показано:

*   Количество каналов, используемых в сети.
*   Переключатель глобальных настроек для просмотра энергии в AE или E/FE.
*   Количество [энергия](../ae2-mechanics/energy.md), хранящихся в сети, и максимальная энергетическая емкость сети.
*   Количество энергии, поступающей и используемой сетью
*   Список всех [устройства](../ae2-mechanics/devices.md) и компонентов в сети.

Это окно также полезно для выяснения того, являются ли два разных кабеля или устройства частью одной сети, когда вы возитесь с [Подсети](../ae2-mechanics/subnetworks.md).

## <a name="hiding-facades" />Скрытие фасадов

<ItemLink id="facade" />s будут скрыты, если держать сетевой инструмент в любой руке.

Вы можете взаимодействовать с блоками за скрытыми фасадами, не снимая их предварительно.
