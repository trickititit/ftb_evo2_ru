# <a name="matter-balls" />Материальные шары

<ItemImage id="matter_ball" scale="4" />

Шар из обычной материи, полезный в качестве боеприпасов для <ItemLink id="matter_cannon" /> или для производства [пейнтболы](paintballs.md).

Состоит из 256 предметов или ведер в режиме <ItemLink id="condenser" /> в режиме шара материи.
