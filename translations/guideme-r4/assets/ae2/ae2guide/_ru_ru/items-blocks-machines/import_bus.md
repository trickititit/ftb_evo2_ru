# <a name="the-import-bus" />Импортный автобус

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/import_bus.snbt" />
</GameScene>

Шина импорта извлекает предметы и жидкости (и все остальное, учитывая аддоны) из инвентаря, к которому он прикасается, и помещает их в [сетевое хранилище](../ae2-mechanics/import-export-storage.md).

В целях сокращения задержки, если шина импорта в последнее время что-то не импортировала, она переходит в своего рода «спящий режим», в котором она работает медленно, и просыпается и разгоняется до полной скорости (4 операции в секунду), когда она успешно импортирует что-то.

Они [части кабеля](../ae2-mechanics/cable-subparts.md).

## <a name="filtering" />Фильтрация

По умолчанию шина импортирует все, к чему имеет доступ. Элементы, вставленные в слоты фильтров, будут действовать как белый список, позволяя импортировать только эти конкретные элементы.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если у вас на самом деле нет ни одного из этих предметов.

Щелкните правой кнопкой мыши контейнер с жидкостью (например, ведро или резервуар с жидкостью), чтобы установить эту жидкость в качестве фильтра вместо ведра или бака.

## <a name="upgrades" />Обновления

Шина импорта поддерживает следующие [обновления](upgrade_cards.md):

*   <ItemLink id="capacity_card" /> увеличивает количество слотов фильтра.
*   <ItemLink id="speed_card" /> увеличивает количество вещей, перемещаемых за операцию.
*   <ItemLink id="fuzzy_card" /> позволяет шине фильтровать по уровню повреждения и/или игнорировать элемент NBT.
*   <ItemLink id="inverter_card" /> переключает фильтр из белого списка в черный список.
*   <ItemLink id="redstone_card" /> добавляет контроль красного камня, заставляя шину работать во время высокого сигнала, низкого сигнала или один раз за импульс.
