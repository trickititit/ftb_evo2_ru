# <a name="the-guide" />Руководство

<ItemImage id="guide" scale="8" />

### <a name="this-guide-that-you-are-reading-now,-for-all-your-ae2-guiding-needs." />Это руководство, которое вы сейчас читаете, отвечает всем вашим AE2 потребностям.

* Откройте боковую панель слева, чтобы найти оглавление.
* На многих страницах есть интерактивные сцены. Если рядом со сценой есть кнопки ![Плюс](../assets/diagrams/plus.png) и ![Минус](../assets/diagrams/minus.png) (масштаб), вы можете вращать и перемещать камеру. Щелкните левой кнопкой мыши и перетащите, чтобы повернуть, щелкните правой кнопкой мыши и перетащите, чтобы перевести.
