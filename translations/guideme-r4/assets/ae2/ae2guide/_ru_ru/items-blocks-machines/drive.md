# <a name="the-me-drive" />МЭ Драйв

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/drive.snbt" />
</GameScene>

Диск — это [устройство](../ae2-mechanics/devices.md), к которому вы подключаете [ячейки хранения](storage_cells.md), чтобы использовать их для [сетевое хранилище](../ae2-mechanics/import-export-storage.md). Он имеет 10 слотов, каждый из которых принимает ячейку.

Вы можете перемещать и вытаскивать ячейки из его инвентаря, используя любую логистику предметов, например бункеры или автобусы AE2.

Его можно вращать с помощью <ItemLink id="certus_quartz_wrench" />.

## <a name="cell-status-leds" />Светодиоды состояния ячеек

На ячейках привода имеется светодиод, показывающий их состояние:

| Цвет | Статус |
| :----- | :------------------------------------------------------------------------------- |
| Зеленый | Пусто |
| Синий | Имеет некоторое содержание |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) полно, новые типы добавлять нельзя |
| Красный | [Байты](../ae2-mechanics/bytes-and-types.md) заполнено, больше нельзя вставить элементы |
| Черный | Ни силы, ни драйва нет [канал](../ae2-mechanics/channels.md) |

## <a name="priority" />Приоритет

Приоритеты можно установить, щелкнув гаечный ключ в правом верхнем углу графического интерфейса. Товары, поступающие в сеть, начинаются с хранилища с наивысшим приоритетом в качестве первого пункта назначения. В случае двух хранилищ или ячеек с одинаковым приоритетом, если одно из них уже содержит элемент, они предпочтут это хранилище любому другому. Любые ячейки [разделенный](cell_workbench.md) будут рассматриваться как уже содержащие элемент, если они находятся в той же группе приоритета, что и другие хранилища. Предметы, удаляемые из хранилища, будут удалены из хранилища с наименьшим приоритетом. Эта система приоритетов означает, что по мере того, как элементы вставляются и удаляются из сетевого хранилища, хранилища с более высоким приоритетом будут заполняться, а хранилища с более низким приоритетом будут опорожняться.
