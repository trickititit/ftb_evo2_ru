# <a name="the-color-applicator" />Цветной аппликатор

<ItemImage id="color_applicator" scale="4" />

Аппликатор цвета используется для окраски цветных блоков, таких как [кабели](cables.md), шерсть, терракота, стекло и бетон. В нем используются [пейнтболы](paintballs.md) или красители, а снежки можно использовать, чтобы счистить цвет с кабелей и пятна от пейнтбола с блоков.

Его энергию можно перезарядить в <ItemLink id="charger" />.

Цветные аппликаторы действуют как [ячейки хранения](storage_cells.md), и их хранилище для краски легче всего заполнить, вставив аппликатор в слот ячейки хранения в <ItemLink id="me_chest" />.

Щелкните правой кнопкой мыши цель, чтобы применить выбранный цвет. Чтобы изменить цвета, используйте колесо прокрутки, удерживая клавишу Shift, или щелкните правой кнопкой мыши без цели.

## <a name="upgrades" />Обновления

Цветные аппликаторы поддерживают следующий символ [обновления](upgrade_cards.md), вставленный через <ItemLink id="cell_workbench" />:

*   <ItemLink id="equal_distribution_card" /> выделяет одинаковое количество байтов ячейки для каждого типа, поэтому один тип не может заполнить всю ячейку
*   <ItemLink id="void_card" /> аннулирует вставленные элементы, если ячейка заполнена (или выделенное пространство этого конкретного типа в случае карты равного распределения). Будьте осторожны, разделив это!
*   <ItemLink id="energy_card" />, чтобы увеличить емкость аккумулятора
