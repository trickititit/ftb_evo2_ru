# <a name="the-level-emitter" />Измеритель уровня

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../assets/blocks/level_emitter.snbt" />
</GameScene>

Эмиттер уровня излучает сигнал красного камня в зависимости от количества предмета в [сетевое хранилище](../ae2-mechanics/import-export-storage.md).

Существует также версия, которая излучает сигнал красного камня в зависимости от [энергия](../ae2-mechanics/energy.md), хранящегося в вашей сети.

Предметы и жидкости можно перетаскивать в слот из JEI/REI, даже если у вас на самом деле нет ни одного из этих предметов.

Щелкните правой кнопкой мыши контейнер с жидкостью (например, ведро или резервуар с жидкостью), чтобы установить эту жидкость в качестве фильтра вместо ведра или бака.

Они [части кабеля](../ae2-mechanics/cable-subparts.md).

В отличие от других [устройства](../ae2-mechanics/devices.md), излучатели уровня *не* требуют [канал](../ae2-mechanics/channels.md).

## <a name="settings" />Настройки

*   Эмиттер уровня может быть установлен в режим «больше/равно» или «меньше».
*   Когда вставлен <ItemLink id="crafting_card" />, его можно установить на «испускать красный камень во время создания предмета» или «испускать красный камень при создании предмета».

## <a name="upgrades" />Обновления

Эмиттер уровня поддерживает следующие [обновления](upgrade_cards.md):

*   <ItemLink id="fuzzy_card" /> позволяет эмиттеру фильтровать по уровню урона и/или игнорировать предмет NBT.
*   <ItemLink id="crafting_card" /> включает функцию крафта.

## <a name="crafting-functionality" />Создание функциональности

Если вставлен <ItemLink id="crafting_card" />, эмиттер переключится в режим крафта.

Это дает возможность использовать два варианта:

Первый вариант, «излучать красный камень во время создания предмета», заставляет излучатель излучать сигнал красного камня, пока ваш [автокрафтинг](../ae2-mechanics/autocrafting.md) создает какой-то конкретный предмет через <ItemLink id="pattern_provider" />. Это полезно для включения только определенных энергоемких настроек автоматизации, пока они фактически используются.

Второй вариант, «использовать красный камень для создания предмета», чрезвычайно полезен для конкретных случаев использования, таких как бесконечные фермы и настройки автоматизации, которые имеют только шанс получить результат, а не гарантированный результат. Этот параметр создает виртуальный [узор](patterns.md) для использования [автокрафтинг](../ae2-mechanics/autocrafting.md) для любого элемента, находящегося в слоте фильтра излучателя. (Для правильной работы реальный шаблон для одного и того же предмета **не должен существовать** в ваших <ItemLink id="pattern_provider" />)

Этот «шаблон» не определяет ингредиенты и даже не заботится о них. Все, что там написано: «Если вы излучаете красный камень из излучателя этого уровня, система ME получит этот предмет в какой-то момент в ближайшем или отдаленном будущем». Обычно это используется для активации и деактивации бесконечных ферм, которые не требуют входных ингредиентов, или для активации [система, которая обрабатывает рекурсивные рецепты](../example-setups/recursive-crafting-setup.md) (что стандартное автокрафтирование не может понять), например, «1 булыжник = 2 булыжника», если у вас есть машина, которая дублирует булыжник.
