# <a name="the-memory-card" />Карта памяти

<ItemImage id="memory_card" scale="4" />

Карта памяти используется для копирования и вставки настроек между AE2 [устройства](../ae2-mechanics/devices.md) и ссылкой [P2P-туннели](p2p_tunnels.md). Он также может вставлять [карты обновления](upgrade_cards.md) в устройства.

- Shift — щелкните правой кнопкой мыши, чтобы скопировать настройки или создать новую частоту соединения P2P.
- Щелкните правой кнопкой мыши, чтобы вставить настройки, карты обновления или частоту привязки.
