# <a name="the-spatial-anchor" />Пространственный якорь

<BlockImage id="spatial_anchor" p:powered="true" scale="8"/>

Сеть AE2 должна быть загружена частями, чтобы любой из ее [устройства](../ae2-mechanics/devices.md) мог функционировать, и если загружена только часть сети, она может работать неправильно. Пространственный якорь решает эту проблему. Он принудительно загружает фрагменты, занимаемые его сетью. Одного кабеля, проходящего через границу фрагмента, достаточно для загрузки нового фрагмента.

Он будет распространять свою «нагрузку» по [квантовые мосты](quantum_bridge.md), но не между измерениями, поэтому, если у вас есть квантовый мост в Пустоту, вам понадобится пространственный якорь в сети на вашей базе и в сети в Пустоте.

По умолчанию он также включает случайные тики в загруженных фрагментах, но это можно отключить в конфигурации AE2.

Его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />, если вы по какой-то причине хотите это сделать.

## <a name="settings" />Настройки

*   Пространственная привязка обеспечивает доступ к глобальным настройкам для просмотра энергии в AE или E/FE.
*   Может отображаться внутримировая голограмма, показывающая загружаемые фрагменты.

## <a name="energy" />Энергия

Пространственный якорь будет использовать [энергия](../ae2-mechanics/energy.md) согласно этому уравнению:

e = 80 + (x\*(x+1))/2

где x — количество загружаемых фрагментов
