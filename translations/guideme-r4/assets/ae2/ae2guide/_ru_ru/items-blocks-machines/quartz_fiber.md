# <a name="the-quartz-fiber" />Кварцевое волокно

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/assemblies/quartz_fiber.snbt" />
<IsometricCamera yaw="195" pitch="30" />
</GameScene>

Кварцевое волокно используется для распределения энергии между [сети](../ae2-mechanics/me-network-connections.md), сохраняя при этом их разделение. Это позволяет подавать питание на [подсети](../ae2-mechanics/subnetworks.md) без необходимости прокладывать повсюду приемники энергии и силовые кабели. Его также можно использовать для предотвращения подключения кабелей, хотя использование кабелей разных цветов или использование <ItemLink id="cable_anchor" /> дешевле и эффективнее.

Они [части кабеля](../ae2-mechanics/cable-subparts.md).
