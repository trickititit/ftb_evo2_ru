# <a name="the-fluix-crystal" />Кристалл Флюкса

<ItemImage id="fluix_crystal" scale="4" />

*"Кристаллы Fluix обладают уникальной способностью поглощать и преобразовывать энергию из одной формы в другую и являются основой всех технологий Материи Энергии"*

Один из основных ингредиентов для блоков AE2, [устройства](../ae2-mechanics/devices.md) и предметов. Изготовлено путем бросания нижнего кварца, красного камня и
<ItemLink id="charged_certus_quartz_crystal" /> в воде.

Это может быть [автоматизированный](../example-setups/throw-in-water-automation.md), используя <ItemLink id="formation_plane" /> и <ItemLink id="annihilation_plane" />.
