# <a name="the-cable-anchor" />Кабельный анкер

<GameScene zoom="6" background="transparent">
  <ImportStructure src="../assets/assemblies/cable_anchor.snbt" />
  <IsometricCamera yaw="195" pitch="30" />
</GameScene>

Небольшие декоративные шипы, прикрепленные к кабелю, которые можно использовать, чтобы предотвратить соединение кабелей, создать лестницы с кабелями или создать впечатление, будто кабель соединен со стенами вокруг него. Также используется для создания <ItemLink id="facade" />.

Кабельные анкеры предотвращают образование соединений на той стороне, на которой они установлены.

По ним можно подняться как по лестнице.
