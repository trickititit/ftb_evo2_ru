# <a name="the-inscriber" />Надписчик

<BlockImage id="inscriber" scale="8" />

Устройство записи используется для записи цепей и [процессоры](processors.md) с помощью [прессует](presses.md), а также для измельчения различных предметов в пыль. Он может принимать либо силу AE2 (AE), либо энергию Ткани/Forge (E/FE). Он может быть двусторонним, так что при вставке предметов с разных сторон они вставляются в разные слоты в инвентаре. Чтобы облегчить это, его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />. Его также можно настроить на перенос результатов ремесел в соседние инвентари.

Размер входного буфера можно регулировать. Например, если вы хотите подавать из одного инвентаря в большой массив писцов, вам нужен небольшой буфер, чтобы материалы распределялись между писателями более оптимально (вместо того, чтобы первый писец заполнял до 64, а остальные были пустыми).

Для изготовления [процессоры](processors.md) используются 4 контурных пресса.

  <ItemImage id="logic_processor_press" scale="4" />

Нажатие имени можно использовать для именования блоков, похожих на наковальню, что полезно для маркировки объектов цифрой <ItemLink id="pattern_access_terminal" />.

## <a name="settings" />Настройки

* Устройство для рисования можно настроить на одностороннее (как описано ниже) или разрешить ввод данных в любой слот с любой стороны, при этом внутренний фильтр решает, что куда идти. В нестороннем режиме предметы нельзя извлечь из верхних и нижних слотов.
* Устройство для записи можно настроить на перемещение предметов в соседние инвентари.
* Размер входного буфера можно регулировать, большой вариант предназначен для автономного устройства записи, которое вы вводите вручную,
Маленький вариант — сделать большие распараллеленные установки более жизнеспособными.

## <a name="the-gui-and-sidedness" />Графический интерфейс и односторонность

В одностороннем режиме средство записи фильтрует то, что куда идет, с какой стороны вы вставляете или извлекаете.

![Графический интерфейс записывающего устройства](../assets/diagrams/inscriber_gui.png) ![Стороны для нанесения надписей](../assets/diagrams/inscriber_sides.png)

A. Доступ к **Верхнему входу** осуществляется через верхнюю часть устройства для рисования (элементы можно как вставлять, так и вытягивать из этого слота)

B. **Центральный вход** вставляется через левую, правую, переднюю и заднюю стороны устройства записи (элементы можно только вставлять в этот слот, но не вытягивать из них)

C. **Нижний вход** доступен через нижнюю часть устройства для рисования (элементы можно как вставлять, так и вытягивать из этого слота)

D. **Вывод** извлекается через левую, правую, переднюю и заднюю стороны устройства записи (элементы можно вытягивать только из этого слота, но не вставлять в него)
