# <a name="import-chest" />Импортировать сундук

Сундук с 9 слотами, который автоматически помещает все, что находится внутри него, в [Сетевое хранилище](../nodeworks-mechanics/network-storage.md). Бросайте предметы вручную, с помощью бункера или из труб другого мода, и сундук автоматически попадает в сеть.

  <ImportStructure src="../assets/assemblies/import_chest.snbt" />
</GameScene>

Предметы, которые невозможно принять (фильтры, отсутствие места и т. д.), остаются в сундуке, чтобы вы могли точно видеть, что застряло.

## <a name="channel" />Канал

Установите канал в графическом интерфейсе, чтобы ограничить передачу данных на карты памяти на этом канале. По умолчанию выполняется передача на каждую карту памяти в сети. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel).

## <a name="round-robin" />Круговая система

Переключите циклический перебор в графическом интерфейсе, чтобы распределить вставки по целевым картам памяти вместо того, чтобы всегда заполнять первую. Удобно, если вы хотите, чтобы входящие элементы распределяли нагрузку по нескольким целевым хранилищам.

## <a name="tick-interval" />Тиковый интервал

Графический интерфейс показывает, как часто сундук пытается вставиться, по умолчанию — один раз в секунду. Меньше для более быстрого потребления за счет большей работы сети, выше для настроек в режиме ожидания.

## <a name="redstone" />Редстоун

Красный камень графического интерфейса определяет, работает ли сундук:

- **Высокий**: активен при включении.
- **Низкий**: активен при отсутствии питания.
- **Игнорируется**: красный камень ничего не делает.

## <a name="wireless" />Беспроводная связь

Поместите <ItemLink id="receiver_antenna" /> на верх сундука и соедините его с <ItemLink id="broadcast_antenna" />, сидящим на
<ItemLink id="export_chest" /> в другой сети. Предметы, вставленные в
трансляция Export Chest помещается в этот сундук, а затем направляется в хранилище локальной сети, как и любой другой прием.
