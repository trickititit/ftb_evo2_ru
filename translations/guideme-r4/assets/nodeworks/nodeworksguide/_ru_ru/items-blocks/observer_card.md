# <a name="observer-card" />Карта наблюдателя

Считывает блок на установленной грани. Предоставляет идентификатор блока, каждое свойство состояния, которое имеет блок (рост `age`, `facing`, `waterlogged`, `lit`, ...), а также обратный вызов изменения, чтобы сценарии могли реагировать в тот момент, когда блок переходит в интересующее вас состояние.

<ItemImage scale="6" id="observer_card" />

## <a name="what-it&#x27;s-for" />Для чего это нужно

Фермы с ступенчатыми воротами являются основным вариантом использования. Поршень, подключенный к ванильному наблюдателю, срабатывает при каждом переходе роста, поэтому он сломает небольшой бутон за 1 осколок вместо того, чтобы ждать 4 полного кластера. С помощью карты наблюдателя скрипт может считывать фактическую стадию и подавать импульс прерывателю только тогда, когда блок принимает окончательную форму.

Это также подходящий инструмент для считывания, не являющегося сигналами красного камня: люк открыт/закрыт, состояние двери, уровень меда в улье, заполнение каплями, показания датчика дневного света, рост сладких ягод / водорослей / сахарного тростника, образование льда / снега под блоком, все, что имеет свойство `BlockState`, с которым вы можете сравнивать.

## <a name="installing-and-scripting" />Установка и создание сценариев

Устанавливается на лицевую сторону узла так же, как и <ItemLink id="io_card" />. См. [Установка карты ввода-вывода](./io_card.md#installing) для прохождения. Карта читает блок перед *этим лицом*.

См. [API сценариев ObserverCard](../lua-api/card-handle.md#observer-card), чтобы узнать о методах, которые он предоставляет.

## <a name="channel" />Канал

Карта наблюдателя имеет в графическом интерфейсе средство выбора канала. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel), чтобы узнать, как каналы определяют, какие сценарии могут обращаться к этой карте.
