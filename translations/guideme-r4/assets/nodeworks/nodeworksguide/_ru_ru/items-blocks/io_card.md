# <a name="io-card" />Карта ввода-вывода

Карта ввода-вывода позволяет сети считывать и записывать данные из соседнего блока по требованию. При установленной карте ввода-вывода сценарии могут запрашивать содержимое блока и перемещать в него или из него элементы или жидкости.

<ItemImage scale="6" id="io_card" />

## <a name="installing" />Установка

Карты ввода-вывода устанавливаются в лицевые слоты <ItemLink id="node" />. Щелкните правой кнопкой мыши грань узла, который касается блока, которым вы хотите управлять, и вставьте карту ввода-вывода в любой из 9 слотов. Поведение карты применяется к *этой грани*, поэтому один и тот же узел может иметь карты ввода-вывода на разных гранях, контролирующие разных соседей.

![](../assets/images/node_gui.png)

## <a name="what-it-does" />Что он делает

Блок с прикрепленной картой ввода-вывода отображается в сети как доступный для сценария инвентарь:

- `card:find(filter)` возвращает [ПредметыРучка](../lua-api/items-handle.md) для сопоставления содержимого.
- `card:insert(items)` / `card:tryInsert(items)` переместите в него предметы.
- `card:count(filter)` суммирует соответствующие предметы (и жидкости в mB).

В отличие от <ItemLink id="storage_card" />, блок карты ввода-вывода **не** является частью [Сетевое хранилище](../nodeworks-mechanics/network-storage.md). Скрипты должны явно перемещать элементы в него или из него, `network:find` по всей сети не увидит его содержимое, а
<ItemLink id="inventory_terminal" /> или <ItemLink id="portable_inventory_terminal" /> не будут их перечислять.

## <a name="channel" />Канал

В графическом интерфейсе карты ввода-вывода имеется средство выбора каналов. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel), чтобы узнать, как каналы определяют, какие сценарии и пресеты могут обращаться к этой карте.
