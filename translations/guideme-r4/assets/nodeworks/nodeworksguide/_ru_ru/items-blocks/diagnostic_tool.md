# <a name="diagnostic-tool" />Диагностический инструмент

Портативный инспектор для сети Nodeworks. Щелкните правой кнопкой мыши любой блок в сети, чтобы открыть панель, на которой суммируется все, из чего состоит сеть, и все, что она делает в данный момент.

<ItemImage scale="6" id="diagnostic_tool" />

## <a name="how-to-use-it" />Как его использовать

Щелкните правой кнопкой мыши любой сетевой блок в целевой сети. А
<ItemLink id="node" />, <ItemLink id="terminal" />,
<ItemLink id="network_controller" />, антенна или хранилище блокируют все
работа. Вы также можете щелкнуть любую часть мультиблока [Создание процессора](crafting_cpu.md) (Ядро, Буфер, Охлаждающая жидкость, Подложка, Сопроцессор); инструмент обходит кластер, чтобы найти для вас ядро.

Если блок, на который вы нажимаете, не находится в сети, инструмент сообщит вам об этом с помощью наложенного сообщения и не откроется.

## <a name="what-it-shows" />Что это показывает

Диагностическая панель объединяет все, что предоставляет сеть:

- **Топология**. Каждый блок в сети с указанием его положения, типа и деталей каждого блока. <ItemLink id="node" />s перечисляет карты на каждой грани вместе с соседним блоком, на который они нацелены.
- **Сетевая идентификация**. Имя и цвет контроллера, а также быстрый обзор его режима красного камня, ограничения повторных попыток обработчика и переключателя загрузки фрагментов.
- **ЦП**. Каждый <ItemLink id="crafting_core" /> в сети, его текущий крафт (если есть), использование буфера, эффективность и правильность формирования мультиблока.
- **Терминалы**. Каждый <ItemLink id="terminal" /> в сети со своим списком сценариев, флагом автозапуска, состоянием выполнения и обработчиками [Набор обработки](recipe_sets.md#processing-set), зарегистрированными для каждого запущенного сценария.
- **Предметы, которые можно создать**. Полный список предметов, которые сеть может создать автоматически, собранный из каждого <ItemLink id="instruction_storage" /> и <ItemLink id="processing_storage" />.
- **Недавние ошибки**. Последние 10 ошибок скрипта от терминалов в сети со смещением деления, показывающим, как давно сработала каждая из них.

Представление доступно только для чтения. Ничто из того, что вы нажимаете на панели, не меняет сеть, это просто для того, чтобы выяснить, что где и что пошло не так.

## <a name="when-to-reach-for-it" />Когда к этому обратиться

- Корабль не удался, и вы хотите увидеть ошибку, не стоя рядом с <ItemLink id="crafting_core" />.
- Вы унаследовали разветвленную сеть и вам нужна карта.
- Вы пытаетесь выяснить, почему рецепт нельзя изготовить автоматически, а список предметов, которые можно изготовить, показывает, что на самом деле умеет делать сеть.
- Сценарий кажется зависшим, на панели терминала отображается его рабочее состояние и зарегистрированные обработчики, не открывая каждый терминал вручную.
