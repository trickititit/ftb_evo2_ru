# <a name="inventory-terminal" />Инвентарный терминал

Терминал инвентаря — это окно просмотра в [сетевое хранилище](../nodeworks-mechanics/network-storage.md).

<BlockImage scale="6" id="inventory_terminal" />

## <a name="browsing-the-grid" />Просмотр сетки

![](../assets/images/inventory_terminal_gui_expanded.png)

- Щелчок левой кнопкой мыши захватывает стопку
- Щелчок правой кнопкой мыши забирает половину стека
- Двойной щелчок собирает все совпадающие элементы в курсор.
- Выбрасывание перенесенной стопки на сетку вставляется в [Сетевое хранилище](../nodeworks-mechanics/network-storage.md).
- Щелчок правой кнопкой мыши по перенесенной стопке в сетку вставляет один элемент.
- Удерживайте `Alt`, чтобы отобразить автоматически создаваемые предметы в сети.

На левой стороне расположены кнопки:

- Изменение макетов
- Сортировка сетки
- Фильтрация по (хранилищу, рецептам или тому и другому)
- Вид (предметы, жидкости или и то, и другое)
- Переключатель поиска автофокуса

В центре находится складная сетка для крафта с кнопками:

- Автоматическое извлечение из сети
- Равномерно распределите ингредиенты в сетке крафта.
- Перемещайте ингредиенты из сетки крафта в сетевое хранилище.

Shift — щелчок по результату крафта создаст одну стопку в вашем инвентаре. `Ctrl` + Shift нажмите на поделки столько, сколько поместится.
