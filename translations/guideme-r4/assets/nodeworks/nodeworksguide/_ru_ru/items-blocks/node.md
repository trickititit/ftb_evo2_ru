# <a name="node" />Узел

Узел — это блок, содержащий [Карты](../nodeworks-mechanics/cards.md). Само подключение к сети осуществляется через [Трубы](pipe.md). Узел — это то, что вы добавляете в трубопровод, где хотите, чтобы карты взаимодействовали с соседним блоком.

<BlockImage scale="6" id="node" />

## <a name="faces" />Лица

Каждое лицо адаптируется к тому, что находится рядом с ним. Лицо, касающееся другого сетевого блока, становится частью канала и отключает его слоты для карт. Лицо, касающееся обычного блока, содержит карты, нацеленные на этого соседа.

## <a name="opening-the-gui" />Открытие графического интерфейса

Щелкните правой кнопкой мыши грань, не являющуюся трубой, чтобы открыть ее карточную сетку. Shift + щелчок правой кнопкой мыши открывает *противоположную* грань. Удобно, когда нужная сторона закопана. Торцы труб не открываются; их вкладка в боковой панели выбора отображается затемненной.

![](../assets/images/node_gui.png)

## <a name="cards" />Карты

Поместите карту в любой из 9 слотов на лицевой стороне устройства, чтобы дать этому лицу возможность:

- <ItemImage scale="0.5" id="io_card" /> <ItemLink id="io_card" />: позволяет сети перемещать элементы в соседний блок и из него.
- <ItemImage scale="0.5" id="storage_card" /> <ItemLink id="storage_card" />: помечает инвентарь соседнего блока как сетевое хранилище.
- <ItemImage scale="0.5" id="redstone_card" /> <ItemLink id="redstone_card" />: считывает и излучает сигналы красного камня с этого лица.
- <ItemImage scale="0.5" id="observer_card" /> <ItemLink id="observer_card" />: считывает состояние блока, к которому он обращен.

Несколько карт в одной стопке. Лицо с картой ввода-вывода и картой красного камня может перемещать предметы И излучать сигнал красного камня с одной и той же стороны.

## <a name="focus-node" />Фокусный узел

<GameScene interactive={true} zoom="5">
  <IsometricCamera yaw="200" pitch="10" />
  <ImportStructure src="../assets/assemblies/focus_node.snbt" />
</GameScene>

<ItemLink id="focus_node" /> — это вариант узла для междугородных соединений. Соедините два узла фокусировки с
<ItemLink id="network_wrench" /> и сеть воспринимает их как
подключены, даже если между ними нет непрерывного канала, что полезно для преодоления промежутков или перехода между отдельными кластерами машин без запуска канала целиком.

Фокусные узлы по-прежнему ведут себя как обычные узлы для своих шести граней: те же роли Трубы/Устройства/Свободные, те же слоты для карт, такое же автоматическое подключение к соседним Трубам. Ссылка, связанная с гаечным ключом, является дополнением к любой смежности, которую они подбирают локально.
