# <a name="export-chest" />Экспортный сундук

Сундук с 9 слотами, который автоматически извлекает предметы из [Сетевое хранилище](../nodeworks-mechanics/network-storage.md) в свой собственный буфер.

## <a name="filter" />Фильтр

Графический интерфейс сундука принимает список правил фильтрации, используя тот же синтаксис шаблона, что и <ItemLink id="storage_card" />. Любой предмет, соответствующий правилу, является честной добычей для экспорта. Пустой фильтр простаивает сундук, поэтому новое размещение не приводит к немедленному опустошению сети.

## <a name="push-face" />Нажмите лицо

Выберите лицо в графическом интерфейсе, чтобы автоматически опустошить буфер в инвентарь на этой стороне. Полезно для загрузки бункера, печи или машины без необходимости использования скрипта. Оставьте этот параметр отключенным, чтобы сохранить буфер в качестве места для ручного получения.

## <a name="channel" />Канал

Установите канал, чтобы ограничить использование карт памяти на этом канале. По умолчанию данные извлекаются из каждой карты памяти в сети. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel).

## <a name="redstone" />Редстоун

Красный камень графического интерфейса определяет, работает ли сундук:

- **Высокий**: активен при включении.
- **Низкий**: активен при отсутствии питания.
- **Игнорируется**: красный камень ничего не делает.

## <a name="wireless" />Беспроводная связь

Поместите <ItemLink id="broadcast_antenna" /> сверху сундука и соедините его с <ItemLink id="receiver_antenna" /> в другой сети. Предметы, помещенные в сундук, пересылаются прямо в хранилище принимающей сети.
