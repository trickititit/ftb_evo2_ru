# <a name="breaker-block" />Выключатель Блок

Разрушитель со временем уничтожает блок в позиции перед собой и направляет его обратно в [Сетевое хранилище](../nodeworks-mechanics/network-storage.md) (или в обработчик, предоставленный сценарием). Уровень алмазной кирки, длительность разрушения которого соответствует формуле деревянной кирки, поэтому более твердые блоки ломаются заметно дольше.

<BlockImage scale="6" id="breaker" />

## <a name="placing" />Размещение

Передняя грань Разрушителя направлена на то место, куда вы целились, когда его опускали (такая же форма, как у поршня или дозатора). Блок перед этим лицом — это то, что `:mine()` сломает.

## <a name="target-filter" />Целевой фильтр

В графическом интерфейсе Breaker есть фильтр, для которого он должен сломаться. Оставьте это поле пустым, чтобы сломать что-нибудь впереди, или установите блок, чтобы ограничить Разрушителя этой целью.

## <a name="tree-felling" />Вырубка деревьев

Если вы поместите Разрушитель у основания дерева, оно упадет все.

## <a name="redstone" />Редстоун

Настройка красного камня графического интерфейса определяет, когда Разрушителю разрешено стрелять:

- **Высокий**: активен при включении.
- **Низкий**: активен при отсутствии питания.
- **Игнорируется**: красный камень ничего не делает. Breaker срабатывает только тогда, когда скрипт вызывает `:mine()`.

## <a name="channel" />Канал

В графическом интерфейсе Breaker есть средство выбора имени и канала. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel), чтобы узнать, как каналы определяют, какие сценарии могут обращаться к этому устройству.
