# <a name="scripting-terminal" />Скриптовый терминал

Терминал сценариев — это место, где вы пишете и запускаете сценарии Lua, управляющие сетью.

<BlockImage scale="6" id="terminal" />

## <a name="opening-the-editor" />Открытие редактора

Щелкните правой кнопкой мыши терминал, чтобы открыть. Редактор имеет три панели:

- **Боковая панель**: список всех карточек и переменных в сети. Нажмите, чтобы вставить линию `network:get("…")` возле курсора.
- **Вкладки сценариев**, `main`, а также любые созданные вами модули. `main` запускается при нажатии кнопки «Пуск», другие вкладки загружаются через [`require(name)`](../lua-api/index.md).
- **Панель вывода**, вывод из `print(…)`, плюс любые ошибки сценария.
  - Вы также можете щелкнуть стрелку влево, чтобы развернуть/свернуть вывод, или перетащить разделительную полосу, чтобы изменить его размер.

![](../assets/images/terminal_gui.png)

## <a name="running-scripts" />Запуск сценариев

(также см. ссылку [API сценариев](../lua-api/index.md), где описано все, что могут делать сценарии, сетевые запросы, создание, обратные вызовы планировщика, переменные.)

Нажмите «Пуск», чтобы загрузить и запустить текущую вкладку `main`. Сценарий завершает работу после завершения `main`, если только он не зарегистрирует обратные вызовы для продолжения работы. Нажмите «Стоп», чтобы завершить сценарий.

### <a name="autorun" />Автозапуск

Включите автозапуск в редакторе, чтобы скрипт запускался автоматически при загрузке терминала. Терминал загружается только тогда, когда загружен его чанк, поэтому автоматический запуск НЕ подразумевает «запуск всякий раз, когда сервер включен». Игрок должен находиться в пределах досягаемости, чтобы чанк мог загрузиться, или для <ItemLink id="network_controller" /> сети необходимо включить загрузку чанка, чтобы чанк оставался загруженным, даже если поблизости никого нет.

![](../assets/images/autorun.png)

### <a name="redstone" />Редстоун

Импульс красного камня на терминале переключает сценарий. Если сценарий остановлен, импульс запускает его. Если он уже запущен, импульс останавливает его. Сработает любой нарастающий фронт: нажатие кнопки, ступенька нажимной пластины или только что установленная горелка.

> Если скрипт завершается по истечении времени ожидания настенных часов, Redstone не сможет его перезапустить > пока вы не откроете редактор и не отредактируете скрипт. Это не позволяет часам из красного камня, направленным на плохо работающий терминал, повторно запускать один и тот же сломанный сценарий в каждом цикле.
