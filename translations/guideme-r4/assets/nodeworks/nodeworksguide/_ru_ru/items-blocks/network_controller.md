# <a name="network-controller" />Сетевой контроллер

Каждой сети Nodeworks нужен ровно один контроллер. Без него связанные с ним [Трубы](pipe.md) и [Узлы](node.md) остаются бездействующими.

Разместите контроллер, запустите от него каналы, и любой блок, который подключается к этим каналам, присоединяется к сети.

## <a name="identity" />идентичность

Графический интерфейс контроллера позволяет вам дать сети имя и выбрать цвет. Название косметическое, цвет придает оттенок, узел светится, поэтому несколько сетей в одной области легко отличить друг от друга.

## <a name="chunk-loading" />Загрузка чанка

Переключение загрузки фрагментов в графическом интерфейсе сохраняет принудительной загрузкой каждый фрагмент, к которому прикасается сеть. Полезно для автоматического создания установок, которые должны продолжать работать, пока вы находитесь далеко.

## <a name="one-per-network" />Один на сеть

Два контроллера, подключенные к одному и тому же участку трубопровода, будут конфликтовать, и обе сети отключатся, пока один из них не будет удален.
