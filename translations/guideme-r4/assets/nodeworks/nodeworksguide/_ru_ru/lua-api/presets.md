# <a name="presets" />Пресеты

Пресеты — это декларативные конструкторы для двух наиболее часто встречающихся шаблонов сценариев: **перемещение товаров из A в B** и **поддержание пополнения уровня запасов**. Каждая предустановка представляет собой цепочку вызовов методов, которая читается слева направо как предложение и заканчивается на `:start()` в начале.

Пресеты располагаются поверх существующего API сценариев. Они по-прежнему Lua, по-прежнему используют карты и фильтры таким же образом, и их по-прежнему сносят, когда скрипт останавливается. Разница в том, что одна строка предустановки заменяет примерно 15 строк цикла планировщика с ручным отслеживанием состояния.

<LuaCode>
```lua
-- move cobblestone from a farm chest into Network Storage, once per second.
importer:from("mobFarm"):filter("$item:cobblestone"):to(network):start()
-- keep 64 arrows stocked in a dispenser, crafting more when short.
stocker:ensure("minecraft:arrow"):to("dispenser"):keep(64):start()
```
</LuaCode>

## <a name="current-presets" />Текущие пресеты

* [Импортер](importer.md) перемещает предметы из одного или нескольких источников в одну или несколько целей. По умолчанию — заполнение (исчерпайте каждую цель, прежде чем двигаться дальше). Вместо этого вызовите `:roundrobin()`, чтобы переключаться между целями.
* [Стокер](stocker.md) поддерживает запас цели на уровне `:keep(n)` путем извлечения из хранилища, создания или того и другого. Никогда не извлекается после достижения уровня.

## <a name="source-and-target-references" />Ссылки на источники и цели

Везде, где пресет принимает источник или цель, он принимает три формы:

1. **Строковый** псевдоним карты: `"bufferChest"`.
2. **CardHandle** от `network:get(...)`.
3. Глобальный элемент **`network`** означает «весь пул сетевых хранилищ».

<LuaCode>
```lua
-- All three forms are valid and can be mixed.
importer:from("farm", network:get("secondary"), network)
  :to("output")
  :start()
```
</LuaCode>

Разрешение карты происходит по имени каждый раз, когда меняется топология сети, поэтому карта, которая сломалась и была заменена под тем же именем, продолжает работать без перезапуска предустановки. Пропавшие карты молча пропускаются до тех пор, пока они не вернутся.

## <a name="shared-methods" />Общие методы

Все `ImporterBuilder` и `StockerBuilder` понимают один и тот же жизненный цикл и методы управления.

### <a name="every" />каждый

<LuaCode>
```lua
ImporterBuilder:every(ticks: number): ImporterBuilder
StockerBuilder:every(ticks: number): StockerBuilder
```
</LuaCode>

Устанавливает частоту переоценки предустановки. По умолчанию — 20 тактов (один раз в секунду). Изменение скорости в середине выполнения отменяет текущую задачу планировщика и перерегистрирует ее в новом интервале, поэтому `imp:every(5)` вступает в силу немедленно.

### <a name="start-/-stop-/-isrunning" />запустить / остановить / isRunning

<LuaCode>
```lua
ImporterBuilder:start()
ImporterBuilder:stop()
ImporterBuilder:isRunning(): boolean
```
</LuaCode>

`:start()` проверяет цепочку и начинает тикать. Это недопустимо, если сборщик уже запущен, поэтому его повторный вызов безопасен. `:stop()` прекращает тикать, но сохраняет всю конфигурацию, поэтому более поздний `:start()` возобновляет ту же цепочку, включая любую позицию курсора циклического перебора.

<LuaCode>
```lua
local imp = importer:from("src"):to("dst")
scheduler:second(function()
  if someCondition() and not imp:isRunning() then
    imp:start()
  elseif imp:isRunning() and not someCondition() then
    imp:stop()
  end
end)
```
</LuaCode>

## <a name="cleanup-on-script-stop" />Очистка при остановке скрипта

Когда терминал сценариев останавливается (вручную или из-за отключения от сети), все пресеты, зарегистрированные в течение срока службы этого сценария, автоматически останавливаются. Висячие построители, которые были созданы, но никогда не были `:start()`, также очищаются. Повторный запуск сценария восстанавливает каждую предустановку с нуля, поэтому вы можете свободно редактировать цепной код между запусками, не беспокоясь об оставшихся задачах.
