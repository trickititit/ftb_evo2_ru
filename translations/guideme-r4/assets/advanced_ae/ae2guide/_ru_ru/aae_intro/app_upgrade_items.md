# <a name="advanced-pattern-provider-upgrades" />Расширенные обновления поставщика шаблонов

Элементы поставщика AdvancedAE, которые позволяют обновлять поставщиков шаблонов без необходимости перемещения всех шаблонов и обновлений.

## <a name="advanced-pattern-provider-upgrade" />Расширенное обновление поставщика шаблонов

<ItemImage id="advanced_ae:adv_pattern_provider_upgrade" scale="3"></ItemImage>

Эти обновления можно использовать для обычных поставщиков шаблонов AE и расширенных поставщиков шаблонов ExtendedAE. Использование его на этих машинах обновит их до расширенной версии, сохранив то же количество слотов, что и раньше. Это означает, что в процессе вы не потеряете материалы, использованные для обновления обычных поставщиков до расширенных.

## <a name="advanced-pattern-provider-capacity-upgrade" />Расширенное обновление мощности поставщика шаблонов

<ItemImage id="advanced_ae:adv_pattern_provider_capacity_upgrade" scale="3"></ItemImage>

Увеличение емкости используется для обновления обычных поставщиков шаблонов непосредственно до расширенного поставщика шаблонов с 36 слотами шаблонов.
