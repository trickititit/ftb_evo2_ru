  ## <Color id="gold">Ваша первая мерцающая сталь</Color>
</Column>

Как только ваш ледниковый бассейн соберет жидкую ауру:

1. Щелкните правой кнопкой мыши по чаше, удерживая железный слиток.
2. Утюг превращается в <ItemLink id="shimmersteel_ingot" />.
3. Используйте мерцающую сталь для создания улучшенных инструментов и оружия.
