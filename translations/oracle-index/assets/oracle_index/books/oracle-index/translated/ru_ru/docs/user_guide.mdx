---
title: "Руководство пользователя"
---

Oracle Index — это внутриигровой мод клиентской документации, который предназначен для внутриигрового просмотра контента из [moddedmc.wiki](https://moddedmc.wiki/).

Разработчики модов могут включить свои вики в свои моды, а затем использовать мод Oracle Index для их отображения в игре. Нажмите сочетание клавиш вики (по умолчанию [H]), чтобы открыть индексный экран оракула. Вам не нужна специальная книга или что-то еще. При выходе из экрана он запомнит, где вы остановились.

Вы можете просмотреть документацию мода только в том случае, если мод установлен и разработчик мода решил включить свою документацию с moddedmc.wiki также как Oracle Index wiki.

## Переключение модов
В левой части экрана вы увидите панель навигации для выбранного в данный момент мода. Чтобы переключиться на другой мод, просто щелкните строку заголовка мода над панелью навигации. Откроется раскрывающийся список, в котором вы сможете выбрать, какой мод просмотреть.

## Ссылки на предметы
Разработчики модов могут добавлять вики-ссылки на игровые предметы. Если для элемента доступна вики-страница, вы увидите небольшую дополнительную информацию во всплывающей подсказке к элементу. Удерживайте кнопку [ALT], чтобы открыть соответствующую запись в вики, когда увидите всплывающую подсказку к элементам.

## Язык
Oracle Index автоматически использует переведенный контент для вашего языка Minecraft, если вики его предоставляет. Содержимое страниц, метаданные навигации, заголовки страниц, встроенные элементы управления, выноски и сообщения о состоянии — все это можно перевести.

Переведенные страницы отражают путь к базовой странице под `translated/<locale>/` в вики-схеме 1 или `.translated/<locale>/` в устаревших вики. Если переведенная страница или файл метаданных отсутствует, Oracle Index возвращается к ресурсу базового языка.

Поиск в настоящее время индексирует текст страницы на базовом языке. Результаты по-прежнему открывают переведенную страницу, если она доступна, а отображаемые заголовки страниц используют активный язык.
