Oritech включает в себя несколько блоков обшивки для строительства завода. Они хорошо подходят для полов, стен и каркасных конструкций.

Все блоки обшивки поставляются в вариантах **плиты**, **лестницы** и **прижимной пластины**.

### Варианты покрытия

*   **[Машинное покрытие](@oritech:copper_reinforced_plating)**: стандартное покрытие, используемое для корпусов машин.
Он имеет чистую, гладкую текстуру, которая хорошо сочетается с машинами Oritech.
*   **[Железное покрытие](@oritech:iron_plating)**: Более темное, прочное покрытие промышленного класса.
Подходит для областей тяжелой промышленности и структурных опор.
*   **[Никелирование](@oritech:nickel_plating)**: Яркое, устойчивое к коррозии покрытие со слегка желтоватым оттенком.
Полезно для чистых помещений или помещений со специализированным оборудованием.
*   **[Карбоновое покрытие](@oritech:carbon_plating)**: Современное высокопрочное темное покрытие.
Полезно для контрастных и более темных проектов продвинутых объектов.
