# Исследования и разработки

Для начала войдите в собранный **Центр кибернетического расширения**.  Откроется интерфейс исследования, в котором вы сможете просматривать и запускать проекты. Для каждого улучшения требуется определенная энергия и ресурсы, взятые либо из вашего личного инвентаря, либо из внутренней памяти машины (доступной через интерфейс).

Многие высокоуровневые улучшения требуют более ранних исследований, как показано в дереве технологий.

Центр действует как узел для **Исследовательских станций**, построенных как многоблочные надстройки. Основное устройство поддерживает до **трех станций**, что позволяет осуществлять параллельную обработку.
*   Для каждой станции требуется **3 машинных ядра**.
*   Станция одновременно выполняет одну активную исследовательскую задачу.

# Применение и контроль

После завершения исследования аугментация становится доступной для установки. Для этой процедуры требуется единовременная затрата ресурсов, чтобы навсегда объединить технологию с вашим плеером.

Если у вас установлены дополнения, вы можете загрузить их в машину с помощью функции **Импорт** (кнопка пользовательского интерфейса слева внизу).

**Управление улучшениями**. Ваши улучшения должны быть постоянными: они не требуют обслуживания или постоянных затрат на электроэнергию. Однако если какая-либо способность отвлекает (например, **Рудное зрение** или **Гиперскорость**), ее можно переключить по своему желанию.

*   **Переключение меню**: удерживайте горячую клавишу аугментации (**[G]** по умолчанию), чтобы открыть радиальный интерфейс. Наведите курсор на нужный 
увеличить и отпустить, чтобы переключить его состояние.
*   **Удаление**: Хотя улучшения должны быть постоянными, при необходимости их можно удалить. 
Обратите внимание, что ресурсы, вложенные в установку, не подлежат возврату.

**Информация для разработчиков модпаков**

Oritech аугментации полностью управляются данными и настраиваются, что позволяет осуществлять обширную настройку с помощью пакетов данных.

*   **Дополнения модификаторов**: изменяют атрибуты объекта (например, скорость, радиус действия, здоровье).
*   **Усиление эффектов**: применяйте статусные эффекты, аналогичные зельям.
*   **Пользовательские улучшения**: реализация уникальной логики (например, Ore Vision). На них можно ссылаться в пакетах данных, но для этого требуется Java-версия. 
мод для базовой логики.

Существующие дополнения можно изменить или отключить, а совершенно новые можно определить с помощью JSON.
*   **Пример определения**: [Увеличение урона от атаки (GitHub)](https://github.com/Rearth/Oritech/blob/1.21/fabric/src/main/generated/data/oritech/recipe/augment/attackdamage.json)
*   **Расположение текстуры**: `oritech/textures/gui/augment`

Не забудьте включить записи перевода для любых пользовательских дополнений.
