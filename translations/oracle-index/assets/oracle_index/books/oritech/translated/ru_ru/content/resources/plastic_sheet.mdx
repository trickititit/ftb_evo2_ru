Пластик — полезный полимер, используемый для изготовления изоляторов, корпусов и многих компонентов игры среднего и позднего уровня.

В Oritech есть два основных способа производства пластика:
1. **Биологический путь**: Обработка [упакованная пшеница](@oritech:packed_wheat) в [центрифуга](@oritech:centrifuge)
с водой для получения необработанного биополимера, который затем можно снова центрифугировать с водой для получения пластиковых листов.
2. **Нефтяной путь**: перерабатывайте сырую нефть в [нефтеперерабатывающий завод](@oritech:refinery)
для получения нафты. Перерабатывайте нафту в центрифуге с песком, чтобы получить полимерную смолу, которую можно переплавить в пластиковые листы. Этот маршрут требует больше настроек, но при этом производит больше пластика.

Пластик используется в деталях машин высокого уровня и передовых компонентах автоматизации.
