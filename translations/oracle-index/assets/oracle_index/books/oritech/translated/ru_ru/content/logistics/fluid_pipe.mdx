Переносит жидкости между машинами и резервуарами. Скорость передачи по умолчанию составляет 0,5 корзины каждые 3 тика. Трубы для жидкости не имеют внутреннего хранилища.

## Использование
Подсоедините трубы к любому блоку с возможностью работы с жидкостью. Щелкните правой кнопкой мыши соответствующую часть трубы, чтобы переключить извлечение. Никакого гаечного ключа не требуется. Однако для отключения трубных соединений можно использовать гаечный ключ.

## Варианты
*   **Стандарт**: базовая модель трубы.
*   **В рамке**: цельноблочная версия для крепления к стене.
*   **Воздуховод**: альтернативный эстетический стиль. Канальные варианты не подключаются к машинам напрямую, а только к другим трубам.
