Высококачественный энергетический кабель для очень большой передачи RF. Скорость передачи по умолчанию составляет 4,1M RF/t.

## Использование

Работает как стандартные энергетические трубы, но с гораздо более высокой пропускной способностью. Они толще обычных труб. Сверхпроводники не могут соединяться с обычными энергетическими трубами.

## Варианты
*   **Стандарт**: Сверхпроводящий кабель с сердечником
*   **В рамке**: полноблочная версия.
*   **Воздуховод**: альтернативный эстетический стиль. Канальные варианты не подключаются к машинам напрямую, а только к другим трубам.

    Необходим для передачи огромной энергии [Ядерный реактор](@oritech:nuclear_reactor_controller).
</Callout>
