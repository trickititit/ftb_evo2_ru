Усиленный контейнер для нестабильных жидкостей, летучих соединений и других материалов, с которыми большинство машин Oritech не работают напрямую.

**Использование**
- **Захват сущности**: можно использовать для захвата сущности маленьких волшебных летающих существ, чтобы 
создать [Нечестивый интеллект](@oritech:unholy_intelligence).
- **Обработка**: Может быть заполнен [Странная материя](@oritech:still_strange_matter) в центрифуге.
- **Ремесло**: используется в рецептах высокого уровня, таких как [Сверхпроводник](@oritech:superconductor), 
[Ultimate Machine Core прогресс](@oritech:machine_core_6), [Сейф Шрёдингера](@oritech:schrodingers_safe) и другие машины с тяжелыми условиями сдерживания.
