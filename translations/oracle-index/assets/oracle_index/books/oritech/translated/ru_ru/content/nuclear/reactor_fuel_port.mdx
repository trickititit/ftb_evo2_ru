---
title: "Топливный порт реактора"
id: oritech:reactor_fuel_port
type: block
---

Топливные каналы необходимо разместить в верхней части реактора, а топливные стержни — внизу.

Сюда можно вставить топливные гранулы. Порт автоматически распределяет введенные урановые или плутониевые гранулы по стержням, расположенным ниже.

При использовании с предметными трубами или дронами его можно использовать для строительства электростанций с постоянным питанием.

Подробную информацию о механике реактора смотрите в разделе [руководство по ядерному реактору]($reactor/introduction).
