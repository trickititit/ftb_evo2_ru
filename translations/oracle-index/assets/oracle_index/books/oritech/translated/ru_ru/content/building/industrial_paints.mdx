Большинство машин Oritech, особенно анимированных, можно перекрасить в разные цветовые схемы. Машинные краски представлены в 9 вариантах, каждый из которых немного отличается по стилю.

Чтобы применить новый цвет, щелкните машину, удерживая краску, удерживая клавишу Shift. Если ничего не произойдет, эту машину нельзя будет перекрасить.
