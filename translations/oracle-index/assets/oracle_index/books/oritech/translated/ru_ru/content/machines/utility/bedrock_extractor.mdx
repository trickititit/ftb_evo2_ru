Экстрактор коренных пород — это большая машина, используемая для добычи ресурсов из-под слоя коренной породы.

<center>
<ModAsset location="oritech:area/bedrock_extraction" width={800} />
</center>

Он может работать только при размещении непосредственно над [узлы ресурсов](@oritech:redstone_resource_node).

---

**Добыча ресурсов коренных пород**

Экстрактор сканирует область 3х3 под ним и добывает из первых видимых рудных узлов, обнаруженных на глубине 3 блоков. При щелчке правой кнопкой мыши машина выделит целевые узлы ресурсов ниже.

Из-за высоких требований к питанию его нельзя запитать через стандартные кабели, и его необходимо подать на [Эндерические лазеры](@oritech:enderic_laser).

Ресурсные узлы являются бесконечными источниками материала и никогда не будут истощены экстрактором.

**Подробности операции**

Во время работы экстрактор случайным образом выбирает один блок из области 3x3 под ним для каждого успешного цикла. Не все блоки в области должны быть рудными узлами, но для достижения наилучшего результата вам следует постараться расположить экстрактор над местом с максимальным количеством рудных узлов.
