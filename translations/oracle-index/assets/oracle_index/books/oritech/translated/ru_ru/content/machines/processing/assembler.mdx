Сборщик имеет сетку крафта 2x2 и автоматически собирает предметы, пока у него есть энергия, предметы во входных слотах и место для готового продукта в выходном слоте.

Некоторые компоненты машин можно изготовить без ассемблера, но для этого требуется значительно больше ресурсов.

Порядок компонентов во входных слотах не имеет значения. Если машине нужно 2 одинаковых предмета, она также может взять оба из одного слота.

## Автоматизация

Для точной настройки ввода предметов можно использовать надстройку прокси-сервера инвентаря, чтобы контролировать, какие предметы куда отправляются. Альтернативно, ассемблер также имеет разные режимы ввода. Варианты «Заполнить равномерно» или «Стороны» могут значительно упростить автоматизацию некоторых настроек.

Автоматизацию также можно выполнить через AE2/RS2. Поставщики шаблонов готовы работать с ассемблером.


## Эффективность

Использование ассемблера — рекомендуемый способ создания сложных компонентов, таких как [моторы](@oritech:motor) или [магнитные катушки](@oritech:magnetic_coil). Создание этих компонентов вручную возможно, но требует больше ресурсов, чем использование ассемблера.
