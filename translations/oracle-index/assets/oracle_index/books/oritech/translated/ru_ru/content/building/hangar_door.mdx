title: "Дверь промышленного ангара"
type: block
---

Дверь промышленного ангара — это большая анимированная дверь для заводских ворот, шахт обслуживания и доступа к грузу. Это дверь размером 1х3х1, которую можно разместить на полу, потолке и стенах.

В отличие от **[промышленная дверь](@oritech:industrial_door)**, дверью ангара можно управлять только с помощью красного камня. Соседние двери ангара можно соединить последовательно, позволяя одному сигналу красного камня открыть весь соединенный ряд.

При размещении на стене он обращен вертикально при размещении сверху/снизу. При размещении с боков он обращен горизонтально.

Он соответствует **[машинное покрытие](@oritech:copper_reinforced_plating)**, а также может быть перекрашен промышленными красками.
