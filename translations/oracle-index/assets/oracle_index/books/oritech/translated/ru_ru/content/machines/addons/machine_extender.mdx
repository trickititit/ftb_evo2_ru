Machine Addon Extender используется для увеличения количества доступных дополнительных слотов для машины.

Сам по себе он не дает никаких бонусов, но позволяет разместить больше аддонов, чем обычно позволяет базовое качество машины.

<center>
<ModAsset location="oritech:area/addon_marker" width={300} />
</center>

---

**Расширение**

Удлинители необходимо подключать непосредственно к машине или к другому подключенному удлинителю. Максимальное количество расширителей, которое может поддерживать машина, определяется ее качеством [Машинное ядро](@oritech:machine_core_2). Ядра более высокого качества позволяют создавать более сложные и многоуровневые настройки надстроек.

<center>
<ModAsset location="oritech:area/extenders" width={700} />
</center>

Качество машины можно просмотреть в левом верхнем углу пользовательского интерфейса машины, наведя курсор на значок ядра машины.
