Электрум — это основной сплав, используемый для создания проводов, разъемов и различных электронных компонентов.

Электрум можно сделать в сетке крафта, используя золото и красный камень:

<CraftingRecipe
    slots={[
        'minecraft:gold_ingot',
        'minecraft:gold_ingot',
        '',
        'minecraft:redstone',
        'minecraft:redstone',
        '',
        '',
        '',
        ''
    ]}
    result="oritech:electrum_ingot"
    count={1}
/>

[литейный завод](@oritech:foundry) может производить больше электрума с меньшим количеством материалов.
