Цветок души — растение, используемое для производства души. Вместо того, чтобы выбрасывать еду или материалы, при сборе урожая высвобождается душа.

## Выращивание

Урожай необходимо сажать на **Почве души**. Для прохождения стадий роста ему требуется уровень освещенности не ниже 9. Костную муку можно использовать для ускорения его роста.

## Сбор урожая

Когда урожай достигает финальной стадии роста и его собирают, происходит событие смерти, которое освобождает душу. Эту душу затем можно собрать любыми ближайшими блоками сбора душ, такими как [Чародейский катализатор](@oritech:arcane_catalyst) или [Контроллер спавнера](@oritech:spawner_controller).

<Callout variant="info">
    Цветы души — единственный способ генерировать души без охоты на мобов, что делает их незаменимыми для автоматических тайных установок.
</Callout>
