Вы можете проектировать свои реакторы по своему желанию. В целом, двойные или четырехстержневые стержни более эффективны в использовании топлива, поскольку они генерируют больше общего количества RF на гранулу, но их гораздо труднее охлаждать.

Вы можете использовать активное охлаждение с помощью поглотителей тепла или пассивное охлаждение с помощью только теплоотводов. Когда один поглотитель окружен активными компонентами со всех сторон, он может поглощать до 16 * 4 = 64 тепла за такт, но для работы ему требуется лед. Вы можете создать лед из воды с помощью промышленного чиллера.

Один теплоотвод может отводить тепло в зависимости от самого горячего соседнего блока. При 1000 C он будет выделять 14 тепла, а при 0 C — всего 4. В зависимости от ваших целей вы, вероятно, захотите либо распределить тепло с помощью распределителей тепла по множеству вентиляционных отверстий, либо окружить несколько поглотителей тепловыми трубками.

Конструкция реактора может быть разной. Небольшого реактора может быть достаточно для выработки электроэнергии в начале и середине игры, тогда как в поздней игре могут потребоваться массивные реакторы. При испытаниях конструкций часто рекомендуется использовать небольшие таблетки, чтобы обеспечить более быструю остановку в случае перегрева реактора.
