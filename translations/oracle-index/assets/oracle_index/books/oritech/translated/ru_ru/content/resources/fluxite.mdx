Fluxite — материал, используемый для управления потоком энергии. Это ключевой компонент современных машин и [Энергит](@oritech:energite_ingot).

Fluxite можно получить двумя основными способами:
- **Обработка аметиста**: добыча **скопления аметиста** с помощью [Эндерик Лазер](@oritech:enderic_laser).
Лазер не разрушит зарождающийся аметист. Вместо этого он ускоряет свой рост.
- **Обработка платины**: ее получают как побочный продукт во время
[платина](@oritech:platinum_ingot) цепочка переработки руды.
