Электропечь — это современная замена традиционной каменной печи. Он использует энергию RF для плавки предметов с гораздо большей скоростью и эффективностью. Электропечь работает в два раза быстрее, чем обычная печь.


Это одна из лучших машин первого качества жизни, которую можно построить после вашего первого генератора, поскольку она полностью устраняет необходимость в ручной плавке топлива.
