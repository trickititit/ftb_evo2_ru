---

Надстройка Inventory Proxy предоставляет выделенную точку доступа для внешних логистических систем для взаимодействия с внутренним хранилищем машины.

Применимо ко всем машинам со слотами для предметов.

---

**Целевой доступ**

По умолчанию машины могут открывать все свои слоты для труб и кабелепроводов. Дополнение прокси позволяет вам указать конкретный слот, который представляет этот блок. Любые элементы, вставленные в прокси-сервер или извлеченные из него, будут отправлены непосредственно в выбранный слот машины.

Это полезно для сложных сборочных линий, где необходимо изолировать определенные входные или выходные слоты.
