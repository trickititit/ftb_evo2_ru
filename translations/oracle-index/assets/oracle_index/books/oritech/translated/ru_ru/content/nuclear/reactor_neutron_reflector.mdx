title: "Нейтронный отражатель"
id: oritech:reactor_neutron_reflector
type: block
---

Отражатели нейтронов будут отражать нейтроны соседних твэлов, повышая их эффективность.

При размещении рядом с [стержень реактора](@oritech:reactor_rod) отражатель отражает нейтронные импульсы обратно в стопку стержней. Это имитирует присутствие дополнительного соседа-твэла, увеличивая как выходную мощность, так и выделение тепла затронутого стержня без потребления дополнительного топлива.

Подробную информацию о механике реактора смотрите в разделе [руководство по ядерному реактору]($reactor/introduction).
