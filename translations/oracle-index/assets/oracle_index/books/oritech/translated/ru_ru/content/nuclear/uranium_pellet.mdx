Уран и плутоний являются источниками энергии высокой плотности, используемыми для питания ядерных реакторов.

<center>
<ModAsset location="oritech:area/uranium_cave" width={700} />
</center>

**Уран** — это природная руда, добываемая глубоко под землей. Его можно перерабатывать в топливные таблетки для стандартной работы реактора.

**Плутоний** — более сильный источник топлива, получаемый путем разрушения кристаллов урана с помощью [Эндерический лазер](@oritech:enderic_laser). Его также можно создать с помощью столкновений частиц.

Сырая руда должна быть обработана через [пульверизатор](@oritech:pulverizer) и [центрифуга](@oritech:centrifuge) для создания обогащенных окатышей. Эти гранулы потребляются внутри [ядерные реакторы]($reactor/introduction) для выработки очень большого количества энергии.
