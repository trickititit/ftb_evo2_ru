Укладчик блоков помещает блоки из своего инвентаря на слой ниже [рама машины](@oritech:machine_frame).

<center>
<ModAsset location="oritech:area/block_placer" width={700} />
</center>

Его также можно использовать для посева семян на сельскохозяйственных угодьях или для высадки саженцев. Перед размещением машина проверяет, действительна ли позиция для предмета.

Эта проверка достоверности делает ее надежной для автоматизации посевов и деревьев, поскольку недопустимые цели пропускаются, а не тратятся впустую.

Если несколько россыпей используют одну и ту же раму, они обрабатывают одну и ту же рабочую зону так же, как это делают другие портальные машины.
