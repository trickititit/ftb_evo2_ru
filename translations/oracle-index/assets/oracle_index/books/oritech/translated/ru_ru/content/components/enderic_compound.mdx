Стабильное соединение, обладающее телепортационными свойствами Края.

**Ремесло**
- **Пульверизатор/измельчитель**: создается путем дробления [Эндер Жемчуг](https://minecraft.wiki/w/Ender_Pearl) или 
[Конечный камень](https://minecraft.wiki/w/End_Stone).
- **Центрифуга**: Извлечено из блоков [Скулк](https://minecraft.wiki/w/Sculk).

**Применение** Используется для технологии телепортации, усовершенствованного покрытия и ядер машин 4-го уровня.
