Удобрение используется для ускорения роста урожая ниже связанного [рама машины](@oritech:machine_frame). Для работы требуется вода и энергия.

Эффект на блоки ниже аналогичен воздействию костной муки, хотя и менее эффективен. Кроме того, он увлажняет сельскохозяйственные угодья внизу.

### Ускорение роста

Вместо воды можно использовать жидкость **Минеральная суспензия**. Это значительно увеличит силу эффекта роста. Костную муку также можно добавить в блок удобрений, чтобы повысить ее эффективность.

Эта машина предназначена для непрерывного земледелия, а не для резкого роста. Вода — это дешевая базовая жидкость, а минеральная суспензия — лучший вариант, если вам нужна гораздо более высокая производительность.

Как и другие портальные машины, несколько удобрений могут использовать одну раму и обрабатывать одно и то же поле.
