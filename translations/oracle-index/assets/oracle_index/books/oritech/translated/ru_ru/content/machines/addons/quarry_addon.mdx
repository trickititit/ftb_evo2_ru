Аддон Quarry расширяет рабочий диапазон автоматизированных раскопок.

Это применимо к:
- **[Разрушитель блоков](@oritech:destroyer)**
- **[Эндерик Лазер](@oritech:enderic_laser)**

---

**Крупномасштабная добыча**

Установка этого дополнения увеличивает рабочую зону машины, позволяя ей очищать гораздо большие зоны без перемещения. Это полезно для крупномасштабных майнинговых установок.

На блочном разрушителе глубина добычи увеличивается на 8 с каждым аддоном. На эндерическом лазере ширина луча увеличивается на +1 с каждым аддоном.
