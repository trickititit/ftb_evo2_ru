Энергетические порты используются для вывода энергии, вырабатываемой реактором.

Их необходимо разместить на внешней стенке корпуса реактора. Каждый порт может выводить до **25 000 RF/t**.

Для крупных реакторов высокой плотности, производящих тысячи RF, потребуются несколько энергетических портов, подключенных к сети [сверхпроводник](@oritech:superconductor), чтобы предотвратить узкие места в энергоснабжении.

Подробную информацию о механике реактора смотрите в разделе [руководство по ядерному реактору]($reactor/introduction).
