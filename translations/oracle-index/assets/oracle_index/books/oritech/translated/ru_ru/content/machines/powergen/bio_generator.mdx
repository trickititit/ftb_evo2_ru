Преобразует [биомасса](@oritech:biomass) и другие биологические материалы в энергию. Хороший способ переработки органических отходов с ваших ферм.

Базовая скорость генерации составляет 128 RF/t.
## Использование

Скармливайте ему топливо, полученное из биомассы, и другие биологические материалы, принятые программой просмотра рецептов. Это многоблочная машина, для работы которой требуется [машинные ядра]($multiblocks).

Это один из самых простых генераторов для автоматизации, если у вас уже есть лесные фермы, растениеводческие фермы или другие системы, производящие устойчивые органические отходы. Поскольку он поддерживает дополнения, он может оставаться полезным даже после прекращения использования базового генератора.

<Callout variant="warning">
    Поддерживайте постоянный запас биомассы, чтобы он работал непрерывно.
</Callout>
