Тонкий кусочек очищенного кремния, используемый в качестве основы для микропроцессоров.

**Ремесло**
- **Атомный Forge**: создан из [Пряди углеродного волокна](@oritech:carbon_fibre_strands) и [Кремний](@oritech:silicon).
- **Центрифуга**: Обработка от [Пряди углеродного волокна](@oritech:carbon_fibre_strands) и 
[Силиконовая промывка](@oritech:still_silicon_wash).

**Применение** Используется в передовых вычислениях и схемах искусственного интеллекта.
