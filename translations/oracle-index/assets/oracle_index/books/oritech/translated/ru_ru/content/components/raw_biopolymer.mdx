Органический предшественник промышленных пластмасс, изготовленный из биологического вещества.

**Ремесло**
- **Центрифуга**: Извлечено из [Упакованная пшеница](@oritech:packed_wheat), [Твердое биотопливо](@oritech:solid_biofuel), 
или блоки биомассы с использованием воды.

**Применение** Используется в качестве основы для пластмасс, специальных жидкостей и биологических добавок.
