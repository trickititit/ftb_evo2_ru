# Русификатор FTB Evolution 2 — r4, без Chisel

Неофициальный перевод для **FTB Evolution 2 1.4.0** (pack 135 / version 100566), **Minecraft 26.1.2**, **NeoForge 26.1.2.121**. Другие версии установщик отклоняет. Сама сборка и моды в комплект не входят.

FTB Quests: 4178 исходных языковых записей в 51 файле. Ресурс-пак: 45 437 записей, 894 файла Patchouli, 748 страниц GuideME и 197 страниц Oracle Index. В r4 добавлены 75 страниц Nodeworks и руководства AE2 с дополнениями, Auroral и Industrial Contraptions. Дополнительно локализованы 135 буквальных строк Modonomicon из Neo Vitae, Occultism и Witchery, а также 61 страница вики Stellaris. Ресурсы Chisel исключены.

Большая часть новых текстов подготовлена автоматическим переводом с выборочными ручными правками. Вводная статья, обзор и часть справки API Nodeworks вычитаны вручную. **Сплошная литературная редактура не выполнялась**, возможны ошибки терминологии. Полный охват файлов не означает ручную проверку каждой формулировки.

## Клиент и Prism Launcher

1. Закройте Minecraft. Скачайте и распакуйте комплект **FTB-Evolution-2-1.4.0-RU-r4-Client.zip** в отдельную папку.
2. Запустите `Install.cmd`. Выберите папку экземпляра Prism Launcher или его папку `minecraft`/`.minecraft`, содержащую `config` и `mods`.
3. Запустите игру, выберите **Русский (Россия)**, включите ресурс-пак **FTB-Evolution-2-Russian-1.4.0.zip** и поставьте его выше остальных паков. Имя ZIP сохранено для обновлений.

Установочный ZIP нужно распаковать; ZIP ресурс-пака в папке `resourcepacks` распаковывать не нужно. Установщик не меняет язык игры, `options.txt`, список включённых паков и адреса серверов. В GuideME должна быть выключена настройка игнорирования переведённых руководств, если вы включали её вручную.

Для одиночной игры достаточно клиентской части. На выделенном сервере таблицы FTB Quests и страницы Stellaris приходят с сервера: для них установите также серверную часть. Для Nodeworks, AE2 и других новых страниц GuideME достаточно обновления клиента.

## Выделенный сервер

1. Штатно остановите сервер FTB Evolution 2.
2. Распакуйте **FTB-Evolution-2-1.4.0-RU-r4-Server.zip** в отдельную папку, запустите `Install.cmd` и укажите корень сервера с `config`, `mods` и `.manifest.json`.
3. Запустите сервер. Игрокам также нужна клиентская часть и русский язык.

Серверный комплект содержит таблицы FTB Quests и текстовый патч Stellaris в `kubejs/data/stellaris/wiki/infos`. Формат Stellaris не выбирает язык страниц для каждого игрока: **на сервере с этим патчем вики Stellaris будет русской у всех**. Обновите сервер до r4 для нового перевода Stellaris. Руководства Nodeworks не требуют серверного патча.

Клиентская часть содержит тот же патч Stellaris для встроенного сервера одиночной игры. Текстовые патчи не меняют рецепты, характеристики предметов, миры, прогресс, условия и награды заданий или игровую механику. JAR модов не изменяются.

## Обновление и резервные копии

Поддерживаются обновления r1/r2/r3 → r4 без предварительного удаления. Повторная установка r4 безопасна: сначала проверяются файлы, первоначальные резервные копии сохраняются. Изменённые пользователем переводы не перезаписываются молча.

Резервные копии и состояние установки находятся в `.ftb-evolution-ru` выбранной папки игры/сервера. Не удаляйте её до отката. Проверяются версия сборки, версии исходных файлов, таблицы заданий и контрольные суммы содержимого комплекта. Нельзя подменять `state.json` состоянием от другой установки.

Нужны Windows PowerShell 5.1 и обычные права записи в выбранную папку. Права администратора и Python не нужны. `Install.cmd` задаёт `ExecutionPolicy Bypass` только для своего процесса, системная политика не меняется.

Проверка без установки:

```powershell
& .\Install.ps1 -Target 'D:\Prism\instances\FTB Evolution 2' -Action Verify
```

## Удаление и откат

На клиенте выключите ресурс-пак, закройте игру; на сервере штатно остановите процесс. Запустите `Rollback.cmd` из комплекта r4 и выберите ту же папку.

**После обновления с ранних выпусков откат восстанавливает состояние до первой установки русификатора**, а не предыдущий выпуск. Изначально отсутствовавшие файлы удаляются, существовавшие восстанавливаются побайтно. Повторный откат безопасен, резервные копии остаются. После успешного отката их можно удалить вручную, если они больше не нужны.

Если вы изменили установленные файлы или повредили резервную копию, откат остановится до восстановления файлов. Сохраните свои правки отдельно; для восстановления установленной версии используйте соответствующий файл из `payload` этого комплекта. Прерванную установку также можно откатить.

## Проверка перевода

После перезапуска откройте руководство Nodeworks: названия разделов, вводная статья и описания должны быть русскими. Проверьте также руководство AE2, страницы Oracle Index по Alt и несколько описаний заданий. В сетевой игре проверьте FTB Quests и вики Stellaris после перезапуска сервера.

Проверены структура файлов, ссылки, код, плейсхолдеры, установка, повторная установка и откат на временных копиях. Изолированный сервер r4 с тестовым миром достиг `Done` и штатно остановился. **Клиентское отображение и подключение игрока не проверялись.** Подробности приведены в `REPORT-RU.md`.

На исходном языке остаются код и комментарии в примерах Lua/JavaScript, встроенные справочные файлы терминала ComputerCraft, внешние сайты документации, текст внутри изображений и жёстко заданные строки без механизма локализации. Команды, имена API, ссылки, идентификаторы, переменные и имена собственные сохраняются намеренно.
