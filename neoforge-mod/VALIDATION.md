# Проверки мода локализации 1.0.0

Сборка: официальный NeoForge ModDevGradle 2.0.148, JDK 25, NeoForge 26.1.2.121. Проверены реальные FTB Quests / FTB Library 26.1.2.9. Репозиторий FTB в этой среде отвечал тайм-аутами; успешная сборка выполнена с `-PmodpackDir`, используя уже установленные JAR только для компиляции. Зависимости не включены в мод.

Все 4178 исходных записей проверены на реальных классах FTB Quests: строки, массивы описаний, английский язык, изменение исходника, обновление кэша и приоритет пользовательского русского текста. Проверены синтаксис ресурсов, метаданные, версии Java, контрольные суммы, отсутствие чужих классов и вложенных JAR. Клиентские ресурсы побайтно совпадают с r4.

На изолированном сервере удалены старые русские таблицы и KubeJS-патч Stellaris. Установлен только новый JAR. Сервер достиг Done и штатно остановлен, код 0. Проверочный сценарий подтвердил русский заголовок, русское многострочное описание, неизменный английский текст, защиту изменённых исходников и русских правок, а также русскую страницу Stellaris. Через API NeoForge проверены регистрация обязательного клиентского пакета с позицией TOP и доступность в нём руководства Nodeworks. Эта проверка API выполнена на сервере, она не равнозначна запуску клиента.

После удаления JAR сервер снова достиг Done: вернулись исходные заголовок, описание и английская страница Stellaris, следов установки переводов в config/kubejs нет. При подмене версии сборки на 0.0.0 мод отказался загружаться с сообщением о требуемой FTB Evolution 2 1.4.0.

Содержимое конфигураций заданий до и после запусков семантически одинаково. Штатный FTB Quests при сохранении переставил порядок ключей в объектах зачарований двух файлов; это не изменение условий, наград или параметров заданий. Мод перехватывает только чтение переводов и не содержит кода записи конфигураций.

Существующие ошибки Architectury-интеграции KubeJS, отсутствующих тегов Replication и сторонних проверок обновлений встречались также без мода локализации; они не исправлялись изменением механик.

**Графический клиент и подключение игрока не проверялись.** Не заявляется проверка отображения всех экранов. Основная часть текстов r4 подготовлена автоматическим переводом с выборочной редактурой; сплошная ручная вычитка не выполнена. На CurseForge ничего не загружено автоматически. Лицензии и необходимые разрешения на исходные тексты нужно проверить до отправки на модерацию.
