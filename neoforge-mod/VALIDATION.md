# Проверки русификатора 1.5.0 для FTB Evolution 2 1.9.0

Дата: 13 ноября 2026. Minecraft 26.1.2, NeoForge 26.1.2.126, Java 25, FTB Quests 26.1.2.10 / Library 26.1.2.12, Stellaris 2.0.10.
SHA-256 основного JAR: `d6b8e2924448e54afd20be13f17754c19301dcc98cb999227ce7d96b1ed9108c`.

## Перевод

Проверены пользовательский ZIP и официальный FTB-манифест pack 135 / version 100614. Все 431 JAR сверены по SHA-256: 393 переиспользованы из предыдущего выпуска, 35 загружены, 3 получены из overrides архива.

Все **4 391 запись FTB Quests** имеют актуальные отпечатки исходников. Вручную переведены **203 новые записи**: главы Bumblezone, ForceCraft и Сумеречного леса. Две интерактивные JSON-композиции проверены отдельно: меняется только отображаемый текст, а keybind, click/hover actions, ID заданий и payload сохраняются.

Обработаны 797 языковых строк и одна буквальная строка Modonomicon. Вручную исправлены 414 записей: названия ForceCraft, цветовые варианты, римские уровни, все 25 описаний улучшений, новые описания NeoVitae и руководство по выражениям Integrated Dynamics. Проверено наличие перевода для всех 985 новых/изменённых английских ключей; часть использует встроенный русский перевод. Шесть совпадающих значений — технические форматы, URL и имя ForceCraft — не считаются русским переводом.

Итого **47,684 языковых записей**, 894 файла Patchouli, 760 страниц GuideME, 197 страниц Oracle Index, 25 файлов меню и 61 страница Stellaris. Добавлены/обновлены 5 страниц GuideME (HorsePowered, LTxi, Nautec), 4 страницы Oracle Index и одно меню. Изменившиеся страницы GuideME вычитаны выборочно, сохранены ссылки, код, идентификаторы, числа и клавиши. Chisel исключён.

## Структура и установка

- **89,799 структурных проверок**: JSON, ключи, SHA исходников, плейсхолдеры, форматирование, ссылки, примеры кода, директивы вики, CRC и безопасные пути ZIP/JAR, совпадение ресурсов артефакта с исходниками. 1072 совпадающих с английским технических значений/имён во всём дополнении учитываются отдельно.
- Сборка Gradle/JDK 25 против точных версий Quests/Library из 1.9.0 успешна. В JAR только собственные классы Java 25 и ресурсы; нет вложенных модов, установщиков, миров и игровых данных, кроме страниц вики Stellaris.
- На настоящих классах FTB Quests проверены все 4391 записи, защита от изменения английского источника, приоритет пользовательского русского текста и сброс кеша.
- **140 проверок Windows PowerShell 5.1** на временных папках: Prism и сервер, Verify/Install/reinstall/Rollback, повторный и прерванный откат, повреждённые файлы/резервные копии, неверная сборка/Minecraft/NeoForge, пользовательский перевод и выход пути за корень.
- Проверены прямые обновления с модов 1.1.0, 1.2.0, 1.2.1, 1.3.0 и 1.4.0, а также полная цепочка r4 → все промежуточные моды → 1.5.0 → последовательный откат. Старые JAR, файлы и состояния восстановлены побайтно. Контрольный файл мира сохранён.

## Нативный запуск сервера

- Временная копия сборки 1.9.0 с NeoForge 26.1.2.126 достигла `Done`, выполнила интеграционные проверки и штатно остановилась с кодом 0 (324 с).
- В настоящем FTB Quests получены русский заголовок и полное новое описание «Заряжено силой», включая JSON-подсказку клавиши. Английский источник остался английским; пользовательский перевод и изменённый источник защищены.
- Через API NeoForge зарегистрирован обязательный ресурс-пак TOP, через PackResources прочитано русское руководство Nodeworks. Это проверка API, не графического клиента.
- Stellaris загрузил русские страницы синей жидкости и консервов (100 mB). Отдельных RU-таблиц в config и KubeJS-патча вики не было.
- После удаления JAR сервер достиг `Done`, вернул английские задания/вики и штатно завершился с кодом 0 (211 с). Перевод не записался в config/KubeJS.
- Заведомо несовместимая сборка отклонена до запуска с сообщением о необходимости версии 1.9.0.

## Ограничения

Клиентская отрисовка и подключение игрока **не проверялись**. Значительная часть унаследованного перевода автоматическая с выборочной редактурой; полной литературной вычитки нет. На английском остаются примеры и комментарии кода, терминальная справка ComputerCraft, внешняя документация, изображения, оригинальные названия музыкальных композиций/авторов и некоторые строки без механизма локализации. Chisel исключён.

FTB Quests сам сериализует файлы при запуске. При первом запуске в новой главе ForceCraft отсутствующее поле `quest_links` сохранилось как пустой массив `[]`; поэтому строгий флаг неизменности JSON в отчёте равен false. Отдельная проверка всех файлов подтвердила, что это единственное различие значений, остальные правки — форматирование. После удаления мода значения больше не менялись. Установщик не меняет определения заданий, прогресс, миры, баланс и настройки игроков.

Предупреждения сторонних модов присутствуют и без русификатора. Загрузка и остановка проверены; механика исходной сборки не исправлялась. Рабочие клиент и сервер не изменялись. Тестовые миры, игровые логи и персональные файлы не распространяются.
