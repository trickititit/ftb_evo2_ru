# <Color id="gold">НауТек 2</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="aquatic_catalyst" scale="2"/>
  Океанский технологический мод, работающий на лазерных лучах.
</Column>

Машины NauTec работают на энергии лазера (AP), излучаемого из одного блока в другой. В этом руководстве рассказывается о изготовлении и прокладке балок, машинах, которые их используют, разведении бактерий для получения ресурсов, установке дополнений к вашему телу и подводном аппарате Морской разведчик.

Впервые в моде? Прочтите [Введение](getting_started/introduction.md), затем [Мощность лазера](getting_started/laser_power.md), чтобы запустить первый луч.
