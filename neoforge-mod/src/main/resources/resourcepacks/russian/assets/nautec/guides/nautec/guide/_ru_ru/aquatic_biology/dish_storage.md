# <Color id="light_purple">Хранилище для посуды</Color>

Шкаф для чашек Петри. У каждого блюда есть свой слот, поэтому колонии разных штаммов, размеров и характеристик никогда не перепутаются.

| Блокировать | Блюда |
|---|---|
| Хранение посуды для аквариумов | 48 |
| Глубокое хранение стальной посуды | 96 |
| Хранение Атлантической золотой посуды | 192 |

Каждый уровень создается на основе предыдущего, и в него входят только чашки Петри, пустые или полные.

Щелкните его правой кнопкой мыши, чтобы открыть. На экране одновременно отображается 48 блюд: прокрутите колесо мыши или перетащите полосу справа, чтобы увидеть остальные. Shift — щелчок по блюду из инвентаря помещает его в первый свободный слот, даже тот, который прокручен вне поля зрения. Счетчик в углу показывает, сколько посуды он вмещает.

Хопперы, трубы и [Наутехнический дистрибьютор](nautec:getting_started/distributor.md) позволяют загружать и вынимать посуду через любое отверстие. Компаратор рядом с ним подает сигнал о том, насколько он заполнен.

Если его сломать, выпадет все блюдо, которое оно держит.
