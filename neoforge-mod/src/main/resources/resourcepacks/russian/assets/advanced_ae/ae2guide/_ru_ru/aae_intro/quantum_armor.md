Вы когда-нибудь задумывались, каково это — носить систему AE? Что ж, вам больше не придется задаваться вопросом. Комплект квантовой брони — это высокотехнологичная скрытная одежда, которая подключается к системе AE2, обеспечивая удобный доступ ко всему, что вам нужно в пути! По умолчанию это костюм с энергетическим питанием, защита которого сравнима с незеритовым снаряжением. Он способен использовать свой буфер для создания энергетического щита, обеспечивая значительное поглощение урона. Ботинки также обеспечивают отрицание урона от падения, а нагрудник может устранить штрафы за минирование в полете. Однако истинная сила этого костюма откроется только тогда, когда вы наполните его улучшениями!

<br/>

## <a name="linking-the-armor" />Соединение брони

Части брони можно индивидуально связать с системой, вставив их в соответствующие слоты в
<ItemLink id="ae2:wireless_access_point" />. Это открывает различные перки в зависимости от предмета снаряжения и установленного обновления.
карты. Подробнее об этом позже. Обратите внимание: для правильной работы этих дополнительных функций вам также необходимо находиться в зоне действия подключенной точки доступа.

<br/>

## <a name="installing-upgrades" />Установка обновлений

Чтобы установить обновления, вам необходимо экипировать эти части, а затем открыть меню конфигурации квантовой брони, нажав горячую клавишу (по умолчанию N).

![КАГУИ](../pic/quantum_armor_config.png)

На этом экране вы сможете добавлять/удалять обновления, а также включать/выключать их и настраивать параметры обновлений, в которых они есть.

<br/>

## <a name="quantum-upgrade-base-card" />Базовая карта квантового улучшения

<ItemImage id="advanced_ae:quantum_upgrade_base" scale="2"></ItemImage>

<ItemLink id="advanced_ae:quantum_upgrade_base" /> сам по себе не делает ничего особенного, но используется в качестве ингредиента для изготовления всех карт улучшений.

<br/>

## <a name="auto-feeding-card" />Карта автоматической подачи

<ItemImage id="advanced_ae:auto_feeding_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:auto_feeding_card" /> позволяет выбирать определенные предметы, которые будут использоваться для кормления игрока. Просто перетащите нужные предметы в слоты фильтра, и если снаряжение привязано к сетке AE2, оно попытается найти их в системе, чтобы накормить игрока, когда он голоден.

<br/>

## <a name="auto-stock-card" />Авто фондовая карта

<ItemImage id="advanced_ae:auto_stock_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:auto_stock_card" /> также требует, чтобы часть оборудования была связана с системой AE2 и имела соответствующий радиус действия до точки доступа. Это позволяет всегда сохранять конфигурацию нескольких стеков в определенных количествах в инвентаре пользователя. Слоты не ограничены стеком, поэтому вы можете настроить их так, чтобы в инвентаре всегда было заполнено более одного слота, если вы того пожелаете.

<br/>

## <a name="flight-cards" />Карты полетов

<Row gap="10">
<ItemImage id="advanced_ae:flight_card" scale="2"></ItemImage>
<ItemImage id="advanced_ae:flight_drift_card" scale="2"></ItemImage>

### <a name="flight-card" />Карта полета

При установке <ItemLink id="advanced_ae:flight_card" /> обеспечивает творческий полет. Скорость полета можно настроить с помощью ползунка в пользовательском интерфейсе. На это также влияет аддитивное повышение скорости ходьбы/спринта.

### <a name="flight-drift-card" />Карта дрейфа полета

<ItemLink id="advanced_ae:flight_drift_card" /> работает только тогда, когда установлена карта полета, и добавляет еще один ползунок конфигурации для изменения инерции, влияющей на творческий полет. Более низкие значения заставляют вас останавливаться быстрее, останавливаясь мгновенно, когда значение установлено на 0.

<br/>

## <a name="me-recharging-card" />Карта пополнения ME

<ItemImage id="advanced_ae:recharging_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:recharging_card" /> обеспечивает беспроводную подзарядку установленного устройства. Для этого требуется подключение к сети и нахождение в зоне действия точки доступа. Установка этого улучшения в нагрудник дает дополнительное преимущество, поскольку также заряжает слоты инвентаря.

<br/>

## <a name="portable-workbench-card" />Портативная карта верстака

<ItemImage id="advanced_ae:portable_workbench_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:portable_workbench_card" /> добавляет к квантовому костюму переносной клеточный верстак. Чтобы его открыть, нужно нажать настроенную горячую клавишу. Это работает так же, как и форма блока.

<br/>

## <a name="pick-craft-card" />Выберите карту ремесла

<ItemImage id="advanced_ae:pick_craft_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:pick_craft_card" /> добавляет к броне новую функцию горячих клавиш. Нажатие на нее попытается создать блок, на который в данный момент нацелен игрок. Для этой функции требуется ссылка на сетку и шаблон, соответствующий цели. Появится всплывающее окно с запросом желаемой суммы, и процесс будет точно таким же, как и при обычном запросе на автоматическое создание.
