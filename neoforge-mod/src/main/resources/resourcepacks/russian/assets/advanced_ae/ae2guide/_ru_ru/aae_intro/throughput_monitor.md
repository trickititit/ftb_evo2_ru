# <a name="me-throughput-monitor" />Монитор пропускной способности ME

<GameScene zoom="8" background="transparent">
<ImportStructure src="../structure/throughput_monitors.snbt"></ImportStructure>
<IsometricCamera yaw="195" pitch="30" />
</GameScene>

Мониторы пропускной способности — это подтип мониторов. Они предоставляют те же функции, что и <ItemLink id="ae2:storage_monitor" />, но с добавлением измерителя пропускной способности. Я буду отслеживать один предмет/тип жидкости и следить за его количеством, отображая пользователю количество в секунду.

Для этого *не* требуется канал.

## <a name="keybinds" />Сочетания клавиш

*   Щелкните правой кнопкой мыши элемент или дважды щелкните правой кнопкой мыши контейнер с жидкостью, чтобы настроить монитор на этот элемент/жидкость.
*   Щелкните правой кнопкой мыши пустой рукой, чтобы очистить монитор.
*   Shift — щелкните правой кнопкой мыши пустой рукой, чтобы заблокировать монитор.

## <a name="throughput-monitor-configurator" />Конфигуратор монитора пропускной способности

<ItemImage id="advanced_ae:throughput_monitor_configurator" scale="4"></ItemImage>

Конфигуратор монитора пропускной способности — это инструмент, который можно использовать для изменения представленных данных. Щелчок правой кнопкой мыши по монитору с одним из них в руке переключает три варианта:

* Предметов за тик
* Предметов в секунду
* Предметов в минуту

Примечание. При смене режимов может пройти некоторое время, прежде чем показания стабилизируются, поэтому не доверяйте первоначальным значениям!
