# <a name="advanced-ae!" />Продвинутый АЭ!

Advanced AE направлен на улучшение пользовательского опыта при работе с вашей ME-системой и расширение возможностей конечных игровых систем. Этот мод позволяет вам модернизировать поставщиков шаблонов, чтобы они могли перемещать предметы по определенным сторонам целевых машин и создавать многоблочные компьютеры, которые могут выполнять неограниченное количество ремесел, используя общие сопроцессоры, пока у них осталось хранилище для крафта, а также массу других дополнений, улучшающих качество жизни!
