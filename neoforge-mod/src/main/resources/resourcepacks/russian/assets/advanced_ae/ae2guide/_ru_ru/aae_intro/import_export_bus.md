# <a name="import-export-bus" />Импорт-экспортный автобус

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_import_export_bus.snbt"></ImportStructure>
</GameScene>

Автобус «Импорт-экспорт» представляет собой смесь <ItemLink id="ae2:import_bus" /> и <ItemLink id="ae2:export_bus" />. Фильтр можно настроить для настройки экспортируемых стеков. Все, чего нет в фильтре, является допустимым стеком для импорта.
