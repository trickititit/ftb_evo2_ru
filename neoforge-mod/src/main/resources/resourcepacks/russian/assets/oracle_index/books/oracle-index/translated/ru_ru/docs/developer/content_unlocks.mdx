---
title: "Система развития контента"
---

Индекс Oracle также имеет функцию, при которой контент необходимо разблокировать, прежде чем игрок сможет получить к нему доступ. Заблокированные страницы представлены в запутанном виде и не отображаются в поиске. Если все записи в папке заблокированы, вся папка будет скрыта.

<Callout variant="warning">
    Эта функция, очевидно, доступна только во внутриигровой вики, а не в онлайн-вики. Основная целевая аудитория здесь — производители модпаков, которые не хотят раскрывать все сразу.
</Callout>

Чтобы контролировать разблокировку, в заголовке страницы должен быть раздел *unlock*. Это может выглядеть следующим образом:

```
---
title: Ingame Mod View Setup
unlock: advancement:minecraft:oritech/pulverizer
---
"unlock" is always the same
"advancement" is the name of the progress validator
anything after the "advancement:" part is passed to the validator
```

# Валидаторы
Моддеры могут зарегистрировать собственный валидатор в **Oracle Progress API**. Для получения более подробной информации обратитесь к javadocs класса API.

Индекс Oracle не хранит, какие записи были разблокированы, и просто вызывает валидаторы по требованию.

## Валидатор продвижения
По умолчанию в мод включен только один валидатор: валидатор продвижения. Он проверяет, выполнил ли игрок определенное продвижение для просмотра страницы.
