Energite — это высококачественный сплав, используемый для создания передовых компонентов и машин, связанных с энергетикой. Он используется для хранения энергии высокой емкости и усовершенствованного распределения энергии.

Энергит можно создать в [литейный завод](@oritech:foundry) путем сплавления [никель](@oritech:nickel_ingot) и [флюсит](@oritech:fluxite).
