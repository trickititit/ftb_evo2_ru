---
title: "Поиск"
---

Oracle Index имеет функцию интеллектуального поиска. Чтобы открыть окно поиска, нажмите [CTRL + ORACLE_HOTKEY] или горячую клавишу поиска (по умолчанию она не привязана). При просмотре записи в вики также есть небольшой значок поиска.

<Callout variant="info">
    Поиск также поддерживает математические вычисления/выражения!
</Callout>

При первом открытии экрана поиска индексация доступных страниц может занять несколько секунд, прежде чем вы сможете выполнить поиск. Поиск представляет собой полноценный семантический поиск, основанный на машинном обучении. Это означает, что вам не нужно искать по точным ключевым словам, вы можете вводить полные предложения, и соответствующий контент будет показан, даже если слова не совпадают точно. Будут показаны любые соответствующие темы.

## Технические детали
Под капотом Oracle Index генерирует вложения для всех страниц, которые предварительно обрабатываются на фрагменты. Модель преобразователя небольших предложений (all-MiniLm-L6-V2-q) затем генерирует вложения для каждого фрагмента и для поискового запроса. Векторы внедрения хранятся в памяти. Затем вектор внедрения поискового запроса сравнивается с внедрениями фрагментов вики. Затем пользователю отображаются N ближайших результатов.

Для этого используется библиотека Langchain4j, использующая DJL Framework. Размер встраиваемой модели составляет около 15 МБ.

## Пределы

Поиск индексирует текст страницы на базовом языке и в настоящее время не создает отдельный семантический индекс для переведенного текста. При выборе результата по-прежнему открывается переведенная страница, если она доступна, а в заголовках результатов используется активный язык.

Модель внедрения и собственная среда выполнения увеличивают размер артефакта с поддержкой поиска. Если установленный артефакт платформы не включает эту среду выполнения, Oracle Index сообщает, что поиск недоступен, и вместо этого указывает на кроссплатформенный артефакт. Обычный просмотр вики не зависит от семантического поиска.
