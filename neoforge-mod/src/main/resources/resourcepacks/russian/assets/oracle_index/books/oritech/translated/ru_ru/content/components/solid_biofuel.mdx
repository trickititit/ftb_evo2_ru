Прессованный топливный брикет, изготовленный из биомассы.

**Ремесло**
- **Ассемблер**: сжато из 3 [Биомасса](@oritech:biomass) и Planks.

**Применение** Используется в качестве эффективного источника топлива для биореакторов и химической обработки.
