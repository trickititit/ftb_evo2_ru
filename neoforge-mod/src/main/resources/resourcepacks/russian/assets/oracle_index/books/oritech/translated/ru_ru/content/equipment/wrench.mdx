Трубный ключ – основной инструмент управления заводской логистикой. Работает со всеми типами труб и кабелей в моде.

### Трубы

Гаечный ключ поможет вам настроить трубопроводные сети:
- **Переключение**. Нажмите на конец трубы, где она соединяется с чем-то другим, чтобы включить или отключить это соединение.
- **Быстрый подбор**: Shift + Щелкните правой кнопкой мыши по трубе, чтобы мгновенно ее поднять.

Вы можете использовать гаечный ключ, чтобы затянуть **тросы** на провода между [столбы электропередач](@oritech:energy_transmission_pole). Просто щелкните правой кнопкой мыши по проводу, чтобы быстро переместиться на другую сторону.

Зиплайнинг – это быстрый способ передвижения без затрат энергии.
