---
title: "Мультиблоки"
icon: oritech:item/machine_core_6
---

Некоторым машинам для работы требуются дополнительные ядра машины. Они должны быть размещены в определенных местах относительно самой машины. Количество ядер, необходимое для машины, указано во всплывающей подсказке машины. Ядра не могут быть разделены между машинами.

<Callout variant="info">
    Лучшие ядра не заставляют машины работать быстрее. Они влияют только на то, сколько слоев расширителей машины вы можете добавить.
</Callout>

Чтобы начать сборку мультиблока, сначала положите саму машину.

При щелчке правой кнопкой мыши по машине все блоки, которые должны быть ядрами, будут подсвечены на несколько секунд. Затем вы можете поместить туда ядра. Альтернативно, вы можете щелкнуть правой кнопкой мыши по машине с ядром в руке, чтобы автоматически разместить следующее ядро. Обратите внимание, что это работает только в том случае, если целевые местоположения беспрепятственны. Если есть препятствие, вместо него будет подсвечен блок.

Каждое ядро машины имеет связанное с ним качество. Использование более совершенных сердечников повышает общее качество машины.

Чтобы просмотреть итоговое качество машины, наведите указатель мыши на значок машины в левом верхнем углу пользовательского интерфейса. Качество машины само по себе не влияет напрямую на работу машины. Вместо этого он определяет, сколько аддонов можно добавить на машину. Если вы не планируете добавлять в машину аддоны, можно использовать самые дешевые ядра.
