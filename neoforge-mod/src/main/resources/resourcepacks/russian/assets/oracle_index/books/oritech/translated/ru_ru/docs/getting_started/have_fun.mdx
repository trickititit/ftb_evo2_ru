На этом этапе у вас есть основные части, необходимые для разветвления.

Следующие хорошие направления включают в себя:
- Создание более чистой логистики и энергетических сетей.
- Расширение портальной автоматизации и ферм на базе станков.
- Инвестирование в [мультиблоки]($MULTIBLOCKS) и [дополнения]($ADDON_CONCEPTS).
- Нажимаем на [ядерные реакторы]($NUCLEAR_REACTOR) или [ускоритель частиц]($PARTICLE_ACCELERATOR).
- Начинайте исследования в области кибернетических дополнений, как только ваш поток ресурсов стабилизируется.

Изучите остальную часть руководства, выберите направление и начните специализировать свою фабрику.
