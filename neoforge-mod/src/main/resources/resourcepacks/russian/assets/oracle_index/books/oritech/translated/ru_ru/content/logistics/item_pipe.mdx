Oritech включает каналы товаров и блоки фильтров товаров для логистики товаров. Трубы предметов соединяются друг с другом и с соседними инвентарями.

В отличие от других трубок, у трубок предметов нет инвентаря. Это означает, что другие блоки, например бункеры, не могут самостоятельно вставлять элементы в трубопроводную сеть. Вместо этого можно настроить трубу для извлечения предметов из ближайшего инвентаря.

## Варианты
*   **Стандарт**: Базовая труба
*   **В рамке**: полноблочная версия.
*   **Прозрачный**: отображает движущиеся внутри предметы. Работает только в том случае, если весь путь трубы состоит из прозрачных труб.
*   **Воздуховод**: альтернативный эстетический стиль. Канальные варианты не подключаются к машинам напрямую, а только к другим трубам.

Чтобы переключить режим извлечения, щелкните правой кнопкой мыши участок трубы, соединенный с блоком, из которого вы хотите извлечь. Извлечение будет разрешено только в том случае, если труба подключена к блоку, поддерживающему извлечение. Каждое соединение труб можно переключать независимо. Используйте трубный ключ, чтобы отключить соединения в определенных направлениях.

Извлеченные предметы помещаются в **ближайший** доступный инвентарь дальше по сети, в зависимости от расстояния до мира.
