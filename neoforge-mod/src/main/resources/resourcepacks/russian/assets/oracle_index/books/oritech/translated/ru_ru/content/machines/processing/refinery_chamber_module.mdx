Модули камер нефтеперерабатывающего завода — это компоненты расширения для [Промышленный нефтеперерабатывающий завод](@oritech:refinery). До двух модулей можно установить поверх одного нефтеперерабатывающего блока, чтобы обеспечить дополнительные каналы вывода жидкости.

---

**Управление несколькими выходами**

Каждый модуль действует как специальный резервуар для вторичных и третичных жидких продуктов процесса нефтепереработки. Жидкости необходимо добывать непосредственно из блоков модулей, а не на основной базе нефтеперерабатывающего завода. Этим модулям также требуется собственный [машинные ядра]($multiblocks), чтобы быть частью мультиблочной сборки.
