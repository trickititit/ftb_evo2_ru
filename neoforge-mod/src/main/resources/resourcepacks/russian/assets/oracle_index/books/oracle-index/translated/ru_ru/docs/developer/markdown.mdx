---
title: "Справочник по Markdown и MDX"
---

Oracle Index отображает практическое подмножество синтаксиса, поддерживаемого ModdedMC Wiki. Одну и ту же страницу можно использовать онлайн и в игре, если ее внутриигровое представление соответствует указанным ниже функциям.

## Стандартная уценка

Поддерживаемая Markdown включает в себя:

- заголовки
- абзацы и разрывы строк
- **жирный**, *курсив* и `inline code`
- упорядоченные и неупорядоченные списки, включая вложенные списки
- относительный, идентификатор контента, ссылка на страницу, стандартный элемент и веб-ссылки
- изолированные блоки кода с дополнительным языком и именем файла
- блок кавычек
- Таблицы в стиле GitHub
- изображения с замещающим текстом и атрибутами размера.

Внутриигровой рендерер не выполняет произвольный HTML, JSX, JavaScript или CSS. Неподдерживаемые блоки HTML и пользовательские компоненты игнорируются, а не отображаются в виде текста.

## Ссылки

Обычные относительные ссылки разрешаются с текущей страницы. Oracle Index также понимает следующие формы вики-ссылок:

```md
[Relative page](../machines/generator)
[](@minecraft:diamond_pickaxe)
[](+custom_page_ref)
[]($getting_started)
[Website](https://example.com)
```

`@namespace:id` открывает страницу содержимого, проиндексированную для этого идентификатора реестра. `+ref` использует значение `ref` заголовка страницы контента. `$slug` нацелен на страницу документации. В пустых метках ссылок используется заголовок целевой страницы или переведенное имя элемента, где это применимо.

Ссылки на привязки заголовков в настоящее время не поддерживаются в игре. Блок атрибутов завершающего заголовка скрыт от отображаемого заголовка для совместимости, но идентификаторы и атрибуты, такие как `{#details}` или `{clear}`, не влияют на макет и не предоставляют цель прокрутки.

## Изображения и ресурсы

Поддерживаются изображения Markdown, простые HTML-элементы `<img>` и псевдонимы `<Asset>`/`<ModAsset>`:

```md
![](@example:machine_layout)
![Machine layout](@example:machine_layout){center width=160}
![Small icon](@example:icon){item}
<img src="@example:machine_layout" width="160" />
<Asset location="example:machine_layout.png" width="50%" />
```

По умолчанию изображения центрируются. `{left}` выбирает выравнивание по левому краю. `{center}` явно центрируется. `{right}` принимается для совместимости, но Oracle Index не может размещать контент рядом с текстом и, следовательно, центрировать его в игре. Атрибуты ширины и высоты используют пиксели экрана; процентная ширина использует доступную ширину контента. Изображения ограничены доступной шириной.

Атрибут `{item}` всегда отображается в размере 32×32 и предназначен для значков в стиле элементов. Идентификаторы элементов реестра, такие как `@minecraft:diamond`, используют фактическую модель предмета в игре. Автономные изображения Markdown с замещающим текстом показывают этот текст в виде подписи.

Ресурсы схемы 1 загружаются из `assets/<namespace>/` внутри вики. Расширения файлов по умолчанию равны `.png` для изображений и `.ogg` для аудио. В устаревших вики используется `.assets/<namespace>/`.

## Оповещения и уточнения

Оповещения в стиле GitHub поддерживают `NOTE`, `TIP`, `IMPORTANT`, `WARNING` и `CAUTION`:

```md
> [!TIP] Optional custom title
> Helpful content.

> [!WARNING]+
> Expanded by default and collapsible.

> [!CAUTION]- At your own risk
> Collapsed by default and expandable.
```

Маркер `+` делает оповещение свернутым и первоначально развернутым. Маркер `-` делает его разборным и изначально свернутым.

Эквивалентный компонент поддерживает варианты `note`/`info`, `tip`, `important`, `warning` и `caution`/`danger`:

```mdx
<Callout variant="warning" title="Back up first" collapsible>
    Callout content can contain supported Markdown.
</Callout>

<Callout variant="danger" collapsed>
    This starts collapsed.
</Callout>
```

`collapsible` начинает расширяться. `collapsed` подразумевает складной вариант и начинается в закрытом состоянии. Названия встроенных вариантов переводятся как Oracle Index; пользовательские заголовки являются содержимым страницы и принадлежат каждому переведенному файлу MDX.

## Блоки кода и вкладки

Изолированный блок кода может включать язык и имя файла:

````md
```json recipe.json
{"тип": "minecraft:crafting_shaped"}
```
````

Вкладки кода содержат прямые дочерние элементы изолированного кода. Поставьте `!!tabs` после языка и добавьте к нему видимый заголовок вкладки:

````mdx
<CodeTabs>
```js !!tabs main.js
console.log("Привет");
```

```css !!tabs styles.css
тело {маржа: 0; }
```
</CodeTabs>
````

Подсветка синтаксиса и специальный моноширинный шрифт в настоящее время не предусмотрены. Язык предназначен только для метаданных, и на каждой вкладке отображается обычный текст с использованием шрифта Minecraft. Вложенные оболочки внутри `<CodeTabs>` не проверяются.

## Другие поддерживаемые компоненты

`CraftingRecipe` отображает рецепт одной формы 3×3. Его массив `slots` должен содержать ровно девять идентификаторов элементов или пустых строк. Он не запрашивает менеджер рецептов и не поддерживает рецепты других измерений.

```mdx
<CraftingRecipe
    slots={['', 'minecraft:stick', '', '', 'minecraft:stick', '', '', 'minecraft:diamond', '']}
    result="minecraft:diamond_shovel"
    count={1}
/>
```

`Audio` воспроизводит актив `.ogg` посредством внутриигрового элемента управления воспроизведением/остановкой:

```mdx
<Audio controls src="example:sounds/notification.ogg" />
```

`VideoEmbed` создает кнопку, открывающую видео на YouTube. Oracle Index не транслирует и не встраивает видео в игру:

```mdx
<VideoEmbed id="Y_WnAEKoeA4" />
```

В тексте при наведении используется `?[label](description)`:

```md
A pickaxe is required to ?[mine](break while also dropping an item) this block.
```

Ярлык и описание представляют собой обычный текст. Вложенное форматирование и закрывающие скобки внутри описания не поддерживаются.

## Поведение перевода

Для схемы 1 переведенные файлы отражают свои базовые пути ниже `translated/<locale>/`. Например:

```text
docs/machines/generator.mdx
translated/de_de/docs/machines/generator.mdx
translated/de_de/docs/machines/_meta.json
```

Вместо этого в устаревших вики используется `.translated/<locale>/`. При сопоставлении локали используется точный активный код языка Minecraft. Английские локали используют базовые ресурсы. Отсутствующие переведенные файлы возвращаются к базовой странице или метаданным.

Заголовки страниц считываются из заголовка переведенной страницы `title`, заголовка первого уровня или переведенного названия внутриигрового предмета. Поиск индексирует только основной текст на базовом языке, но открывает переведенные результаты и отображает заголовки с учетом локали.
