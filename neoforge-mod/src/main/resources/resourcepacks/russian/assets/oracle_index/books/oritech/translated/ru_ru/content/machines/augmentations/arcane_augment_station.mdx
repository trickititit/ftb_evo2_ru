Станция тайных исследований позволяет вашему [Центр аугментации](@oritech:cybernetic_augmentation_center) работать с тайной энергией. Это необходимый компонент для исследования «Нечестивых» дополнений.

Для него требуется **3 ядра машины** и он занимает один слот станции центра дополнений, как и другие типы станций.

Этот уровень охватывает самые необычные улучшения в дереве, включая полет, плащ, возвращение через портал, рудное зрение, контроль гравитации, удачу и другие гибридные техно-магические улучшения поздней игры.
