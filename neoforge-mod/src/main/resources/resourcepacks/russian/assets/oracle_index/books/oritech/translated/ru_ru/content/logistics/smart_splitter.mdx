Smart Splitter — это небольшой буфер элементов, который равномерно распределяет элементы между своими горизонтальными выходами. Он хранит по одному стопке за раз, поэтому не может смешивать разные типы предметов.

Он использует стандартный API транзакций с предметами и не привязан к каналам предметов Oritech. Трубы, бункеры и другие системы передачи предметов из других модов могут взаимодействовать с ним, если они используют один и тот же API передачи предметов.

## Автоматическая боковая конфигурация

Разделитель узнает, как используется каждая горизонтальная сторона:

* Сторона становится **входной** после фиксации вставки через эту сторону.
* Сторона становится **выходом**, как только труба проверяет ее на предмет извлечения или пытается извлечь через нее. Вывод обнаруживается, даже если разделитель пуст, запрошенный элемент недоступен или извлечение только моделируется и никогда не фиксируется.
* Неиспользованные стороны остаются **закрытыми**.

Элементы также можно вставлять сверху или снизу, но выводиться могут только горизонтальные стороны.

Щелкните правой кнопкой мыши горизонтальную грань, чтобы переключить ее между выходным и закрытым режимами. Нажмите правой кнопкой мыши на блок, чтобы просмотреть режимы его распространения. Выбранный режим отображается в чате.

## Режимы распространения

### Строгий

Элементы резервируются как можно более равномерно для каждого сконфигурированного выхода. Труба может извлечь только ту долю, которая зарезервирована для ее стороны. Оставшиеся элементы чередуются между выходами при последующих вставках.

Этот режим гарантирует равномерное разделение, но элементы, зарезервированные для заблокированного или неиспользуемого выхода, остаются в разделителе.

### Переполнение

Первоначально элементы получают те же резервирования, что и в строгом режиме. Если выход не выполняется в течение примерно одной секунды, его зарезервированные элементы становятся доступными для других активных выходов.

Используйте этот режим, когда предпочтительнее равномерное разделение, но поддержание движения потока элементов более важно, чем сохранение заблокированных общих ресурсов на неопределенный срок.

### Круговая система

Одновременно может быть извлечен только один выход. После одной успешно завершенной операции извлечения наступает очередь следующего сконфигурированного вывода. Имитация или откат извлечения не занимают ход.

Количество, перемещаемое за ход, определяется извлекающей трубой, поэтому усиленные трубы по-прежнему могут передавать большие партии, не заставляя каждый элемент выполнять операцию с фиксированной скоростью.

Если текущий выход заблокирован, Round Robin ожидает его. Вместо этого используйте режим переполнения, когда заблокированные выходы должны автоматически обходиться.

<Callout variant="info">
Сплиттер уравновешивает возможности извлечения и резервирования. Он не может заставить принимающий инвентарь принимать предметы, поэтому строгий режим может намеренно удерживать предметы для недоступного вывода.
</Callout>
