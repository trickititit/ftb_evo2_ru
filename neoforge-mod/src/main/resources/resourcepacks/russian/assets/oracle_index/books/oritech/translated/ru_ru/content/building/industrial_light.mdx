Потолочный светильник представляет собой заводской осветительный блок. Обеспечивает яркий свет на большой площади.

Есть два варианта:
*   **Монтаж заподлицо**: Размещается непосредственно на лицевой стороне блока.
*   **Подвесной**: подвешивается на цепи для высоких потолков.

Свет нельзя переключить.
