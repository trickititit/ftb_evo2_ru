---
title: "(Необязательно) Автоматическая синхронизация Gradle Wiki"
---

Рекомендуется добавить задачу gradle для автоматической синхронизации содержимого из вашего каталога «вики» со встроенным модом. Простая задача Gradle архитектуры может выглядеть следующим образом:

```
tasks.named('processResources') {
    from("$rootDir/wiki") {
        into "assets/oracle_index/books/oritech"
        exclude 'assets/item/**'   // items are rendered ingame as actual item components, no need to include them here
    }
    doLast {
        println "processResources executed: wiki folder copied into assets/oracle_index"
    }
}
```

Файлы добавляются в папку «common/build/resources». Обратите внимание, что этот пример был создан для многоплатформенных проектов архитектуры и добавлен в файл build.gradle в «общем» проекте. В зависимости от настроек вашего мода вам может потребоваться настроить это.
