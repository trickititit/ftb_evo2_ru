Аддон «Охотник» изменяет систему прицеливания [Эндерик Лазер](@oritech:enderic_laser), позволяя ему нацеливаться и атаковать живые существа, а не просто блоки.

---

## Боевое применение

После установки лазер будет сканировать мобов на пути своего луча. Каждый дополнительный аддон охотника увеличивает эффективную дальность сканирования и улучшает способность лазера отслеживать движущиеся цели. Это можно использовать для создания автоматизированных систем защиты базы или специализированных установок для выращивания мобов.

Аддоны скорости заставляют лазер наносить больше урона. Надстройки эффективности сокращают его использование на RF/t. Аддоны доходности **не** увеличивают выпадающую добычу.

Добыча с убитых сущностей автоматически собирается в инвентарь лазера. XP сферы не выпадают, когда объект убит лазером.

## Конфигурация

Чтобы изменить цели, по которым стреляет лазер, щелкните по ней правой кнопкой мыши с целеуказателем в руке. Он циклически переключает следующие параметры:
- Все неигровые мобы
- Враждебные и нейтральные мобы (за исключением домашних животных)
- Только враждебные мобы

Его нельзя настроить только на определенные типы мобов. Однако надстройка фильтра обрезки позволяет пропускать дочерние объекты.
