title: "Резонатор узла ресурсов"
type: item
---

Резонатор узлов ресурсов помогает вам найти близлежащие узлы ресурсов любого типа для [Экстрактор коренных пород](@oritech:bedrock_extractor).

Для использования требуется RF.

- **Используйте** выполняет поиск или направляет вас к сохраненному результату.
- **Скрытное использование** снова выполняет поиск.
