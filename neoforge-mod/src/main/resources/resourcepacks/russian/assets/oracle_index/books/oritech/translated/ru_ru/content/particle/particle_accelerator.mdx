---
title: "Контроллер ускорителя"
id: oritech:particle_accelerator
type: block
---

Контроллер ускорителя частиц является точкой входа для частиц. Элементы, вставленные в этот блок, превращаются в частицы. Результаты столкновений можно получить из выходного слота.

Прямую цифру [направляющее кольцо](@oritech:accelerator_ring) необходимо разместить прямо за контроллером, лицом в сторону, чтобы визуальные элементы были правильно выровнены. Любой предмет можно вставить в контроллер и использовать в качестве частицы.

После введения частица движется по маршруту, определяемому направляющими кольцами.

Подробную информацию о механике ускорения частиц см. в разделе [руководство по ускорителю частиц]($particle_accelerator).
