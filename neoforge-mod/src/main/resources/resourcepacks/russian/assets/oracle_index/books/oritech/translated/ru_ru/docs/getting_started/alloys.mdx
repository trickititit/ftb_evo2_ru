Ручная обработка приемлема для самых первых машин. Однако как можно скорее переведите производство сплавов на схему [Пульверизатор](@oritech:pulverizer) плюс [Литейный завод](@oritech:foundry).

Этот сдвиг является одним из самых больших улучшений эффективности в начале Oritech прогресса, а также настраивает вас на более поздние сплавы, такие как биосталь, энергогит и дюратий.
