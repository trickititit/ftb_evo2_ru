Контроллер спавнера управляет автоматизированной системой спауна мобов. Если его разместить над [нерестовая клетка](@oritech:spawner_cage), его можно использовать для создания определенных типов мобов.

</Callout>

## Настройка

Тип моба определяется первой сущностью, которая проходит через контроллер. Изменить этот тип можно только сломав и заменив контроллер. После того, как тип моба установлен, контроллер выделит необходимый размер клетки-спавнера, необходимой под ним.

## Операция

Контроллер собирает души ближайших смертей и поглощает их, чтобы создать назначенного моба.

- **Стоимость души**: количество душ, необходимое для одного появления, рассчитывается на основе 
здоровье моба (в частности, квадратный корень из его максимального здоровья).
- **Диапазон появления**: контроллер пытается найти подходящую поверхность нереста в пределах 
небольшой радиус (4 блока) вокруг себя.
- **Управление красным камнем**: подача сигнала красного камня на контроллер отключит 
это, остановив все операции по нересту.

Щелчок правой кнопкой мыши по контроллеру предоставляет информацию о его текущем рабочем состоянии, включая установленный моб и текущие уровни души.

<Callout variant="info">
    Спаунер не может быть настроен на типы мобов, которые являются частью тега `oritech:spawner_blacklist`.
</Callout>
