Ваш следующий большой шаг — построить [Ассемблер](@oritech:assembler) и [Центрифуга](@oritech:centrifuge).

Сборщик изготавливает многие компоненты более эффективно, чем вручную, и требуется для изготовления некоторых деталей, которые невозможно правильно изготовить вручную.

Центрифуга обрабатывает преобразование ресурсов, от которого зависит остальная часть технологического дерева, включая куски руды, производство углеродного волокна и последующую обработку жидкости после подключения соответствующего дополнения.

Обеим машинам нужна мощность RF, и обе они станут гораздо полезнее, как только вы поймете [дополнения]($ADDON_CONCEPTS).
