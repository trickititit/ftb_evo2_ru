Ресурсные узлы — это бесконечные источники сырья, которые можно добыть с помощью [Экстрактор коренных пород](@oritech:bedrock_extractor). Эти узлы встроены в скальную породу и неразрушимы.

Чтобы найти эти узлы, найдите [Рудные валуны](@oritech:deepslate_platinum_ore) на поверхности. Они отмечают ресурсный узел прямо под коренной породой.

<center>
<ModAsset location="oritech:area/resource_node" width={700} />
</center>

Ресурсные узлы существуют для нескольких материалов, включая железо, медь, золото, никель, платину, уран и даже редкие драгоценные камни, такие как алмазы. Для добычи этих узлов требуется бур, чтобы достичь слоя коренной породы.

<center>
<ModAsset location="oritech:area/bedrock_extraction" width={1000} />
</center>

[Резонатор узла ресурсов](@oritech:resource_node_resonator) находит ближайший загруженный узел ресурса любого типа. Скрытность — используйте для повторного поиска после перехода в другую область.
