Эта страница предназначена для разработчиков, которые хотят, чтобы их вики была доступна через мод Oracle Index.

## Настройка проекта
1. Создайте каталог / макет вики-контента как обычно, следуя инструкциям moddedmc.wiki.
2. Убедитесь, что у вас есть файлы _meta.json с записями для **всего** вашего контента. Oracle Index использует файлы Meta.json для создания
панель навигации.
3. Скопируйте всю вики в папку ресурсов вашего мода. Это можно автоматизировать, см. [автоматическая синхронизация градиента](../developer/gradle_task). Правильный путь: «resources/assets/oracle_index/books/your-mod-id/».
4. Индекс оракула автоматически загрузит ресурсы ваших модов.

Результирующее дерево каталогов должно выглядеть следующим образом:

<center>
<ModAsset location="oracle-index:folder_layout" width={600} />
</center>

Горячей перезагрузки нет. Используйте предварительный просмотр moddedmc.wiki для создания содержимого вики. Однако перезагрузка ресурса обновит игровой контент.

Внутриигровые вики-ресурсы можно добавлять через пакеты ресурсов (которые также могут содержаться внутри модов). Взгляните на репозиторий oritech, чтобы увидеть пример настройки. Пример пакета ресурсов находится на github в репозитории индекса Oracle: https://github.com/Rearth/Oracle-Index/tree/26.1.2/example_resource_pack

### Совместимость с уценкой

Oracle Index поддерживает функции Markdown и MDX, обычно необходимые вики-сайтам ModdedMC, включая таблицы, оповещения, изображения, вкладки кода, выноски, рецепты, аудио- и видеоссылки. См. [Справочник по Markdown и MDX](./markdown) для ознакомления с синтаксисом и точными ограничениями.

Это специальный внутриигровой рендерер, а не веб-браузер. Произвольные HTML, JSX, JavaScript, CSS и пользовательские компоненты React не оцениваются. Неподдерживаемые блоки HTML игнорируются. Поддерживается простой `<img>`, тогда как теги-оболочки `<center>`, `<div>` и `<span>` отбрасываются, когда они используют свои простые формы тегов.

Для вики схемы 1 изображения и аудиофайлы относятся к `assets/<namespace>/` в каталоге вики. Вики устаревшего формата используют `.assets/<namespace>/`. Старый каталог `.assets/item/<namespace>/` не нужен, поскольку идентификатор элемента реестра отображается с использованием внутриигровой модели.

Страницы контента с действительным `id` также получают внутриигровую панель свойств. Размер стека, долговечность, информация о майнинге, уровень освещенности и подобные значения взяты из реестров активных игр.

### Ссылки на предметы
Одна дополнительная функция, добавленная Oracle Index, — это возможность связывать соответствующие элементы вики-страницы. Для этого во фронтматер mdx добавляется новый параметр: «related_items», который содержит массив идентификаторов игровых предметов. Это может выглядеть следующим образом:
```
---
title: Generators
icon: oritech:basic_generator_block
related_items: [oritech:basic_generator_block, oritech:bio_generator_block, oritech:lava_generator_block, oritech:fuel_generator_block, oritech:big_solar_panel_block]
---
Here would be your content.
```

Эти ссылки будут автоматически созданы для записей вики-контента.

### Пользовательская книга / Открытие экранов
Oracle Index по умолчанию не поставляется с путеводителем. Однако в своем моде вы можете очень легко просто добавить новый элемент книги и открыть нужный экран при использовании книги. Вы также можете открыть книгу с помощью других механизмов, например, кнопки на другом экране.

Вызовите следующий код на стороне клиента:
```java
// Oritech is the wiki name here.
// Entry resources always use the oracle_index namespace.
Identifier entry = Identifier.fromNamespaceAndPath(
    "oracle_index", "books/oritech/docs/intro.mdx"
);
OracleClient.openScreen("oritech", entry, Minecraft.getInstance().screen);
```
