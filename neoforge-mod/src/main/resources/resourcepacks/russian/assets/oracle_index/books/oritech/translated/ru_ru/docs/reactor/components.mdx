Реактор может быть изготовлен из нескольких различных компонентов:

- Контроллер реактора: сердце вашего реактора. Этот блок нужно один раз разместить где-нибудь на стенах. С ним нужно взаимодействовать, чтобы собрать или обновить реактор.
Графический интерфейс показывает текущее состояние реактора, а также температуру компонентов и статистику. Графический интерфейс показывает только первый уровень внутренней части.

- Стенка реактора. Стенка реактора представляет собой очень прочную и взрывостойкую часть реактора. Он должен охватывать всю раму.

- Стержень реактора: Стержни реактора представляют собой внутренние компоненты, которые необходимо снабжать таблетками из урана или плутония. Необходимо наличие топливного порта над каждым пакетом стержней.
чтобы залить топливо. Он доступен в виде одиночных, двойных или четырехстержней, которые будут генерировать тепло и энергию в зависимости от количества стержней.

- Тепловая трубка реактора: Тепловые трубки поглощают тепло от соседних топливных стержней, а затем распределяют тепло между соседними теплоотводами. Максимум передано
количество тепла от соседнего компонента основано на разнице температур между двумя компонентами: > temperDiff / 4 + 10

- Отражатель нейтронов реактора: эти блоки отражают нейтроны соседних топливных стержней, повышая их эффективность.

- Теплоотвод реактора: Вентиляционные отверстия отводят тепло от самого горячего соседнего компонента. Количество отводимого тепла зависит от температуры соседнего
компонент. Более горячие компоненты будут отводить больше тепла. Точная формула: > соседнее тепло / 100 + 4.

- Теплопоглотители реактора: Теплопоглотители могут отводить фиксированное количество тепла от всех соседних компонентов. Это означает, что он более эффективен, когда
окружен компонентами, которые необходимо охлаждать. Однако для этого требуется постоянная подача охлаждающей жидкости в виде льда, голубого льда или упакованного льда в порт охлаждающей жидкости над блоком абсорбера. Количество используемой охлаждающей жидкости фиксировано и не увеличивается при увеличении количества охлаждаемых сторон. Каждый тик от каждого соседа снимается по 16 единиц тепла.

- Энергетический порт реактора: энергетический порт используется для вывода энергии, вырабатываемой реактором. Каждый порт может выводить до 25 000 RF/t.

- Топливный порт реактора: необходимо разместить на внешнем потолке реактора, а топливные стержни — под ним. Сюда можно вставить топливные гранулы.

- Отверстие для абсорбера охлаждающей жидкости реактора: необходимо разместить на внешнем потолке реактора, а под ним разместить поглотители тепла.
Здесь можно заливать охлаждающую жидкость в виде льда, голубого льда или упакованного льда.

- Порт реактора из красного камня: энергетический сигнал в порт из красного камня отключит поступление нового топлива. Любая топливная таблетка, которая уже начала гореть, нуждается в
должно быть завершено до того, как реактор полностью отключится с помощью сигнала красного камня в порт. Порт также можно использовать с компаратором для вывода данных. Он имеет 3 режима: энергия, количество активных стержней и температура. Для переключения между режимами просто щелкните порт правой кнопкой мыши.

## Деятельность топливных стержней

Каждый топливный стержень будет потреблять фиксированное количество топлива из топливных отверстий выше. Каждая топливная таблетка имеет разную топливную емкость. Используйте JEI, REI или EMI, чтобы просмотреть использование пеллет для конкретных данных о производительности. Каждый одинарный стержень использует 1 единицу мощности, двойной стержень - 2, а четырехстержневой - 4.

При горении топлива каждый стержень генерирует нейтронные импульсы. Каждый импульс создает определенное количество энергии, по умолчанию 128 RF. Чем больше импульсов получает стержень, тем больше энергии он создает. По умолчанию каждый стержень отправляет и получает один импульс. Однако если соседний компонент также является твэлом, он также ударит импульсом по соседнему компоненту. Отражатели нейтронов можно использовать для отправки импульса обратно к его источнику, действуя аналогично стержню в качестве соседа.

Двойные и четверные импульсы поражают импульсами другие стержни в том же блоке, а также отправляют 2 или 4 импульса соседям.

Одинарный стержень генерирует 1 внутренний импульс, двойной стержень — 4, четверной — 12.

Количество выделяемого тепла основано на общем количестве импульсов стержня, внутренних и внешних импульсов: > импульсов / 2 * импульсов + 4.
