title: "Ускорительный двигатель"

Прохождение через двигатель-ускоритель ускоряет частицу на 1 м/с, пока двигатель включен.

Потребность в мощности увеличивается с увеличением скорости. Каждый раз, когда двигатель ускоряет частицу, он потребляет текущую скорость частицы * 10 RF.

Двигатели можно использовать в качестве прямых направляющих на пути акселератора.

Подробную информацию о механике ускорения частиц см. в разделе [руководство по ускорителю частиц]($particle_accelerator).
