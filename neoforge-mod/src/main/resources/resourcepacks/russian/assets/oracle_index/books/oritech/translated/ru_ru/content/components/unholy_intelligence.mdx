id: oritech:unholy_intelligence

Редкое логическое ядро, полученное путем захвата определенных магических существ.

**Получение**
- **Захват объектов**: замените [Сомнительный контейнер](@oritech:dubious_container) на [Аллай](https://minecraft.wiki/w/Allay). 
или взаимодействуйте с [Векс](https://minecraft.wiki/w/Vex), чтобы уловить их суть.
- **Центрифуга (Альтернатива)**: может быть синтезирована путем обработки [Сомнительный контейнер](@oritech:dubious_container) 
с [Странная материя](@oritech:still_strange_matter). Этот метод стоит гораздо дороже, чем захват объектов.
