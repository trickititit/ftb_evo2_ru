Биосталь — более экологичная альтернатива стали. Это сплав среднего уровня, используемый для создания [дополнения]($ADDON_CONCEPTS), [датчики](@oritech:accelerator_sensor) и других компонентов.

Его можно создать в [литейный завод](@oritech:foundry) с помощью железа и [биомасса](@oritech:biomass).
