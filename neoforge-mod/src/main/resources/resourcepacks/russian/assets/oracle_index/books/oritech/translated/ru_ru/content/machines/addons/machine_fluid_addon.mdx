---
title: "Жидкий аддон"
id: oritech:machine_fluid_addon
type: block
---

Надстройка Fluid обеспечивает возможности обработки жидкостей для машин, которые в противном случае обрабатывают только предметы.

Это особенно необходимо для следующих операций:
- Чтобы [Центрифуга](@oritech:centrifuge) обработался и
отдельные жидкости.
- Для [Порт дронов](@oritech:drone_port) для транспортировки жидкостей.

<Callout variant="info">
    После подключения в машине появится хранилище для жидкости, и соответствующие отверстия для жидкости будут видны в пользовательском интерфейсе.
</Callout>
