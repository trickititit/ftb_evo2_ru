Направляющие кольца определяют путь, по которому частицы перемещаются в ускорителе.

Их можно щелкнуть правой кнопкой мыши, чтобы добавить поворот на 45 градусов с одной стороны. Еще одно направляющее кольцо должно находиться на пути частицы, определенном направляющими кольцами. В зависимости от скорости допустимое расстояние между направляющими блоками увеличивается.

### Редстоунские переключатели

Когда сигнал красного камня подается на непрямой направляющий блок, он становится блоком переключателя. При включении он направляет частицы прямо; в выключенном состоянии он направляет их в исходное изогнутое направление.

Подробную информацию о механике ускорения частиц см. в разделе [руководство по ускорителю частиц]($particle_accelerator).
