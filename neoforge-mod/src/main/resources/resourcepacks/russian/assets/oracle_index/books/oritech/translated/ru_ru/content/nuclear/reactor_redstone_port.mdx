Сигнал красного камня в порт красного камня отключит поступление нового топлива.

Любая топливная таблетка, которая уже начала гореть, должна быть доведена до конца до того, как реактор полностью отключится с помощью сигнала красного камня в порт.

Порт также можно использовать с компаратором для вывода данных. Имеет 3 режима:

*   **Температура**: выходной сигнал основан на температуре самого горячего компонента (относительно максимального тепла реактора).
*   **Количество активных стержней**: указывает количество стержней, сжигающих топливо (например, фактическое количество стержней на слой, которые активны в данный момент. Двойные и четверные стержни считаются за один).
*   **Энергия**: измеряет сохраненный ток RF.

Для переключения между режимами просто щелкните порт правой кнопкой мыши.

Подробную информацию о механике реактора смотрите в разделе [руководство по ядерному реактору]($reactor/introduction).
