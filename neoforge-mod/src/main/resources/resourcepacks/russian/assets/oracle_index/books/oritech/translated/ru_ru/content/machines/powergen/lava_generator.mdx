Использует лаву в качестве топлива для выработки электроэнергии. Насос можно использовать для сбора лавы в больших количествах.

Базовая скорость генерации составляет 128 RF/t. Также можно использовать огонь Шеола, и он горит намного дольше, чем обычная лава.

Подачу жидкости можно автоматизировать с помощью резервуаров, насосов или труб. Ручное заполнение ковша — это нормально на ранних этапах, но машина работает намного лучше, если она является частью надлежащей сети жидкостей.

<Callout variant="info">
    Огонь Шеола стоит доработать специально для этой машины, потому что он горит гораздо дольше, чем обычная лава.
</Callout>
