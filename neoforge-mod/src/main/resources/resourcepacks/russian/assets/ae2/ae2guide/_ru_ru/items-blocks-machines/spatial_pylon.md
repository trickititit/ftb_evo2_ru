# <a name="the-spatial-pylon" />Пространственный пилон

<BlockImage id="spatial_pylon" p:powered_on="true" scale="8" />

Пространственный пилон используется в [пространственный ввод-вывод](../ae2-mechanics/spatial-io.md) для создания пространственного поля и определения объема, на который будет воздействовать.

Каждая непрерывная линия пилонов использует 1 [канал](../ae2-mechanics/channels.md).

Для функционирования линии пилонов должны иметь длину не менее 2 блоков.
