# <a name="wireless-terminals" />Беспроводные терминалы

<Row>
  <ItemImage id="wireless_terminal" scale="4" />

  <ItemImage id="wireless_crafting_terminal" scale="4" />
</Row>

Беспроводные терминалы представляют собой портативные версии обычных проводных [терминалы](terminals.md). У них точно такой же пользовательский интерфейс, как и у их проводных аналогов, за исключением того, что вместо слотов для <ItemLink id="view_cell" /> у них есть слоты для [карты обновления](upgrade_cards.md).

Чтобы соединить их с сетью, вставьте терминал в верхний правый слот <ItemLink id="wireless_access_point" />, подключенного к этой сети. (Слот с изображением беспроводного терминала и стрелкой под ним)

Для работы они должны находиться в пределах диапазона <ItemLink id="wireless_access_point" />.

Их энергию можно перезарядить в <ItemLink id="charger" />.

# <a name="wireless-crafting-terminal" />Беспроводной терминал для крафта

<ItemImage id="wireless_crafting_terminal" scale="4" />

Беспроводной терминал крафта похож на обычный беспроводной терминал, со всеми теми же настройками и разделами, но с добавленной сеткой крафта, которая будет автоматически пополняться с [сетевое хранилище](../ae2-mechanics/import-export-storage.md). Будьте осторожны, нажимая клавишу Shift!
