# <a name="singularity" />Сингулярность

<ItemImage id="singularity" scale="4" />

Очень компактный шар материи.

Сделано из 256 000 предметов или корзин в <ItemLink id="condenser" /> в режиме сингулярности.

## <a name="quantum-entangled-singularity" />Квантовая запутанная сингулярность

<ItemImage id="quantum_entangled_singularity" scale="4" />

Необходимы для создания соединения между двумя [Квантовые сетевые мосты](quantum_bridge.md), они всегда создаются совпадающими парами. Чтобы создать соединение, поместите одну из пары квантово запутанных особенностей в <ItemLink id="quantum_link" /> моста с каждой стороны.

Они создаются путем реакции между <ItemLink id="minecraft:ender_pearl" /> или <ItemLink id="ender_dust" />\ и <ItemLink id="singularity" />. Любой взрывной силы должно быть достаточно, чтобы вызвать реакцию.

<RecipeFor id="quantum_entangled_singularity" />

***Почти любой взрыв, даже криперы, сработает.***

Всегда создаются парами, но требуется только один <ItemLink id="singularity" />.

Возможно, было бы неплохо пометить их именами, когда вы создаете их с помощью ванильной наковальни.
