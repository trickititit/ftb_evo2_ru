# <a name="quartz-tools" />Кварцевые инструменты

<Row>

  <ItemImage id="nether_quartz_cutting_knife" scale="4" />

Режущие ножи используются для изготовления цифр <ItemLink id="name_press" /> и <ItemLink id="cable_anchor" />.

Чтобы изготовить именной пресс, щелкните правой кнопкой мыши режущий нож и вставьте слиток металла. Затем вам нужно будет ввести имя, которое вы хотите написать на пластине, а затем просто извлечь готовую пластину.
