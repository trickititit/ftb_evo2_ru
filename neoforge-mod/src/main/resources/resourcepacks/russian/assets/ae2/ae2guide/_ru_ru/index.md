# <a name="what-is-applied-energistics-2?" />Что такое Applied Energistics 2?

# <a name="how-to-use-this-guide" />Как использовать это руководство

* Откройте боковую панель слева, чтобы найти оглавление.
* На многих страницах есть интерактивные сцены. Если в сцене есть ![Плюс](assets/diagrams/plus.png)
и кнопки ![Минус](assets/diagrams/minus.png) (масштаб) рядом с ней, вы можете вращать и перемещать камеру. Щелкните левой кнопкой мыши и перетащите, чтобы повернуть, щелкните правой кнопкой мыши и перетащите, чтобы перевести.

# <a name="what-is-applied-energistics-2?" />Что такое Applied Energistics 2?

Applied Energistics 2 добавляет компоненты и механику для обеспечения решений по логистике и хранению. Вы можете заменить свою огромную комнату, полную сундуков, компактной ME-сетью, но это только начало. Applied Energistics предназначен для работы и автоматизации других модов в модпаке. Вы можете настроить свою систему так, чтобы одним щелчком мыши создавать все необходимые условия (и конечный результат) сложной цепочки крафта или хранить определенное количество предметов на складе, создавая больше по мере необходимости, или просто перемещать предметы по своей базе.
