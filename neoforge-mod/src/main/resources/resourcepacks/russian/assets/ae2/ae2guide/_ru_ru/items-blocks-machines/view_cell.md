# <a name="view-cell" />Просмотр ячейки

<ItemImage id="view_cell" scale="2" />

Ячейки просмотра используются для фильтрации отображения [терминалы](terminals.md). Вы разделяете их на <ItemLink id="cell_workbench" />.

Например, предположим, что вы хотите, чтобы терминал отображал только выбор каменных строительных материалов. Разделите ячейку представления на эти материалы и поместите ее в терминал, и будут показаны только эти элементы.

Ячейки просмотра являются аддитивными: если у вас есть ячейка просмотра для дубовых досок и ячейка просмотра для булыжника, при добавлении обеих будут показаны и доски, и булыжник.
