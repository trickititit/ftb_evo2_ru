# <a name="the-cell-workbench" />Сотовый верстак

<BlockImage id="cell_workbench" scale="8" />

Cell Workbench позволяет настраивать [ячейки хранения](storage_cells.md) и <ItemLink id="view_cell" />.

Вы можете добавить [карты обновления](upgrade_cards.md) и настроить «разделы», чтобы фильтровать то, что будет храниться в ячейке.

Предметы и жидкости можно перетаскивать в слоты из JEI/REI, даже если у вас на самом деле нет ни одного из этих предметов.

Щелкните правой кнопкой мыши контейнер с жидкостью (например, ведро или резервуар с жидкостью), чтобы установить эту жидкость в качестве фильтра вместо ведра или бака.

## <a name="settings" />Настройки

В левом верхнем углу рабочей среды ячейки есть несколько кнопок:

*   Вы можете разделить ячейку на основе ее существующего содержимого.
*   Вы можете очистить разделение ячейки
*   В рабочей среде можно настроить сохранение настроек раздела при удалении ячейки, что позволяет копировать настройки между ячейками.
