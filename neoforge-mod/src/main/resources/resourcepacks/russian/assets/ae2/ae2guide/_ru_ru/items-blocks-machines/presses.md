## <a name="name-press" />Имя Пресса

Пресс имени можно использовать в пишущей машинке для обозначения предметов, подобно наковальне. В принтере можно использовать одну или две пластины одновременно. Если вы используете две пластины, имя будет напечатано, используя комбинацию обоих имен: сначала верхний слот, затем нижний слот.

Чтобы создать, щелкните правой кнопкой мыши, удерживая <ItemLink id="certus_quartz_cutting_knife" /> или
<ItemLink id="nether_quartz_cutting_knife" /> и вставьте слиток металла.
Затем вам нужно будет ввести имя, которое вы хотите написать на табличке, а затем просто извлечь готовую табличку.
