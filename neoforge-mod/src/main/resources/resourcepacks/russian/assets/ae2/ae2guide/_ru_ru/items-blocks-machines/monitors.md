# <a name="monitors" />Мониторы

Мониторы позволяют визуализировать и взаимодействовать с одним элементом или типом жидкости без открытия графического интерфейса.

Мониторы унаследуют цвет [кабель](cables.md), на котором они установлены.

Если монитор находится на полу или потолке, его можно повернуть с помощью <ItemLink id="certus_quartz_wrench" />.

Они [части кабеля](../ae2-mechanics/cable-subparts.md).

# <a name="storage-monitor" />Монитор хранения

Покажет предмет или жидкость и ее количество. Поставьте их рядом со своими фермами или что-то в этом роде...

*Не* требует [канал](../ae2-mechanics/channels.md).

Сочетания клавиш:

*   Щелкните правой кнопкой мыши элемент или дважды щелкните правой кнопкой мыши контейнер с жидкостью, чтобы настроить монитор на этот элемент/жидкость.
*   Щелкните правой кнопкой мыши пустой рукой, чтобы очистить монитор.
*   Shift — щелкните правой кнопкой мыши пустой рукой, чтобы заблокировать монитор.

# <a name="conversion-monitor" />Монитор конверсий

Монитор преобразований аналогичен монитору хранилища, но позволяет вставлять или извлекать настроенный элемент.

Если настроенный предмет равен [автопроизводимый](../ae2-mechanics/autocrafting.md) и ни один из них не находится в хранилище, при попытке взять предмет вместо этого откроется пользовательский интерфейс, в котором можно указать количество, которое необходимо создать.

*Требуется* [канал](../ae2-mechanics/channels.md).

Дополнительные сочетания клавиш:

*   Щелкните левой кнопкой мыши, чтобы извлечь стопку настроенного предмета (или, если его нет на складе, чтобы запросить создание этого предмета).
*   Щелкните правой кнопкой мыши любой элемент, чтобы вставить его.
*   Щелкните правой кнопкой мыши пустой рукой, чтобы вставить все настроенные элементы из вашего инвентаря.
