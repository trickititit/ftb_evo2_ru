# <a name="the-me-chest" />Сундук МЕ

<GameScene zoom="8" background="transparent">
<ImportStructure src="../assets/blocks/chest.snbt" />
</GameScene>

ME Chest действует как миниатюрная сеть с <ItemLink id="terminal" />, <ItemLink id="drive" /> и <ItemLink id="energy_acceptor" />. Хотя ее можно использовать в качестве крошечной сети хранения данных, ее емкость только для одного [ячейка хранения](../items-blocks-machines/storage_cells.md) означает, что ее полезность как таковая ограничена.

Вместо этого он полезен для взаимодействия конкретно с ячейкой хранения, установленной внутри него. Его встроенный терминал может видеть и получать доступ только к предметам на подключенном диске, в то время как [устройства](../ae2-mechanics/devices.md) в общей сети может получать доступ к предметам в любом [сетевое хранилище](../ae2-mechanics/import-export-storage.md), включая ME сундуки.

Он имеет два разных графических интерфейса и предназначен для транспортировки предметов. Взаимодействие с верхним терминалом открывает встроенный терминал. Через эту грань предметы можно вставлять в установленную ячейку хранения, но нельзя извлекать. Взаимодействие с любым другим лицом открывает графический интерфейс со слотом для ячейки хранения и настройками приоритета. Ячейку можно вставлять и извлекать при логистике товара только через лицевую сторону с гнездом для ячейки.

Его можно вращать с помощью <ItemLink id="certus_quartz_wrench" />.

Он имеет небольшой буфер хранения энергии AE, поэтому, если он не в сети с [энергетическая ячейка](../items-blocks-machines/energy_cells.md), вставка или извлечение слишком большого количества элементов одновременно может привести к его отключению.

Терминал может быть окрашен в цвет <ItemLink id="color_applicator" />.

## <a name="settings" />Настройки

ME Chest имеет все те же настройки, что и <ItemLink id="terminal" /> или <ItemLink id="crafting_terminal" />. Однако он не поддерживает <ItemLink id="view_cell" />.

## <a name="cell-status-leds" />Светодиоды состояния ячеек

На ячейках в сундуке есть светодиод, который показывает их состояние:

| Цвет | Статус |
| :----- | :------------------------------------------------------------------------------- |
| Зеленый | Пусто |
| Синий | Имеет некоторое содержание |
| Оранжевый | [Типы](../ae2-mechanics/bytes-and-types.md) полно, новые типы добавлять нельзя |
| Красный | [Байты](../ae2-mechanics/bytes-and-types.md) заполнено, больше нельзя вставить элементы |
| Черный | Ни силы, ни драйва нет [канал](../ae2-mechanics/channels.md) |

## <a name="priority" />Приоритет

Приоритеты можно установить, щелкнув гаечный ключ в правом верхнем углу графического интерфейса ячейки. Товары, поступающие в сеть, начинаются с хранилища с наивысшим приоритетом в качестве первого пункта назначения. В случае двух хранилищ или ячеек с одинаковым приоритетом, если одно из них уже содержит элемент этого типа, этот элемент предпочтет это хранилище любому другому. Любые ячейки [разделенный](cell_workbench.md) будут рассматриваться как уже содержащие элемент, если они находятся в той же группе приоритета, что и другие хранилища. Предметы, удаляемые из хранилища, будут удалены из хранилища с наименьшим приоритетом. Эта система приоритетов означает, что по мере того, как элементы вставляются и удаляются из сетевого хранилища, хранилища с более высоким приоритетом будут заполняться, а хранилища с более низким приоритетом будут опустошаться.
