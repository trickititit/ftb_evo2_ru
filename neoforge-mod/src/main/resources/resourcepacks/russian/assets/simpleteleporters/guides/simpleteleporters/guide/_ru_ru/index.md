# Простые телепорты

Welcome к Простым Телепортам! Этот мод предоставляет простую в использовании механику телепортации для Minecraft.

## Особенности

<Row>
<Column>

### Сеть телепортов

Создайте сеть из блоков <ItemLink id="simpleteleporters:teleporter" />, связанных элементами <ItemLink id="simpleteleporters:ender_shard" />, чтобы быстро перемещаться между локациями. Повысьте уровень до <ItemLink id="simpleteleporters:enhanced_ender_shard" /> для путешествий между измерениями!

</Column>
<Column>

### Персональная телепортация

Используйте <ItemLink id="simpleteleporters:hearth_crystal" />, чтобы сохранить личное местоположение дома и телепортироваться обратно к нему из любого места.

</Column>
</Row>
