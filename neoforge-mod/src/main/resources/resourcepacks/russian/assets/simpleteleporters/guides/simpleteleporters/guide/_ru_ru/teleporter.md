## Как использовать

### Настройка телепорта

1. Поместите блок телепорта в пункт назначения.
2. Привяжите <ItemLink id="simpleteleporters:ender_shard" /> к месту над телепортом пункта назначения, **подкравшись** и **щелкнув** правой кнопкой мыши** по нему.
3. Поместите еще один блок телепорта в исходное место.
4. **Нажмите правой кнопкой мыши** на стартовом телепорте со связанным ядром Края, чтобы вставить его.

### Телепортация

Встаньте на активный телепорт (с частицами портала) и **крадитесь**, чтобы телепортироваться в указанное место.

## Крашение

Телепорты можно покрасить в любой из 16 ванильных цветов, чтобы организовать сеть телепортов. Просто **щелкните правой кнопкой мыши** по телепорту с любым красителем, чтобы изменить цвет его кварцевого основания и платформы. Цвет по умолчанию — белый.

Это чисто косметический эффект, но полезен для цветового кодирования пунктов назначения (например, красный для центра Незера, синий для океанских баз).

## Активация Редстоуна

Телепорты можно активировать с помощью **сигнала красного камня**! Когда телепортер получает импульс красного камня, он телепортирует **все объекты**, стоящие на нем, в связанное место назначения, включая игроков, мобов, животных и предметы.

Это открывает мощные возможности автоматизации:
- Автоматические фермы мобов, которые телепортируют мобов в зону сбора.
- Системы транспортировки игроков по времени с использованием часов из красного камня
- Триггеры нажимной пластины для телепортации без помощи рук.
- Телепортационные станции, активируемые кнопками

Телепорт активируется только на **нарастающем фронте** сигнала красного камня (когда он меняется с отключенного на включенный), предотвращая непрерывную телепортацию от устойчивых сигналов.

## Особенности

- **Окрашивание**: щелкните правой кнопкой мыши по любому красителю, чтобы настроить основной цвет кварца.
- **Редстоун активирован**: отправьте сигнал красного камня, чтобы телепортировать все объекты на площадке.
- **Телепортация сущностей**: телепортирует игроков, мобов, животных и многое другое.
- **Частицы портала**: активные телепорты отображают частицы портала, если у них есть связанное ядро Края.
- **Перезарядка**: короткое время восстановления предотвращает мгновенную повторную телепортацию.
- **Водонепроницаемый**: можно размещать под водой.
- **Поддержка измерений**: то же измерение с ядрами Края, межпространственное с <ItemLink id="simpleteleporters:enhanced_ender_shard" />

## Советы

- Для двунаправленного перемещения установите два телепорта с ядрами Края, направленными друг на друга.
- Телепорт выбрасывает Ядро Края, когда вы щелкаете по нему правой кнопкой мыши, что позволяет вам перенастроить вашу сеть.
- Если пункт назначения заблокирован, вы получите сообщение об ошибке.
