<Column alignItems="center" fullWidth={true}>
  ## <Color id="gold">Шаг 2 — Настой ледникового бассейна</Color>
</Column>

<Row>
  <ItemImage id="glacial_basin" />
  ### <Color id="aqua">Настой</Color>
</Row>

Наполните неочищенную мерцающую сталь <ItemLink id="glacial_basin" />, наполненную жидкой аурой.

1. Разместите ледниковый бассейн под открытым небом в холодном биоме.
2. Подождите, пока полярное сияние полностью заполнит бассейн (3/3 ауры).
3. Щелкните правой кнопкой мыши таз с неочищенной мерцающей сталью.
4. Бассейн потребляет **всю** свою жидкую ауру для производства одного слитка мерцающей стали.

**Важно:** для проведения инфузии таз должен быть полностью заполнен.
