# <a name="me-smart-annihilation-plane" />ME Умный самолет уничтожения

<GameScene zoom="8" background="transparent">
  <ImportStructure src="../structure/cable_smart_annihilation_plane.snbt"></ImportStructure>
</GameScene>

Умный самолет уничтожения ME — это <ItemLink id="ae2:annihilation_plane" />, который может разбивать блоки или поглощать предметы в соответствии с его конфигурацией.

Вам не нужно настраивать для него подсеть. Он работает как <ItemLink id="ae2:import_bus" />, но разбивает блоки вместо того, чтобы импортировать предметы из сундука.
