# <a name="me-extended-io-port" />Расширенный порт ввода-вывода ME

<Row gap="20">
<BlockImage id="extendedae:ex_io_port" p:powered="true" scale="8"></BlockImage>
</Row>

Расширенный порт ввода-вывода ME работает в восемь раз быстрее, чем стандартный порт <ItemLink id="ae2:io_port" />.

Он также имеет больше слотов для обновления, чем стандартный порт ввода-вывода.
