# <a name="me-crystal-fixer" />ME Кристаллический фиксатор

<BlockImage id="extendedae:crystal_fixer" scale="8"></BlockImage>

ME Crystal Fixer может отремонтировать блок зарождающегося цертусового кварца и превратить его в улучшенную форму.

Для работы требуется <ItemLink id="ae2:charged_certus_quartz_crystal" /> и питание. Щелкните правой кнопкой мыши с помощью <ItemLink id="ae2:charged_certus_quartz_crystal" />, чтобы вставить кристалл.
