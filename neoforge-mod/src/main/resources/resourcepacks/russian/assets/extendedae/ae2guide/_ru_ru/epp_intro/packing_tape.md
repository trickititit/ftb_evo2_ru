# <a name="me-packing-tape" />Упаковочная лента ME

Упаковочная лента ME позволяет упаковать находящееся в мире ME-устройство в элемент упакованного устройства.

<Row>
<ItemImage id="extendedae:me_packing_tape" scale="4"></ItemImage>
<ItemImage id="extendedae:package" scale="4"></ItemImage>
</Row>

## <a name="packing" />Упаковка

Кликните правой кнопкой мыши по устройству ME с лентой, чтобы превратить его в предмет упаковки. Все настройки и инвентарное содержимое устройства сохраняются. Это полезно при перемещении установки ME.

ME Packing Tape поддерживает только устройства из списка. Этот список устройств можно настроить.

## <a name="unpacking" />Распаковка

Щелкните правой кнопкой мыши элемент пакета, как при размещении исходного блока или детали устройства. После этого упакованное устройство будет восстановлено из пакета.
