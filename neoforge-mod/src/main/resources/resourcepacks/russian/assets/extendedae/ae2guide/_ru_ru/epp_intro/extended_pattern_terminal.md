## <a name="better-pattern-search" />Улучшенный поиск по шаблону

Вы можете искать шаблоны по названиям их входных или выходных ингредиентов.

![Агентство по охране окружающей среды1](../pic/epa_gui1.png)

## <a name="pattern-highlight" />Выделение узора

Иногда все же сложно найти нужный узор, поскольку узоры всегда отображаются группой. Терминал доступа к расширенному шаблону может выделить соответствующий шаблон в графическом интерфейсе.

![Агентство по охране окружающей среды2](../pic/epa_gui2.png)

## <a name="pattern-provider-in-world-highlight" />Поставщик шаблонов в мире

Может быть сложно определить, какой поставщик шаблонов застрял во время большой работы. Терминал доступа к расширенным шаблонам может выделить поставщика шаблонов в мире, что упрощает его поиск.

![Агентство по охране окружающей среды3](../pic/epa_gui3.png)
