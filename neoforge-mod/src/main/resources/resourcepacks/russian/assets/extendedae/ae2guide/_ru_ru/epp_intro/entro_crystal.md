# <a name="the-entro-crystal" />Энтро Кристалл

<Row>
<ItemImage id="extendedae:entro_crystal" scale="4"></ItemImage>
</Row>

*"Энтро-кристаллы проявляют чрезвычайно сильное пространственное сродство после того, как Эндер-пыль вводится в кристаллы флюкса, что позволяет им резонировать в пространстве-времени."*

Кристаллы Энтро — основной ингредиент для изготовления большинства предметов и машин ExtendedAE. Используйте <ItemLink id="extendedae:entro_seed" />, чтобы превратить <ItemLink id="ae2:fluix_block" /> в [Энтрозированный флюикс почкование](./entro_budding.md), затем соберите Энтро-кластер, чтобы получить Энтро-кристаллы.
