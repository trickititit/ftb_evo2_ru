# <a name="the-start-of-extendedae" />Начало ExtendedAE

<Row>
<BlockImage id="extendedae:machine_frame" scale="8"></BlockImage>
</Row>

Собрав достаточно <ItemLink id="extendedae:entro_crystal" />, вы наконец сможете создать свою первую расширенную раму машины. Эти фреймы являются основой ExtendedAE, и они требуются большинству блочных машин в ExtendedAE.
