# <a name="me-oversize-interface" />Интерфейс увеличенного размера ME

Интерфейс ME Oversize имеет такое же количество слотов, как и <ItemLink id="extendedae:ex_interface" />, но каждый слот по умолчанию может вмещать в 16 раз больше элементов (настраивается). Это означает, что в каждом слоте может храниться 1024 (64 x 16) предметов.

Определенные множители можно настроить для определенного контента из других модов.
