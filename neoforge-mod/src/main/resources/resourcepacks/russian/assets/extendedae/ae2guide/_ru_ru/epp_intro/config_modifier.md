# <a name="config-modifier" />Модификатор конфигурации

Модификатор конфигурации — это инструмент для массового изменения реестров конфигурации.

<ItemImage id="extendedae:config_modifier" scale="4"></ItemImage>

Щелкните его правой кнопкой мыши, чтобы открыть графический интерфейс.

## <a name="usage" />Использование

Модификатор конфигурации может быстро изменять реестры конфигурации, например инвентарь конфигурации интерфейса, в соответствии с его настройками. Например, он может установить максимальное значение настроенных элементов или удалить их все.

Используйте модификатор конфигурации на целевом устройстве (блоке или подразделе) в мире, чтобы изменить его конфигурацию.

## <a name="settings" />Настройки

Он имеет две основные настройки: **режим модификации** и **количество модификации (X)**.

Нажмите кнопку, чтобы изменить режим.

![графический интерфейс](../pic/cm.png)

- Сложение/вычитание/умножение/деление: сложение, вычитание, умножение или деление каждой настроенной суммы на X.
- Максимизировать: установите для каждой настроенной суммы максимальное значение.
- Минимизировать: установите для каждой настроенной суммы минимальное значение.
- Установить: установите для каждой настроенной суммы значение X.
- Очистить: очистить всю конфигурацию.
