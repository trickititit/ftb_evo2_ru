# <a name="ε-series-tools" />Инструменты серии ε

Серия ε (epsilon) — это наша стандартная линейка инструментов. Все инструменты не ломаются, работают от <Color id="energy">Энергии</Color> и [обновляемый](fundamentals/upgrade_system.md).

Дрель, Лопата, Топор и Мотыга считаются *модульными горнодобывающими инструментами*. Переключение режима оборудования циклически переключает 5 доступных базовых скоростей майнинга:

- **Выкл.**: разрыв блока отключен, в том числе в творческом режиме.
- **Медленно**: 3,0
- **Нормальный**: 9,0
- **Быстро**: 20,0
- **Турбо**: 75,0

Система апгрейда позволяет повысить уровень добычи (лимит) и расширить набор блоков, на которых эффективен инструмент. Лопата, Топор и Мотыга эффективны для соответствующих материалов. Для удобства добычи бур эффективен как для *кирки*, так и для *лопаты*.

> Модуль обновления Shovel ε-Series по умолчанию предоставляет Silk Touch.

## <a name="compatible-upgrades" />Совместимые обновления

### <a name="all-ε-series-tools" />Все инструменты серии ε

- **Resonance-Настроенные сервоприводы**: максимальный ранг 1. Подавляет вибрации, которые излучает удерживаемый инструмент.
- **Батарея дополненного оборудования**: Максимальный ранг 4. Умножает энергоемкость на 4 на ранге 1, удваивая каждый ранг до 32x на ранге 4. Также подходит для [Броня АЛ/1С](armor.md).

### <a name="mining-tools" />Горные инструменты

Дрель, лопата, топор, мотыга, ножницы и гаечный ключ.

- **Разогнанная матрица урожая**: максимальный ранг 5. Применяет Фортуну на уровне 1, 2, 3, 5 или 7 в зависимости от ранга.
- **Стабилизированная матрица урожая**: максимальный ранг 1. Применяет Шелковое прикосновение.
- **Связь с подпространством для добычи полезных ископаемых**: максимальный ранг 1. Отправляет сломанные блоки прямо в ваш инвентарь.

> Две матрицы урожая имеют общий эксклюзивный набор. Инструмент может нести Фортуну или Шелковое касание, но не то и другое.

### <a name="modular-mining-tools" />Модульные инструменты для добычи полезных ископаемых

Дрель, лопата, топор и мотыга.

- **ε Cutter Rev.000**: Максимальный ранг 1. Делает инструмент эффективным на каждом блоке, помимо собственного набора материалов.

### <a name="single-tool-modules" />Отдельные инструментальные модули

- **Старатель Нанитов**: Максимальный ранг 1. ε Бур. В жилах добывается до 64 руд одновременно, тратя дополнительную энергию на каждый дополнительный блок.
- **Отдел лесозаготовок**: Максимальный ранг 1. ε Топор. Валит до 256 бревен одновременно вместе с окружающими листьями без дополнительных затрат энергии.
- **ε Набор рыболова**: Максимальный ранг 5. ε Удочка. Применяет «Приманку» и «Морскую удачу» установленного ранга.

### <a name="melee-weapons" />Холодное оружие

ε Sword и ε Axe также являются частью `#ltxi:weapons`, поэтому они принимают модули со стороны оружия: протокол боевой мощности, алгоритм разрыва, связь боевого подпространства, биометрическое запутывание и три протокола взаимодействия. См. [Оружие](weapons/index.md), чтобы узнать, что делает каждый из них.
