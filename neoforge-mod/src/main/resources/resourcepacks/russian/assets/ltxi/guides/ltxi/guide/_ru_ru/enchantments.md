# Чары

## Бритва

- Совместим с: `#minecraft:enchantable/sharp_weapon`
- Максимальный уровень стола зачарования/наковальни: 3.

Чары Бритвы в первую очередь служат для сбора голов с побежденных мобов. Из некоторых врагов может выпасть дополнительная добыча.

### Обезглавливание толпы

- Шанс выпадения стандартных голов/черепов составляет 10% за уровень.
- **Только уровень 4+**: 50% шанс за каждый уровень после 4-го уровня выронить голову Эндер Дракона.

### Разная добыча

- 33% шанс выпадения кроличьей лапки за уровень из побежденных кроликов.
