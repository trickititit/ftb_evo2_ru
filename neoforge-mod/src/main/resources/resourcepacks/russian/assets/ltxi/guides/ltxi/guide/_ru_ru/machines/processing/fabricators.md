# Технологическое производство

Некоторые улучшения и снаряжение слишком сложны, чтобы их можно было изготовить на обычных обрабатывающих машинах или верстаке.
Для этого вам нужно будет создать Фабрикатор. Рецепты изготовления уникальны среди всех типов рецептов LTXI, проконсультируйтесь
спецификации данных рецепта ниже.

## Спецификация рецепта
- Входы: 1–16 предметов.
- Выход: 1 предмет
- Стоимость энергии: варьируется в зависимости от рецепта, **используется вместо времени изготовления**

Из-за нехватки времени на изготовление скорость Фабрикатора представляет собой гораздо более простую функцию стоимости энергии по рецепту и
**Потребление энергии**. Статистика машины. Вы можете считать это положительным показателем для этой машины.

## Автопроизводитель
<BlockImage id="auto_fabricator" scale="2" />

Более специализированная версия Фабрикатора. Отсутствие разнообразия рецептов компенсируется простотой автоматизации. В отличие от
Обычный производитель имеет 16 слотов для ввода ингредиентов, которые нельзя получить из инвентаря.

### Единая операция на основе чертежа

Поместите закодированный чертеж изготовления в слот для чертежей, чтобы работать в этом режиме. Вы должны предоставить правильный ингредиент
суммы с помощью предпочитаемого вами способа транспортировки товара. Пока у него достаточно ингредиентов и энергии, он будет постоянно
создайте рецепт чертежа.

### AE2 Интеграция с поставщиком шаблонов
**Поставщики шаблонов** компании AE2 имеют встроенную совместимость с Автопроизводитель и закодированными чертежами изготовления. **Примечание!
Слот для чертежей должен быть пустым, иначе поставщик выкроек не распознает Автопроизводитель как допустимое изделие.
машина.**

- Чертежи — это шаблоны. Вставьте их непосредственно в слоты шаблонов поставщика шаблонов, нет необходимости в шаблонах обработки.
- По умолчанию поддерживается составной ингредиент/тег/замена.
- В режиме блокировки нет необходимости, подача предметов и чертежей осуществляется автоматически.
- Конфигурация ввода-вывода элемента переконфигурируется при каждой отправке шаблона. Он будет автоматически выводиться на стороне поставщика шаблонов и отключать все остальное.

## Совместимые обновления

Устанавливается через [Система обновления](../../fundamentals/upgrade_system.md).

- **Усовершенствованная головка инструмента**: максимальный ранг 4. Умножает потребление энергии на 4 на 1-м уровне, удваивая каждый уровень.
  до 32x на 4-м ранге, а также соответствующим образом увеличивает энергоемкость и скорость передачи. Поскольку Фабрикатор
  Скорость зависит от потребления энергии, более высокие ранги создают быстрее.

> Подходит как для производителя, так и для автоматического производителя. Ни один из них не является частью
> `#ltxi:upgradable/standard`, поэтому блок питания Σ/VM3 к ним не подходит.
