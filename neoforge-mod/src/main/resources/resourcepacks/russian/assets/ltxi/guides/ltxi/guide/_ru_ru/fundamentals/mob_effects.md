# Эффекты мобов (Эффекты зелий)

## Обморожение
Обморожение замедляет цели. Он также замораживает их на время действия эффекта.
### Модификаторы атрибутов
- Скорость атаки: -25% x уровень эффекта.
- Скорость передвижения: -25% x уровень эффекта.
- Скорость полета: -25% x уровень эффекта.
- Скорость копания: -25% x уровень эффекта.

-------

## Разъедающий
Коррозия ослабляет броню цели.
### Модификаторы атрибутов
- Броня: -33% x уровень эффекта.
- Прочность брони: -33% x уровень эффекта.

-------

## Мрак
Мрак уменьшает *весь* урон от атак цели, пока его можно проследить до нее. Кроме того,
затронутая цель не может применять эффекты зелий в течение срока действия эффекта.

### Модификаторы атрибутов
- `limacore:damage_multiplier`: -25% x уровень эффекта.
