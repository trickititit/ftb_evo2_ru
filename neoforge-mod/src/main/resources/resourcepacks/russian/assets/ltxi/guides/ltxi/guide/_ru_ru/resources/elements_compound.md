# Сложные элементы

Некоторые элементарные соединения обнаруживаются или легко доступны из природных ресурсов. Как и базовые элементы, они могут быть
добывается с помощью некоторой машинной обработки.

## Метан

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:methane', amount:16000}" scale="2" />

Метан — это богатый углеводородный газ, обнаруженный в болотах земного мира. Требуется [Атмосферный скруббер](../machines/resource/atmospheric_scrubber.md)
собирать урожай. Это эффективный источник топлива, а также сырье для современных полимеров и силиконовых соединений.

## сульфурин

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:sulphurine', amount:16000}" scale="2" />

Сульфурин — атмосферный газ Незера. Невероятно сухие условия Незера позволяют этому газу оставаться
стабилен и не распадается на элементарную серу. [Химическая лаборатория](../machines/processing/chem_lab.md) может реагировать с серой.
с водой с образованием серной кислоты, а также используется для отверждения силиконового масла в резину.

## Морская вода

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:sea_water', amount:16000}" scale="2" />

Вода из океанов Верхнего мира имеет высокую концентрацию хлора из морской флоры. Атмосферный скруббер может
собирать воду из океана, и впоследствии хлор можно будет извлечь с помощью [Электроцентрифуга](../machines/processing/electrocentrifuge.md).

## Аммиак

<ItemImage id="portable_tank" components="limacore:fluid={id:'ltxi:ammonia', amount:16000}" scale="2" />

Аммиак — токсичное азотно-водородное соединение, используемое для выращивания некоторых экзотических растений в [Био/АРУ Сад](../machines/resource/digital_garden.md)
и для мрачного газового оружия. Что еще более важно, он используется на линии по переработке металлического рения.
