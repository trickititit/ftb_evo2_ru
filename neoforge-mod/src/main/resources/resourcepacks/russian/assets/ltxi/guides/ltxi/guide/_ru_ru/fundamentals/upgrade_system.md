# Система обновления LTXI

Оборудование LTXI (инструменты, броня, оружие) и машины можно значительно модернизировать с помощью нашей системы обновлений.

## Обновление модулей

<ItemImage id="upgrade_module" />

Эти маленькие ребята имеют рейтинговое обновление. Удерживайте Shift на элементе модуля, чтобы увидеть его название, ранг,
всплывающие подсказки эффектов и то, на что их можно установить. Хотя большинство обновлений будут эксклюзивными либо для предметов снаряжения, либо для
машины, некоторые совместимы с обоими. Например, модули улучшения боевых чар совместимы с
как вооружение, так и турели.

## Установка на машины

![](../assets/machine_upgrades_button.png)

Управление обновлением встроено в обновляемые машины. Кнопка будет самой верхней опцией на правой боковой панели.

## Установка на оборудование

<BlockImage id="upgrade_station" scale="2.5" />

Для настройки обновлений оборудования вам понадобится **Станция обновления**. Вставьте предмет снаряжения в слот для снаряжения.
изменить его обновления.
