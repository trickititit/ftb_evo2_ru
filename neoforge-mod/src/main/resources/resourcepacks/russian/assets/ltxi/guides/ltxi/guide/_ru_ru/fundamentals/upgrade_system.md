# <a name="ltxi-upgrade-system" />Система обновления LTXI

Оборудование LTXI (инструменты, броня, оружие) и машины можно значительно модернизировать с помощью нашей системы обновлений.

## <a name="upgrade-modules" />Обновление модулей

<ItemImage id="upgrade_module" />

Эти маленькие ребята имеют рейтинговое обновление. Удерживайте Shift на элементе модуля, чтобы увидеть его имя, ранг, всплывающие подсказки по эффектам и то, на что его можно установить. Хотя большинство обновлений будут эксклюзивными либо для оборудования, либо для техники, некоторые из них совместимы и с тем, и с другим. Например, модули улучшения боевых чар совместимы как с вооружением, так и с турелями.

## <a name="installing-on-machines" />Установка на машины

![](../assets/machine_upgrades_button.png)

Управление обновлением встроено в обновляемые машины. Кнопка будет самой верхней опцией на правой боковой панели.
