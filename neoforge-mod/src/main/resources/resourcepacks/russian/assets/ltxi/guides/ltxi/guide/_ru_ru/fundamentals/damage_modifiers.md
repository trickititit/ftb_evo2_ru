# Глобальные модификаторы урона
Не каждое оружие будет хорошо работать в любом сценарии. Некоторое оружие будет бороться с определенными типами врагов.
Например, оружие основного типа будет наносить уменьшенный урон врагам со средней и высокой угрозой.

## Порядок подачи заявки
Глобальные модификаторы урона применяются **после всех обновлений**.

## Таблица модификаторов урона

| Оружие(а) | Тип цели | Модификатор |
|-------------|---------------|----------|
| Легкий | Высокая угроза | -80% |
| Легкий | Средняя угроза | -50% |
| Специалист | Высокая угроза | -40% |
| Специалист | Средняя угроза | -25% |
