# Пасхальные яйца

Несколько фиктивных прозвищ (и один трюк с предметом) делают что-то особенное. Псевдонимы не чувствительны к регистру.

---

## Только звуковые прозвища

Эти манекены воспроизводят собственный звук удара вместо звука по умолчанию.

- Топииньо
- Данрике
- МитиньоИгрок
- ДжазараГеймер
- Джазаринья
- Нофаксу
- мамао170
- МейоЭльфо
- БрунимНеец
- ForeverPlayerG
- Ле_Рай
- Гетоксиз

---

## Псевдонимы, которые делают больше

### Бессмертный

Переименуйте манекен в «Бессмертный» и поместите его. Название может немного ввести в заблуждение.

<br />

### Хиробрин

Все знают, что нельзя называть манекен «Херобрин». Не будьте тем, кто узнает, почему.

<br />

### Джек о'Лантерн

Некоторым чайникам просто нужен фонарь Джека вместо головы. Попробуйте передать один.
