# Тренировочный манекен

Настраиваемый боевой манекен для проверки урона, снаряжения и модов — бросьте его, ударьте и читайте.
цифры.

- **Поместите** генератор манекенов на землю, чтобы вызвать манекен.

- **Ударьте** чем угодно, чтобы увидеть цифры урона, отображаемые в чате или на экране (настраивается).

- **Щелкните правой кнопкой мыши палкой**, чтобы открыть инвентарь (броня, сувениры, здоровье, настройки отображения).

- **Ударьте его палкой**, чтобы удалить — из него выпадет спаунер, который можно положить обратно.

- **Переименуйте его** (на наковальне, с именной меткой), чтобы придать ему настоящий скин Minecraft игрока.

- **Размещение одного загруженного генератора манекенов** в любой сетке крафта сбрасывает его здоровье/имя/
  настройки дисплея, но сохраняет все, что помнит.

## Отображение урона

Каждый манекен может отображать входящий урон в виде **Общего**, **Урона** или **За удар** — устанавливается для каждого манекена.
не глобально.

При каждом попадании также указывается тип урона (Огонь, Замораживание, Взрыв, Молния, Магия), когда он
это не просто физическое повреждение.
