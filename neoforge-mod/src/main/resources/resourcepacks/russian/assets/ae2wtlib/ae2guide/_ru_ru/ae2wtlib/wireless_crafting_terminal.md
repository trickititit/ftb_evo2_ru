# <a name="wireless-crafting-terminal" />Беспроводной терминал для крафта

<ItemImage id="ae2:wireless_crafting_terminal" scale="3" />

<ItemLink id="ae2:wireless_crafting_terminal" /> — это [беспроводной](wireless_terminals.md) версия <ItemLink id="ae2:crafting_terminal" />. AE2WTLib добавляет автоматический [пополнение запасов](restock.md) из сети ME и позволяет выбирать блок для рисования элементов из сети ME. С <ItemLink id="ae2wtlib:magnet_card" /> он также действует как магнит.

Его можно объединить с другими [Беспроводные терминалы](wireless_terminals.md) в <ItemLink id="ae2wtlib:wireless_universal_terminal" />.

AE2WTLib расширяет функциональность Minecraft `Pick Block`: он будет извлекать предметы из сети, если их невозможно найти в вашем инвентаре. (Он также попытается сохранить предметы, если ваш текущий слот окажется заполнен)

## <a name="upgrades" />Обновления

<ItemLink id="ae2:wireless_crafting_terminal" /> поддерживает следующий [обновления](ae2:items-blocks-machines/upgrade_cards.md):

*   <ItemLink id="ae2:energy_card" /> для увеличения емкости аккумулятора
*   <ItemLink id="ae2wtlib:quantum_bridge_card" />, что позволяет терминалу иметь неограниченный радиус действия даже в разных измерениях и автоматически заряжает терминал от сети ME. 
*   <ItemLink id="ae2wtlib:magnet_card" />, чтобы добавить функцию магнита
