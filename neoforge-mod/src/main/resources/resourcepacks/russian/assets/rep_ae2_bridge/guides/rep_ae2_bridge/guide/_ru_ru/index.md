# <a name="replication-ae2-bridge" />Replication AE2 Мост

Этот аддон соединяет **Applied Energistics 2** с **Replication**. Материя из сети Replication может жить в вашей МЕ-системе, а AE2 может попросить Replication создать для вас предметы.

## <a name="contents" />Содержание

* [AE2–Replication Мост](bridge.md) — связывает сети, распределение энергии и приоритеты.
* [Сборщик Материи](matter_assembler.md) — быстрый AE2 работник, выполняющий Replication задания
* [Хранение материи](matter_storage.md) — ячейки, шины, мониторы и кодировка элемента → материи.
