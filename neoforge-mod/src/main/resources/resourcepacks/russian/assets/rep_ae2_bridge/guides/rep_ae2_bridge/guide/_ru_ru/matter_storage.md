# <a name="matter-storage" />Хранение материи

<Row gap="20">
<ItemImage id="rep_ae2_bridge:matter_storage_cell_1k" scale="4"></ItemImage>
<ItemImage id="rep_ae2_bridge:matter_storage_cell_4k" scale="4"></ItemImage>
<ItemImage id="rep_ae2_bridge:matter_storage_cell_16k" scale="4"></ItemImage>
</Row>

Ячейки хранения материи хранят Replication материю внутри вашей **МЕ-системы**, подобно тому, как обычные ячейки хранят предметы. При подключении Моста материя в этих ячейках также доступна сети материи.

## <a name="cells-and-housing" />Клетки и жилье

- Создайте ячейки из **Жилья Материи** и соответствующего компонента ячейки AE2 (1k / 4k / 16k / 64k / 256k).
- Емкость соответствует этому компоненту — более крупные компоненты содержат больше вещества
- Вы также можете создать ячейку за один шаг, используя образец корпуса и компонент в центре.
- **Ячейка для хранения творческих материалов** содержит неограниченное количество материалов каждого типа (творческих/тестовых).

Поместите ячейки в накопители или сундуки ME, как и любую другую ячейку хранения. Терминалы могут фильтровать тип Материи отдельно от предметов и жидкостей.

## <a name="import,-export,-and-storage-bus" />Импорт, экспорт и шина хранения

AE2 **Импортный автобус**, **Экспортный автобус** и **Хранительный автобус** могут перемещать материю к соседним Replication **резервуарам материи** и **Дезинтеграторам**, когда этот аддон загружен. Включите тип ключа Matter на шине, как и для жидкостей.

**Шина хранения** на резервуаре для материалов **перечисляет** содержимое резервуара в ME-системе и может вставлять или извлекать вещества (в двух направлениях). Импортный автобус тянет танк → ME; Экспортный Автобус толкает МЕНЯ → танк.

## <a name="disintegration-patterns-(item-→-matter)" />Паттерны распада (предмет → материя)

В **Терминале кодирования шаблонов** используйте дополнительную вкладку **Материя** (значок чертежа):

- Поместите элемент на вход (увеличьте счетчик для масштабирования выходов)
- Панель предварительного просмотра количества материалов (недоступно для выбора)
- Кодирование создает обычный AE2 **шаблон обработки**

Поместите этот шаблон в **Поставщик шаблонов** напротив **Дезинтегратора**. Вытащите полученную материю с помощью **Импортной шины** (или Шины хранения) на Дезинтеграторе. Мост также отражает материю из сети Replication в МЕНЯ как запас.

## <a name="jei-matter-items" />JEI важные предметы

Предметы виртуальной материи из этого аддона являются JEI помощниками. Перетаскивание их в фильтры AE2 или мониторы автоматически настраивает настоящий ключ **Matter**.

## <a name="storage-monitors" />Мониторы хранения

Щелкните правой кнопкой мыши разблокированный **Монитор хранилища**, удерживая Replication **Резервуар материи** или предмет виртуальной материи:

- Заполненный резервуар/предмет материи → тип этой материи
- Пустой бак на пустом мониторе → AE2 настраивает сам пункт бака
- Опорожните резервуар, когда что-то уже установлено → сначала введите тип материала, затем цикл.

## <a name="autocrafting-and-matter-visibility" />Автокрафт и видимость материи

С помощью Моста AE2 ремесленные работы оставляют материю, не вытягивая ее из МЕНЯ. Запасы остаются в камерах/цистернах/автобусах, поэтому Replication может их видеть; настоящий слив происходит, когда шаблон работает. Отмена очищает фантомное резервирование и не дублирует материал.

## <a name="tips" />Советы

- Материя, показанная через Мост, и материя, хранящаяся в клетках, представляют собой один и тот же пул для Replication машин, использующих Мост.
- Для автомобильных работ, требующих вывода, требуется шина импорта/хранения на дезинтеграторе; Только зеркало моста показывает запас, но не завершает сбор выходных данных поставщика шаблонов.
- Сохраняйте достаточно места в ячейках, если перемещаете большие количества материи через AE2
