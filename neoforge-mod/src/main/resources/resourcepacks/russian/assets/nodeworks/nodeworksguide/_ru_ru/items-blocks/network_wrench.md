# <a name="network-wrench" />Сетевой ключ

Сетевой ключ позволяет корректировать форму сети, ничего не нарушая. Он переключает отдельные соединения труб между блоками и соединениями <ItemLink id="focus_node" /> на расстоянии.

<ItemImage scale="6" id="network_wrench" />

## <a name="toggling-pipe-connections" />Переключение соединений труб

Shift + щелкните правой кнопкой мыши любую грань, где соприкасаются два сетевых блока, чтобы переключить патрубок трубы между ними. Блоки остаются на своих местах, но сеть рассматривает сторону так, как будто там нет трубы.

Это повседневное использование гаечного ключа. Несколько распространенных причин для этого:

- Держите <ItemLink id="node" /> рядом с <ItemLink id="pipe" />, чтобы они не сливались в одну сетевую ветвь.
- Разделите одну сеть на две, отключив одну грань трубы.
- Не позволяйте <ItemLink id="terminal" /> или устройству обнаружить случайное подключение к соседней сети.

Повторите действие на том же лице, чтобы восстановить соединение.

## <a name="linking-focus-nodes" />Связывание узлов фокуса

<ItemLink id="focus_node" /> являются исключением. Два узла фокусировки могут быть
подключен на расстоянии с помощью гаечного ключа:

1. Shift + щелкните правой кнопкой мыши узел фокуса на грани, которая не соприкасается
   другой сетевой блок, чтобы выбрать его в качестве ожидающего источника. Блок получит рамку, чтобы показать, что он выбран.
2. Щелкните правой кнопкой мыши другой узел фокуса, чтобы переключить связь между ними.

Выбор сохраняется после успешной связи, поэтому вы можете связать один источник со многими целями без повторного выбора между ними.

### <a name="rules" />Правила

- Оба узла фокуса должны находиться в том же измерении, что и выбранный.
- Они должны принадлежать **одному сетевому контроллеру**. Гаечный ключ не соединит две отдельные сети.

Ключ сообщит вам, какое правило не выполнено, через сообщение в чате.
