# <a name="card-programmer" />Карточный программист

Программатор карт используется для копирования настроек из шаблона [Карта](../nodeworks-mechanics/cards.md).

<ItemImage scale="6" id="card_programmer" />

## <a name="using-it" />Используя его

Щелкните правой кнопкой мыши предмет в вашей руке, чтобы открыть графический интерфейс, и вы увидите два слота.

- **Шаблон (слева):** добавьте [Карта](../nodeworks-mechanics/cards.md), настройки которого
вы хотите скопировать (карта не используется)
- **Цель (справа):** добавьте карточку для настройки, цель получит шаблон
настройки

![](../assets/images/card_programmer_gui.png)

Вы также заметите две кнопки переключения для копирования имени шаблона и канала.

> **Примечание.** Любая карта, которую уронили или нажали клавишу «Shift» + щелкнули в слот «Цель», немедленно вернется в ваш инвентарь после завершения копирования.
