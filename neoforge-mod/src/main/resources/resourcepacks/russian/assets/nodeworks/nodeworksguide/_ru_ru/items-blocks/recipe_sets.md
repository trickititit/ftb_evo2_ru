# <a name="recipe-sets" />Наборы рецептов

Существует два типа наборов рецептов, которые используются для хранения рецептов крафта, используемых в [автокрафтинг](../nodeworks-mechanics/autocrafting.md).

Наборы рецептов — это элементы шаблона, в которых хранится один рецепт для выполнения системой [автокрафтинг](../nodeworks-mechanics/autocrafting.md). Каждый набор создается в собственном графическом интерфейсе, а затем помещается в соответствующий [Блок хранения](./storage_blocks.md)

Существуют два вкуса, охватывающие два типа рецептов:

- **Набор инструкций:** рецепты крафта ванильных фигурок 3x3 (формовых и бесформенных)
- **Набор обработки:** все остальное (плавка, модифицированные машины, процессы с несколькими выходами и все, что имеет тайм-аут)

---

## <a name="instruction-set" />Набор инструкций

<ItemImage scale="4" id="instruction_set" />

Шаблон для изготовления 3х3. Все, что работает на ванильном верстаке, работает и здесь.

### <a name="creating-a-recipe" />Создание рецепта

Щелкните правой кнопкой мыши, чтобы открыть. Нажмите на призрачный слот с предметом в руке, чтобы закрепить там призрачную копию (без потребления инвентаря), снова щелкните пустой слот, чтобы очистить. Ячейка результата автоматически заполняется всякий раз, когда выкройка соответствует известному рецепту крафта. **Очистить все** сбрасывает сетку.

В графическом интерфейсе также есть переключатель **замены тегов**. Если включено (по умолчанию), рецепт принимает любой предмет из того же тега, что и закрепленный ингредиент, поэтому в слоте дубовой доски с радостью будет использоваться береза, ель или что-нибудь еще в `#minecraft:planks`. Выключите его, чтобы зафиксировать в рецепте точные идентификаторы предметов.

> **Совет:** кнопка **(+)** рецепта JEI работает в этом графическом интерфейсе, поэтому вы можете выбрать любой рецепт крафта > в JEI и нажать (+), чтобы заполнить сетку за один шаг.

### <a name="deploying-it" />Развертывание

Поместите заполненный набор в <ItemLink id="instruction_storage" />. Соседние хранилища инструкций образуют кластер. Каждый Set в кластере виден процессору, пока *любой* блок в кластере находится в сети.

## <a name="processing-set" />Набор обработки

<ItemImage scale="4" id="processing_set" />

Рецепт произвольной формы с 9 входами и 3 выходами, а также дополнительным тайм-аутом для каждого ремесла. Используйте его для всего, что сетка 3×3 не может выразить (выплавка, взрывная обработка, модифицированные рецепты машин, процессы с несколькими выходами или что-то еще, где *"Проходит N тиков, прежде чем появится результат"*)

### <a name="creating-a-recipe" />Создание рецепта

Щелкните правой кнопкой мыши, чтобы открыть. Графический интерфейс имеет:

- **Сетка входов**: (3×3) призрачных слота для любых входов в любом положении.
- **Столбец вывода**: (3 слота) — призрачные слоты для выходов.
- **Поле тайм-аута**: 0–999 тиков (0 = тайм-аут отсутствует). Кнопки `+` и `-` с шагом 20, нажатием клавиши Shift с шагом 100.
- **Последовательный переключатель**: когда он включен, процессор не будет запускать этот рецепт параллельно с самим собой.
- **Переключатель замен**: когда этот параметр включен, ввод, заполненный из рецепта тега (его слот циклически проходит через элементы тега), принимает любой элемент в этом теге, и каждый ввод принимает любой компонентный вариант своего элемента. Выкл. фиксирует рецепт только для показанных элементов.
- **Очистить все**: сбрасывает все.

Количество слотов регулируется путем прокрутки заполненного слота (прокрутка вверх +1, прокрутка вниз -1, прокрутка вниз при 1 очищается).

> **Совет:** **(+)** JEI здесь тоже работает, и он *универсален*. Любая категория рецептов, о которой JEI > знает (выплавка/струйная обработка/модификация), является честной игрой. Ввод JEI показывает несколько элементов >, например, типы песка в `#minecraft:smelts_to_glass`, записанные как этот тег >, поэтому при замене в рецепте используется любой элемент, который у вас есть или который вы можете создать.

### <a name="deploying-it" />Развертывание

Поместите заполненный набор в <ItemLink id="processing_storage" />. Как и хранилище инструкций, соседние хранилища обработки образуют кластер. ЦП координирует свои действия с той внешней машиной, которая фактически выполняет рецепт.
