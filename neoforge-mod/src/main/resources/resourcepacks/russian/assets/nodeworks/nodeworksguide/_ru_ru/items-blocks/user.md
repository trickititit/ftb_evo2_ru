# <a name="user-block" />Пользовательский блок

Пользователь вытаскивает элемент из [Сетевое хранилище](../nodeworks-mechanics/network-storage.md) и щелкает им правой кнопкой мыши по всему, что находится перед блоком. Используйте его для измельчения урожая, чистки подозрительных блоков, поджигания трота кремнем и сталью, наполнения ведер или чего-то еще, что игрок обычно делает вручную.

## <a name="placing" />Размещение

Лицевая сторона пользователя указывает на то, во что вы целились, когда помещали его (такая же форма, как у поршня или дозатора). Он нацелен на первый невоздушный блок на расстоянии до двух позиций перед собой, поэтому пользователь над пустым пространством над урожаем все равно достигает урожая.

## <a name="item-filter" />Фильтр предметов

В графическом интерфейсе пользователя есть слот для элемента, который он должен использовать. Соответствующий элемент извлекается из сетевого хранилища при запуске пользователя и возвращается после завершения действия. Синтаксис фильтра такой же, как и у

## <a name="mode" />Режим

Пользователь работает в одном из двух режимов:

- **Мгновенно**: один щелчок правой кнопкой мыши за пожар. Подходит для одноразовых действий, таких как применение костной муки или кремня и стали.
- **Удерживать**: удерживает щелчок правой кнопкой мыши нажатой до тех пор, пока он не будет отпущен. Подходит для инструментов, которые нужно держать в руках, например, для кисти. Удержание автоматически снимается через 30 секунд.

## <a name="redstone" />Редстоун

Настройка красного камня графического интерфейса определяет, когда пользователю разрешено стрелять:

- **Высокий**: активен при включении.
- **Низкий**: активен при отсутствии питания.
- **Игнорируется**: красный камень ничего не делает. Пользователь срабатывает только тогда, когда к нему обращается скрипт.

## <a name="channel" />Канал

В графическом интерфейсе пользователя есть средство выбора имени и канала. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel), чтобы узнать, как каналы определяют, какие сценарии могут обращаться к этому устройству.
