# <a name="placer-block" />Россыпной блок

Placer размещает блочные элементы в позиции перед собой. Скрипт выбирает, что разместить, по идентификатору элемента или путем передачи [ПредметыРучка](../lua-api/items-handle.md), затем соответствующий элемент извлекается из [Сетевое хранилище](../nodeworks-mechanics/network-storage.md) и помещается. В синхронном режиме сценарий получает `true`/`false` в том же тике, который он запрашивал.

## <a name="placing" />Размещение

Передняя грань россыпи направлена туда, куда вы целились, когда ее устанавливали (такая же форма, как у поршня или дозатора). Какой бы блок ни создавал Россыпь, он приземляется прямо перед этим лицом. Работают только предметы блочной формы, инструменты, еда и разные предметы не выдержат испытания на месте.

## <a name="block-filter" />Блокировать фильтр

В графическом интерфейсе Placer есть слот для блока, который он должен разместить. Соответствующий предмет извлекается из [Сетевое хранилище](../nodeworks-mechanics/network-storage.md) каждый раз, когда срабатывает Россыпь. Оставьте его пустым, пока скрипт не запросит что-то конкретное.

## <a name="redstone" />Редстоун

Настройка красного камня в графическом интерфейсе определяет, когда Placer может срабатывать:

- **Высокий**: активен при включении.
- **Низкий**: активен при отсутствии питания.
- **Игнорируется**: красный камень ничего не делает. Placer срабатывает только тогда, когда к нему обращается скрипт.

## <a name="channel" />Канал

В графическом интерфейсе Placer есть средство выбора имени и канала. См. [Выбор канала](../lua-api/channel.md#choosing-a-channel), чтобы узнать, как каналы определяют, какие сценарии могут обращаться к этому устройству.
