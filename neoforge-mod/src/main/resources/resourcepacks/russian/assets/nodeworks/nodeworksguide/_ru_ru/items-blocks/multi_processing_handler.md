# <a name="multi-processing-handler" />Многопроцессорный обработчик

<ItemLink id="processing_handler" />, который обрабатывает множество рецептов [Набор обработки](./recipe_sets.md#processing-set) одновременно. Привяжите несколько рецептов руды к одному Обработчику перед группой печей, и [Процессор создания](./crafting_cpu.md) направляет каждое ремесло через него, без Lua и без Обработчика на рецепт.

> Для использования требуется <ItemLink id="network_controller" />

## <a name="two-sides" />Две стороны

Та же форма, что и у обработчика обработки: **задняя сторона** присоединяется к родительской сети, **передняя сторона** закрепляет вокруг машин собственную микросеть из каналов, узлов и карт памяти. См. [Две стороны
](./processing_handler.md#two-sides) для макета.

## <a name="choosing-recipes" />Выбор рецептов

Щелкните правой кнопкой мыши обработчик, чтобы открыть его графический интерфейс. В нем перечислены все наборы обработки в родительской сети с флажком. Отметьте те, которые должен принять этот обработчик. Рецепты, отмеченные галочкой, сортируются вверху, а поле поиска сужает список по рецепту или названию элемента.

Счетчик в углу показывает, сколько человек исчерпало лимит. Рецепт, которым уже владеет скрипт или другой обработчик, становится серым, как и все остальное, когда предел достигнут.

Рецепт, отмеченный галочкой, который позже будет удален из хранилища обработки, останется в списке, отмеченном как отсутствующий, поэтому вы можете снять с него галочку. Он возвращается к жизни, если Сет возвращается.

## <a name="channels" />Каналы

Один входной канал и один выходной канал, общие для каждого рецепта. Ингредиенты любого отмеченного рецепта попадают в <ItemLink id="storage_card" />s в микросети с входным цветом, готовые выходные данные извлекаются из карточек с выходным цветом. Для банка печей это одна синяя карта вверху каждой печи и одна красная карта внизу.

Каждый ингредиент поступает по одному и тому же каналу, поэтому сортировка происходит на карточках. Дайте каждой Карте Хранения [фильтр
](./storage_card.md#filters), и только соответствующие предметы попадут в ее блок: карта на стороне каждой печи, которая позволяет `#c:coal` брать топливо, карта сверху, которая запрещает брать руду, обе на синем канале.

## <a name="parallel-mode" />Параллельный режим

По умолчанию Обработчик запускает одно ремесло за раз, поэтому два рецепта из одного и того же дерева крафта выстраиваются в очередь, а не сражаются за одни и те же печи, а ожидающий его сопроцессор переходит к работе над чем-то другим. Если вы хотите изменить это, вы можете нажать тумблер **Параллельно**, который позволяет выполнять поделки параллельно.

![](../assets/images/parallel_toggle.png)

## <a name="compared-to-the-processing-handler" />По сравнению с обработчиком обработки

Используйте <ItemLink id="processing_handler" />, когда для одного рецепта требуется своя машина или собственный канал для каждого ингредиента. Используйте обработчик многопроцессорной обработки, когда многие рецепты используют один машинный банк и все маршрутизируются одинаково.
