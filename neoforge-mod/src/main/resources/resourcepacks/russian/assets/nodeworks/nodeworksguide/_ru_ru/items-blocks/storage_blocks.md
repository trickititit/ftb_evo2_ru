# <a name="recipe-storage-blocks" />Блоки для хранения рецептов

Блоки хранения — это место, где вы сохраняете заполненные [Наборы рецептов](./recipe_sets.md) после того, как они прочитаны, для использования <ItemLink id="crafting_core" />. Щелкните правой кнопкой мыши, чтобы открыть, поместите наборы рецептов в слоты, и все готово.

Каждый тип набора рецептов имеет свой собственный блок хранения.

- **Хранилище инструкций:** содержит наборы инструкций.
- **Хранилище обработки:** содержит наборы обработки.

## <a name="how-they-work" />Как они работают

Подключите блок хранения к узлу, и каждый набор рецептов внутри него станет видимым для ЦП.

<GameScene zoom="3.5" interactive={true} paddingTop="20" paddingLeft="50" paddingRight="60">
  <ImportStructure src="../assets/assemblies/processing_storage_cluster.snbt" />
  <BoxAnnotation min="0 0 0" max="3 1 1">
    Кластер **подключенных** хранилищ обработки экспортируется вместе, поскольку они соприкасаются.
  </BoxAnnotation>
</GameScene>

Блоки хранения также можно размещать рядом друг с другом, образуя кластер. Вам нужно только соединить **один** блок в кластере, а остальные — через общие грани. Разбейте блок, соединяющий две половины, и группа снова разделится на две части, каждая из которых самостоятельно определит, достижима ли она еще. Излучающее свечение блока соответствует цвету сети, к которой он принадлежит, поэтому с первого взгляда вы можете определить, какая группа куда идет.

## <a name="clustering-recipe-storage-blocks" />Кластеризация блоков хранения рецептов

Если у вас есть один блок хранения рецептов, подключенный к сети, все соседние блоки хранения рецептов будут группироваться вместе и также подключаться к сети.
