# <a name="me-requester" />ME-запросчик

<Row>
  <ItemImage id="requester" scale="3"/>
  <ItemImage id="requester_terminal" scale="3"/>
</Row>

Дополнение, которое автоматически поддерживает запас предметов и жидкостей в вашей [ME-сети](ae2:getting-started.md#your-very-first-me-system).
<br/>

## <a name="getting-started" />С чего начать

Для начала поместите <ItemLink id="requester"/> и подключите его к своей сети. Обязательно подключите его к той же сети, в которой находится ваша логика [Автокрафт](ae2:ae2-mechanics/autocrafting.md). Она должна содержать ваши [Процессор создания](ae2:ae2-mechanics/autocrafting.md#the-crafting-cpu) и <ItemLink id="ae2:pattern_provider"/>.

<RecipeFor id="requester"/>

Чтобы <ItemLink id="requester"/> работал, вам необходимо убедиться, что предметы или жидкости, которые вы хотите держать на складе, имеют образец и также могут быть созданы, если вы запросите их как игрок. Это автоматизирует только сам запрос. Крафтом занимается [ME-сеть](ae2:getting-started.md#your-very-first-me-system).
<br/>

## <a name="configuration" />Конфигурация

При первом открытии <ItemLink id="requester"/> вы увидите обзор настроек запроса. Количество слотов, которые может разместить один блок, регулируется в конфигурации. Каждая строка графического интерфейса представляет собой отдельный запрос.
<br/>

### <a name="toggle-switch" />Тумблер

Флажок слева переключает запрос, настроенный в этой строке. Когда запрос отключен, никакие проверки выполняться не будут, и запас вашего запроса не будет поддерживаться.<br/> Это можно использовать для временного отключения определенного запроса или для предотвращения запуска <ItemLink id="requester"/> заданий по крафту, пока вы все еще вносите изменения в строку.
<br/>

### <a name="what-to-stock" />Что запасать

Во втором столбце вы можете указать, что вы хотите иметь на складе. Эти слоты являются призрачными и не могут содержать настоящие предметы. При перетаскивании предмета в слот вы можете щелкнуть правой кнопкой мыши, чтобы установить количество, равное 1, или щелкнуть левой кнопкой мыши, чтобы использовать количество, которое есть в перетаскиваемой стопке. При перетаскивании ведра с жидкостью в слот вы можете нажать правую кнопку мыши, чтобы установить содержащуюся в нем жидкость, или щелкнуть левой кнопкой мыши, чтобы установить само ведро. Вы также можете щелкнуть элементы, удерживая клавишу Shift, чтобы быстро установить тип элемента. Если у вас нет нужного предмета в вашем инвентаре, вы также можете перетащить его из программы просмотра рецептов, поддерживаемой Applied Energistics.
<br/>

### <a name="amount-to-stock" />Поддерживаемое количество

Поле «Поддерживаемое количество» задаёт необходимый запас. Сначала выберите ресурс, затем введите желаемое количество. Для запросов, не относящихся к элементам, поле будет адаптировано к типу. Например, отображение `B` для обозначения ведер с жидкостью. <br/> Когда текущий запас упадет ниже указанного количества, <ItemLink id="requester"/> запросит больше.
<br/>

### <a name="batch-size" />Размер партии

Следующее поле ввода определяет размер партии, которая будет запрошена, как только текущий запас упадет ниже порога, указанного в поле «Поддерживаемое количество». <br/> Это можно использовать, чтобы снизить нагрузку на [Процессор создания](ae2:ae2-mechanics/autocrafting.md#the-crafting-cpu) и машины, используемые в ремесле, поскольку будет запрошен весь объем сразу, а не несколько отдельных заданий.
<br/>

### <a name="submit-button" />Кнопка «Отправить»

Чтобы применить изменения к запросу, введите нужные значения в поля «Поддерживаемое количество» и «Размер партии», а затем либо нажмите Enter, либо нажмите кнопку «Отправить» справа от текущей строки. Нажатие на любую другую строку вернет значения в предыдущее состояние.
<br/>

### <a name="status-bar" />Строка состояния

Полоса под полями ввода и кнопкой отправки отображает текущий статус запроса.
<br clear="all" />
<br/>

## <a name="statuses" />Статусы

В строке состояния для каждого запроса отображаются следующие статусы.
<br/>

### <a name="gray---empty" />Серый — Пустой

Текущая строка отключена или не указано ничего для хранения.
<br/>

### <a name="green---idling" />Зеленый — холостой ход

Целевая сумма запасов уже достигнута или шаблон для настроенного запроса отсутствует.
<br/>

### <a name="red---missing-ingredients" />Красный — недостающие ингредиенты

В системе отсутствуют необходимые ингредиенты для выполнения текущего задания. Это продолжится, как только в системе будет найдено достаточно ингредиентов.
<br/>

### <a name="yellow---crafting" />Желтый — Крафт

Желаемый запрос в настоящее время формируется. Запросчик ожидает завершения задания.<br/> Пока этот статус активен, настройки соответствующего запроса внутри <ItemLink id="requester"/> заблокированы и не могут быть изменены.
<br/>

### <a name="purple---exporting" />Фиолетовый — экспорт

<ItemLink id="requester"/> получил все результаты текущего задания и пытается экспортировать их в систему хранения.<br/> Обычно этот статус не отображается. Если он активен слишком долго, это означает, что в вашей системе хранения недостаточно места.
<br/>

### <a name="block-appearance" />Внешний вид блока

Если какой-либо запрос в <ItemLink id="requester"/> имеет любой статус, кроме бездействующего или пустого, он изменит свой внешний вид.

## <a name="terminal" />Терминал

Мод также предоставляет новый терминал под названием <ItemLink id="requester_terminal"/>. Это позволяет вам получить доступ ко всем <ItemLink id="requester"/> в одной сети из центральной точки.

Терминал имеет те же функции, что и <ItemLink id="ae2:pattern_access_terminal"/>, и позволяет осуществлять поиск по конкретному запросу. Поскольку по умолчанию все <ItemLink id="requester"/> имеют одно и то же имя, все запросы будут сгруппированы под одним заголовком. Если вам нужна отдельная группа из <ItemLink id="requester"/> в <ItemLink id="requester_terminal"/>, вы можете переименовать их на наковальне или с помощью <ItemLink id="ae2:name_press"/>.
