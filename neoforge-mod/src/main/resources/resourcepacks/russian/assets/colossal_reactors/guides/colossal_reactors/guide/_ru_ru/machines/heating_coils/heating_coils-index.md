# Нагревательные змеевики

Нагревательные змеевики — это специализированные блоки, управляемые **рецептами, определенными пакетом данных**: каждый тип змеевиков может потреблять **предметы**, **жидкость**, **энергию** или их комбинации, а во время работы переключается между **выключенными** и **включенными** визуальными элементами.
