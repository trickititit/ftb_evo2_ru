# <a name="turbine-builder" />Турбостроитель

<BlockImage id="turbine_builder" scale="4" />

**Turbine Builder** строит для вас турбину из предметов из своего инвентаря — аналогично [Строитель реактора](../multiblock/reactor_builder.md).

## <a name="typical-workflow" />Типичный рабочий процесс

1. **Поместите** строительную площадку на грань, где вы хотите, чтобы корпус турбины начинался.
2. **Откройте** экран и установите **ширину, высоту и глубину** (в пределах ограничений сборки).
3. Запасите сборщик **корпусом**, **стеклом**, **контроллерами стержней** (по одному на каждый столбец стержней, который необходим шаблону), **стержнями**, **лопастями** и **блоками хранения**, которые вам нужны для катушек.
4. Выберите **макет** (см. [Стержни и лопасти](turbine_rod_and_blades.md)):
   - **Веб-сайт** — вставьте **сид/URL** дизайна в поле дизайна; стержни (и выбор катушки на веб-сайте) соответствуют этой схеме.
   - **Поток** — один центральный вал. Под строкой шаблона переключите переключатель **Эффективный** (кольца для подъема, возможен бонус за высоту **+3%**) или **Производительный** (полные кольца на каждом слое).
   - **Гиперпоток** — лучшая многостержневая сетка для контура (нечетная-нечетная или шахматная, тот же выбор, что и сетка ModDecoded Rod); размещает **контроллер стержня на каждой колонне**. Тот же переключатель «Эффективный/Производительный», что и у «Потока» (кольцо ограничено лучшим кольцом этого макета).
   - **Пользовательский/Нет** — рамка (и катушки для Custom) без содержимого ротора; длинная кнопка под строкой шаблона остается пустой и отключенной.
5. Выберите **тип катушки** (металлы, поддерживаемые циклами; также можно редактировать на веб-сайте) и **количество слоев катушки** (широкая кнопка в разделе «Предварительный просмотр» рядом с ней).
6. Используйте **Предварительный просмотр** (в центре, та же ширина) и панель **Моделирование** для RF/t, пара и материалов. Предупреждения появляются **рядом с центром**.
7. **Отметить ввод** (чуть выше буфера компоновщика):
   - Щелкните слот буфера, когда включен параметр «Отметить ввод», чтобы указать, какой элемент этот слот принимает для этапов сборки.
   - Вы также можете **перетаскивать элементы из JEI** в слоты буфера, чтобы установить фильтры призрачных меток; дважды щелкните слот, чтобы очистить его.
8. Когда будете готовы, нажмите **Создать**.

Порядок сборки: **внешняя оболочка** → **закрывающая панель** → **контроллеры стержней** (по одному на каждый столбец стержней) → **стержни** → **лопасти** → **блоки катушек** в верхних внутренних слоях.

Сборщик **не** размещает внешний **контроллер турбины** или порты — добавляет их вручную после сборки.

## <a name="simulation-panel" />Панель моделирования

Показывает ожидаемые **RF/t** и **пар**, бонусы катушки и лезвия (включая -5%, если на какой-либо колонне стержней отсутствует контроллер), а также **список материалов**. Начальные значения веб-сайта включаются в моделирование, когда дизайн действителен. Названия кнопок могут различаться в зависимости от версии; читайте подсказки на экране во время работы.
