# Турбостроитель

<BlockImage id="turbine_builder" scale="4" />

**Турбостроитель** строит для вас турбину из предметов из своего инвентаря — аналогично [Строитель реактора](../multiblock/reactor_builder.md).

## Типичный рабочий процесс

1. **Поместите** строительную площадку на грань, где вы хотите, чтобы корпус турбины начинался.
2. **Откройте** экран и установите **ширину, высоту и глубину** (в пределах размера вашего рюкзака).
3. Запасите конструктор **корпусом**, **стеклом**, **контроллером стержня**, **стержнями**, **лезвиями** и **блоками хранения**, которые вам нужны для катушек.
4. Выберите **макет**:
   - **Эффективность** — меньше столбцов стержней (шахматная доска); лезвия растут кольцо за кольцом вверх по валу (**возможен бонус по высоте +3%** — см. [Стержни и лезвия](turbine_rod_and_blades.md)).
   - **Производительность** — стержни на каждом разрешенном столбце; каждый слой сразу получает полные кольца (максимум пара быстрее).
5. Выберите **тип катушки** (циклически переключает металлы, которые поддерживает мод) и **сколько слоев катушки** (по умолчанию **3**, измените с помощью ◀ ▶ на экране).
6. Используйте **предварительный просмотр** и панель **моделирования**, чтобы увидеть расчетное значение RF/t, расход пара и необходимые материалы.
7. **Ввод отметки** сообщает строителю, из каких слотов инвентаря какие блоки поставляются для каждого шага.
8. Когда будете готовы, нажмите **Создать**. Вы можете добавить жидкость в резервуар для сборки, если в вашем наборе она используется для проверок настройки.

Порядок сборки: **внешняя оболочка** → **контроллер стержня и стержни** → **лезвия** → **блоки катушек** в верхних внутренних слоях.

## Панель моделирования

Показывает, действителен ли макет, ожидаемы **RF/t** и **пар**, бонусы змеевика и лопасти, а также **список материалов** — та же идея, что и у строителя реактора. Названия кнопок могут различаться в зависимости от версии; читайте подсказки на экране во время работы.
