# Турбина

**Турбина** — это большой мультиблок, который превращает **пар** в **RF**. Соберите корпус из **Корпуса турбины** и **Стекла турбины**, поместите внутрь **стержни и лопасти** ротора, заполните верх **блоками катушек** (металлическими накопительными блоками), добавьте **порты** и поместите один **Контроллер турбины** на боковую стену.

Большинство игроков направляют пар из Colossal Reactors **реактора** в турбину и выводят RF из силовых портов — сильная пара для поздней игры.

**Новое здесь?** Сначала прочитайте [Начало работы](getting_started.md) — **Полный пример**, затем **Настройка 1** (автономный пар) или **Настройка 2** (цепь теплоносителя реактора).
