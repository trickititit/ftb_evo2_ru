# Реактор

Реактор представляет собой полую оболочку, состоящую из **Корпуса реактора** и **Стекла реактора** (прозрачные грани). Внутри вы размещаете топливные **стержни реактора**, дополнительные **радиаторы**, дополнительную **хладагент**, **порты** на корпусе и ровно один **контроллер реактора**, который управляет работой и отображает показания на экране.

**Новенькое здесь?** Сначала прочтите [Начало работы](getting_started.md) — **Полный пример**, затем **Настройка 1** (только RF) или **Настройка 2** (охлаждающая жидкость → турбина).
