# Ресурсный порт реактора

<BlockImage id="resource_port" scale="4" />

Прикрепите **Ресурсный порт(ы) реактора** к **корпусу** для перемещения предметов и/или жидкостей между внешним миром и реактором.

## Типовые планировки

### Вручную / только RF (порты не требуются)

Топливом и отходами можно управлять через графический интерфейс [Контроллер реактора](reactor_controller.md). Вам все еще нужен хотя бы один [Порт питания](power_ports.md).

### Автоматизация: подача топлива + слив (**два порта**, на той же стороне, что и контроллер)

Разместите **оба ресурсных порта на одной стене** с контроллером реактора. Пример в [Начало работы](getting_started.md) — порты разбросаны по этой грани; наведите курсор на ромбы на сцене, чтобы получить подсказки по настройке.

| Порт (пример) | Режим | Фильтр | Ходы |
|----------------|------|--------|-------|
| Нижний левый | **ВСТАВКА** | **Топливо** | Твердое топливо **в** стержни |
| Нижний правый | **ЭКСТРАКТ** | **Отходы** | **Отходы** **выход** |

Добавьте **порт питания** на ту же грань. Труба/бункер **снаружи** каждого порта.

### Контур охлаждающей жидкости (**дополнительные порты**, опционально)

Если вы используете **активную охлаждающую жидкость** (Настройка 2 в [Начало работы](getting_started.md)):

- **ВСТАВКА** с фильтром **охлаждающей жидкости** — трубка охлаждающей жидкости **в** (*Импорт: только охлаждающая жидкость.*)
- **ЭКСТРАКТ** с фильтром **Охлаждающая жидкость** — труба **пар/отработанная жидкость** **выход** → [Турбина Начало работы](../turbine/getting_started.md) (*Выход: только отработанная жидкая охлаждающая жидкость.*)
- Храните **ЭКСТРАКЦИОННЫЕ отходы** в отдельном порту; не ожидайте, что один порт EXTRACT будет выбрасывать несвязанные жидкости.

## Графический интерфейс — кнопки и всплывающие подсказки.

Откройте графический интерфейс порта и **наведите курсор на каждый элемент управления** — текст ниже — это то, что вы видите в игре (на английском языке).

### Режим (верхняя кнопка — нажмите, чтобы переключиться)

| Этикетка | Подсказка |
|-------|---------|
| **Вставить** | Реактор принимает твердое топливо и теплоноситель. |
| **Извлечение** | Реактор извлекает ядерные отходы и отработанный теплоноситель. |
| **Извлечь** | Реактор выбрасывает содержащееся в нем твердое топливо. |

### Фильтр (только реактор — нажмите, чтобы переключить роль топлива/хладагента)

Зависит от **режима**; наведите курсор на кнопку текущего фильтра:

| Режим | Этикетка фильтра | Подсказка |
|------|--------------|---------|
| **Вставить** | Все / Топливо / Охлаждающая жидкость | *Импорт: топливо и охлаждающая жидкость.* / *Импорт: только топливо (предметы или жидкость).* / *Импорт: только охлаждающая жидкость.* |
| **Извлечение** | Все / Отходы / Охлаждающая жидкость | *Выход: твердые отходы и жидкий теплоноситель.* / *Выход: только твердые отходы.* / *Выход: только отработанный жидкий теплоноситель.* |
| **Извлечь** | Оба / Только топливо / Только охлаждающая жидкость | *Выброс: топливо и охлаждающая жидкость из стержней.* / *Выброс: только топливо…* / *Выброс: только охлаждающая жидкость.* |

### Средние переключатели (нажмите, чтобы включить — подчеркнуты, когда активны)

| Кнопка | Подсказка |
|--------|---------|
| **Твердый** | Нажмите, чтобы разрешить или заблокировать твердые объекты через этот порт. |
| **Жидкость** | Нажмите, чтобы разрешить или заблокировать прохождение жидкостей через этот порт. |
| **Газ** | Нажмите, чтобы разрешить или заблокировать подачу газов Mekanism через этот порт. |

### Танки и свалка

| Контроль | Подсказка |
|---------|---------|
| **Резервуар для жидкости** (панель при наведении) | Жидкость: количество/емкость mB плюс название жидкости |
| **Бензобак** (парящая панель, Меканизм) | Газ: количество/мощность mB плюс название газа |
| **D** под резервуаром для жидкости | Сброс: опорожните внутренний бак для жидкости (жидкость выбрасывается) |
| **D** под бензобаком | Свалка: опорожнить бензобак (газ выбрасывается) |

- **Слот для предмета** — ручной ввод-вывод или бункер/труба на **внешней** стороне.

После изменения режимов или фильтров **Перезагрузите** [Контроллер реактора](reactor_controller.md).

## Автоматическое масштабирование мощности

Когда реактор **перепроверяется**, каждый ресурсный порт изменяет размеры резервуаров с жидкостью/газом (газ Mekanism, если он включен):

- Цель ≈ **оценка mB/t для режима этого порта и фильтра × 10**, минимум **16 000 mB** на резервуар.
- **Нет фиксированной верхней крышки** объема жидкости/газа для больших реакторов.
- Производительность **растет** сразу же, как только увеличивается спрос; **сжимается** только тогда, когда сохраненное содержимое по-прежнему соответствует меньшему размеру.
