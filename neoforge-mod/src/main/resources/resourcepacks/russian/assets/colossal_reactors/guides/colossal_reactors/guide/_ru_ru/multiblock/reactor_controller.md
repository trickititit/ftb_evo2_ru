# Контроллер реактора

<BlockImage id="reactor_controller" scale="4" />

Откройте контроллер, **щелкнув** правой кнопкой мыши** блок, когда он находится на **боковой** поверхности корпуса (не сверху или снизу), **заменив блок корпуса** на внешней рамке экраном, обращенным **наружу**.

Впервые в мультиблоках? Начните с [Начало работы](colossal_reactors:multiblock/getting_started.md).

## Операция

- **Validate/run** — проверка первого открытия; Если это действительно так, реактор может включиться **ON** и отобразить RF/тик, показания топлива и охлаждающей жидкости.
- **Топливо** — перемещайте топливо между инвентарем и хранилищем стержней, когда отображаются слоты.
- **Охлаждающая жидкость** — просмотр уровня и заливки/слива при наличии элементов управления (необязательно для игры **RF** с пустым буфером охлаждающей жидкости).
- **Перезагрузка** — повторно проверяет структуру и обновляет размеры резервуаров порта после изменения настроек сборки или порта.

## Остановка без нарушения мультиблока

Используйте [Реактор Редстоун Порт](redstone_port.md), если вы хотите, чтобы внешний красный камень **приостанавливал** или **остановил** работу, пока оболочка остается сформированной. **Без** порта красного камня реактор работает всякий раз, когда он действителен и включен **ВКЛ** (нет ворот красного камня).

Если для вашего пакета включены показатели **стабильности**, они появятся здесь — см. [Нестабильность реактора](reactor_instability.md).

## Реактор действителен, но не производит?

| Проверить | |
|-------|---|
| Порт питания присутствует и подключен? | RF нужен [Порт питания](power_ports.md) с чем-то, принимающим энергию **снаружи**. |
| Режим только RF? | Пустой буфер охлаждающей жидкости = жидкость не требуется; Для режима вода/пар требуется охлаждающая жидкость + вытяжной контур. |
| Редстоун порт? | Реактор может оставаться **ВЫКЛ** до тех пор, пока режим порта + сигнал не разрешит работу. |
| Бесполезное резервное копирование? | Добавьте **ЭКСТРАКТ** [Ресурсный порт](resource_port.md) или очистите мусор вручную. |

Подсказки и строка состояния на этом экране объясняют текущее состояние.
