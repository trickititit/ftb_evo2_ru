# Радиационный контроль

Присутствует, когда **управление радиацией** включено в конфигурации и ваш экземпляр включает интегрированный контент (обычно **Mekanism**). Используйте **JEI**, чтобы подтвердить наличие рецептов и блоков для вашего сохранения.

## Радиационный скруббер

<BlockImage id="radiation_scrubber" scale="4" />

**Радиационный скруббер** тратит энергию и дополнительные **катализаторы** на переработку переносимых по воздуху веществ, связанных с радиацией, в **химический/газовый буфер**, расположенный в его резервуаре.

### Элементы управления

- Два **слота для предметов** для конфигурации катализатора (действительные катализаторы см. в JEI и в вашем пакете данных).

- **Банк для газа/химических веществ**: наведите курсор на содержимое и уровень заполнения.

- **Полоска энергии** сбоку: наведите курсор, чтобы получить накопленную энергию.

Когда присутствует **Mekanism**, автоматизация может взаимодействовать через химические API Mek, представленные блоком; в противном случае взаимодействуйте вручную через экран и прикрепленные каналы, если это поддерживается.

## Радиационная терапия

<ItemImage id="radiation_cure" scale="2" />

**Радиационная терапия** — это расходный материал, используемый в процессе лучевой терапии. Откройте из всплывающей подсказки элемента с помощью GuideMEярлык **открыть руководство** при настройке.
