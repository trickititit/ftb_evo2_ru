# плавильная печь

<BlockImage id="melter" scale="4" />

**Расплавитель** превращает твердые вещества в расплавленную жидкость для вашей реакторной цепи или других машин.

## Элементы управления

- **Входной слот**: сюда помещайте обрабатываемые предметы (действительные рецепты см. в JEI).

- **Индикатор выполнения**: показывает текущий прогресс рецепта; **нажмите на JEI** (если установлено), чтобы открыть соответствующие рецепты.

- **Бак для жидкости**: наведите курсор на тип и количество жидкости. **D** под резервуаром сливается хранящаяся жидкость.

- **Кнопка шестеренки Redstone**: циклически переключает поведение красного камня (игнорировать, низкий, высокий и т. д. — метки на кнопке обновляются). Наведите указатель мыши на название активного режима.
