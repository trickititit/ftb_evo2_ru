# <a name="recursive-ae2-pattern-provider" />Рекурсивный поставщик шаблонов AE2

## <a name="✨-key-features" />✨ Ключевые особенности

### <a name="🎯-automatic-pattern-generation" />🎯 Автоматическое создание шаблонов
- **Умные зависимости**: автоматически создает недостающие шаблоны ингредиентов для крафта на лету.
- **Рекурсивная логика**: отслеживает глубокие цепочки зависимостей до настроенной максимальной глубины.
- **Обнаружение рецептов**: создает шаблоны только для предметов с действительными, решаемыми рецептами.
- **Универсальная поддержка**: создает шаблоны зависимостей для всех стандартных компонентов крафта.
- **Совместимость с**: AE2, Extended AE2, Advanced AE и ExtendedAE-Plus!

### <a name="⚙️-seamless-gui-integration" />⚙️ Бесшовная интеграция графического интерфейса
- **Прямое переключение терминала**: переключение рекурсии непосредственно внутри терминала кодирования шаблонов с помощью специальной кнопки (настраивается с помощью `enableEncodingGuiToggle`).
- **Фокус на выкройку крафта**: легко интегрируется в кодировку выкройки крафта, оставаясь скрытым для режимов, не связанных с крафтом.
- **Альтернативный метод рецепта**: поддерживает преобразование существующих выкроек с помощью рецептов таблицы крафта (`Pattern + Iron Ingot`).

### <a name="🎨-clean-visual-feedback" />🎨 Чистая визуальная обратная связь
- **Встроенные подсказки**: отображает изящную метку `Recursive`, соответствующую собственному дизайну подсказки AE2.
- **Постоянная маркировка**: шаблоны перекодирования в терминале сохраняют свой рекурсивный статус без дополнительных шагов.
