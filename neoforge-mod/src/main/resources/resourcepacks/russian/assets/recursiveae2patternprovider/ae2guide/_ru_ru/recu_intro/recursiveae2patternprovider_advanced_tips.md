# <a name="recursive-ae2-pattern-provider" />Рекурсивный поставщик шаблонов AE2

## <a name="🔧-advanced-tips" />🔧 Дополнительные советы

### <a name="terminal-workflow-efficiency" />Эффективность рабочего процесса терминала
- Используйте **Переключатель рекурсивного шаблона** непосредственно в терминале кодирования шаблонов, чтобы мгновенно создавать пакетные рекурсивные шаблоны, не перенося в инвентарь дополнительных предметов для крафта.
- Состояние переключения в терминале относится только к выкройкам крафта и автоматически скрывается при переключении в режимы обработки или кузнечного дела.
- **Настраиваемая кнопка графического интерфейса**: если вы предпочитаете заставлять игроков создавать рекурсивные шаблоны только с помощью рецептов стола крафта, установите `enableEncodingGuiToggle = false` в файле конфигурации.

### <a name="recursion-depth-control" />Управление глубиной рекурсии
- **Глубина 1**: генерирует только прямые ингредиенты (например, доски для сундука).
- **Глубина 3**: генерирует ингредиенты + их ингредиенты + журналы (рекомендуется для большинства настроек).
- **Неограниченно (-1)**: решает все дерево зависимостей вплоть до исходных материалов.
- **Отключено (0)**: восстанавливает стандартное поведение AE2.

### <a name="pattern-provider-setup-&amp;-performance" />Настройка и производительность поставщика шаблонов
- Размещайте рекурсивные шаблоны в поставщиках шаблонов, подключенных к молекулярным ассемблерам.
- Автоматически созданные шаблоны зависимостей наследуют настройки замены (замена элемента/жидкости) своего родительского шаблона.
- В больших пакетах модов сохраняйте разумные ограничения на глубину рекурсии, чтобы оптимизировать время индексации сетевых шаблонов.
