# <a name="recursive-ae2-pattern-provider" />Рекурсивный поставщик шаблонов AE2

## <a name="💡-example-scenario" />💡 Пример сценария

### <a name="traditional-ae2-setup" />Традиционная установка AE2
Чтобы автоматически создать железную кирку, вам традиционно необходимо вручную закодировать и зарегистрировать:
1. Выкройка железной кирки
2. Шаблон палочки
3. Выкройка деревянной доски (из бревен)
4. Схема выплавки железного слитка (из сырого железа)
5. Вручную заполнить поставщики шаблонов каждым подрецептом...

### <a name="with-recursive-ae2-pattern-provider" />С рекурсивным поставщиком шаблонов AE2
1. Откройте **Терминал кодирования шаблонов**, включите переключатель **Рекурсивный шаблон** и закодируйте ОДИН шаблон железной кирки.
2. Вставьте его в свой поставщик шаблонов.
3. **Все необходимые подшаблоны генерируются автоматически!**

Мод отслеживает все дерево крафта, включая доски, палки и промежуточные детали, сохраняя чистоту вашей сети и исключая повторяющееся создание шаблонов.
