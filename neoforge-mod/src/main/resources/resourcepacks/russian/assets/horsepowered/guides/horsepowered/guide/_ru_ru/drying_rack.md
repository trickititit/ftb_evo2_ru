# Сушилка

Сушилка — это пассивная деревянная полка, которая медленно преобразует влажные или сырые предметы в высушенную форму. Он вмещает **8 предметов одновременно** в сетке 4x2, расположенной поперек планок, и каждый слот независимо отсчитывает свой таймер прогресса, поэтому вы можете загружать стойку по одному слоту за раз, не сбрасывая чей-либо прогресс.

## Использование

1. Поставьте сушилку на землю (она может быть обращена в любом направлении).
2. **Щелкните правой кнопкой мыши**, держа в руках элемент ввода, чтобы поместить его в слот, по которому вы щелкнули. Только один предмет в слоте.
3. Подождите, пока истечет время высыхания рецепта. По завершении предмет слота заменяется высушенным продуктом.
4. **Нажмите правой кнопкой мыши** по заполненному слоту, чтобы забрать предмет обратно. Работает как для вещей, находящихся в процессе сушки, так и для готовых изделий.

## Автоматизация

Хопперы и трубы могут взаимодействовать со стойкой с любой стороны:

- **Вставка**: принимаются только изделия с зарегистрированной рецептурой сушки. Один предмет на пустой слот.
- **Извлечение**: можно извлечь только **готовые** элементы. Вещи, которые еще сохнут, запираются.

Возможен полный конвейер: бункер над подачей сырья, бункер под вытягиванием готовой продукции.

## Примечания

- Стойка не требует энергии, топлива или рабочего. Сушка происходит пассивно с течением времени.
- Предметы с частичным прогрессом сохраняются после перезагрузки фрагмента.
- Доступные рецепты сушки можно найти в JEI/EMI.
