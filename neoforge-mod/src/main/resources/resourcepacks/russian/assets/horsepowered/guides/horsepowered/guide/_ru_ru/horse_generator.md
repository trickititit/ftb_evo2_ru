# Генератор на лошадиной силе

Генератор с приводом от лошади преобразует труд лошади непосредственно в энергию Forge (FE). Шагающий рабочий вращает генератор, заряжая внутренний буфер, который автоматически передает энергию соседним машинам, кабелям и накопителям энергии.

## Настройка

1. Поместите генератор на свободное пространство размером не менее 7x7 вокруг него.
2. Ведите лошадь (или другое допустимое существо) поводком.
3. Щелкните правой кнопкой мыши генератор, удерживая поводок, чтобы прикрепить существо.
4. Примените сигнал красного камня (например, рычаг сверху), чтобы включить генерацию.
5. Красный факел наверху загорается красным, пока генератор активно вырабатывает энергию.

## Проверка рабочей зоны

**Shift+Щелкните** правой кнопкой мыши по генератору пустой рукой, чтобы визуализировать необходимую рабочую область. Зеленый = ясно, Красный = затруднено. Рычаги, расположенные внутри кольца, не делают его недействительным, поэтому генератор можно переключать с помощью рычага на ближайшем блоке пола.

## Примечания

- Подключите любую сторону, верхнюю или нижнюю часть к FE-совместимому кабелю или устройству для получения энергии.
- Генератор работает только тогда, когда у него есть мощность красного камня, а его буфер ниже емкости.
- Пол под дорожкой масштабирует скорость генерации. См. [Путь и скорость лошади](horse_path.md).
- При добыче энергии генератор сохраняет накопленный заряд, поэтому вы можете перемещать его без потери мощности.
- Щелкните правой кнопкой мыши пустой рукой и без смещения, чтобы освободить прикрепленного работника.
