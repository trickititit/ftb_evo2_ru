# Пресс на конной тяге

Пресс на конной тяге сжимает предметы, извлекая жидкости или получая другие продукты. Он подходит для получения масел, соков и прочих жидкостей.

## Установка

1. Поставьте пресс на площадке со свободной областью не менее 7x7 блоков вокруг.
2. Возьмите на поводок лошадь или другое подходящее существо.
3. Нажмите на пресс правой кнопкой мыши, держа поводок, чтобы привязать существо.
4. Существо будет ходить по кругу и приводить пресс в движение.

## Проверка рабочей области

Нажмите на пресс **правой кнопкой мыши с Shift**, держа руку пустой, чтобы увидеть необходимую рабочую область. Зелёный цвет означает свободное место, красный — препятствие.

## Использование

1. Нажмите правой кнопкой мыши с предметами в руке, чтобы загрузить их.
2. Используйте полное ведро для наполнения внутреннего резервуара или пустое — для отбора жидкости.
3. Привязанное существо будет автоматически прессовать предметы.
4. Нажмите правой кнопкой мыши, чтобы забрать готовые твёрдые продукты.

## Резервуар жидкости

Внутренний резервуар используется и для получения, и для расходования жидкостей:

- Рецепт может наполнять его, как при отжиме масла из семян, либо расходовать содержащуюся жидкость.
- Используйте полное ведро для наполнения или пустое для отбора жидкости.
- Подключите жидкостную трубу или резервуар для автоматической перекачки.

## Розлив по ёмкостям

У вёдер есть игровой интерфейс работы с жидкостями. У стеклянных бутылочек его нет, поэтому сами по себе они не могут забирать жидкость из резервуара. Пресс решает эту задачу отдельным списком рецептов розлива.

Нажмите на пресс правой кнопкой мыши с бутылочкой или другой ёмкостью из рецепта. Пресс заберёт нужную жидкость из выходного резервуара и выдаст наполненный предмет. При использовании наполненного предмета произойдёт обратное: жидкость попадёт во входной резервуар, а пустая ёмкость вернётся вам.

По умолчанию есть один рецепт: стеклянная бутылочка забирает 250 mB воды и превращается в бутылочку воды. Сначала получите воду прессованием льда, снега или натёчного камня.

Авторы сборок могут добавлять рецепты в `data/<namespace>/recipe/bottling/<recipe>.json`:

```json
{
  "type": "horsepowered:bottling",
  "container": "minecraft:glass_bottle",
  "fluid": { "id": "minecraft:water", "amount": 250 },
  "result": {
    "id": "minecraft:potion",
    "components": { "minecraft:potion_contents": { "potion": "minecraft:water" } }
  }
}
```

* `container`: ингредиент — пустая ёмкость в руке игрока.
* `fluid`: жидкость и её количество в mB за одно нажатие.
* `result`: выдаваемый наполненный предмет. Компоненты сохраняются, поэтому поддерживаются зелья и другие предметы с дополнительными данными.
* `priority`: необязательный порядок отображения в JEI. Меньшие значения идут первыми.

Так можно вручную извлекать из пресса жидкости, которые существуют только в бутылочках, например фруктовые соки. JEI показывает все рецепты в категории розлива.

## Примечания

- Высота пресса — два блока.
- Для некоторых рецептов нужно несколько исходных предметов или определённая жидкость в резервуаре.
- Нажмите правой кнопкой мыши с пустой рукой, чтобы освободить привязанное существо.
- Покрытие дорожки влияет на скорость работы. Подробнее: [Дорожка и скорость лошади](horse_path.md).
- Доступные рецепты прессования можно посмотреть в JEI/EMI.
