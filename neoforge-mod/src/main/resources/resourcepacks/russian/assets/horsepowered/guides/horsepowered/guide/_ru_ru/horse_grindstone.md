# Лошадиный точильный камень

Лошадиный точильный камень — это автоматизированный шлифовальный станок, приводимый в движение лошадью или другим существом, ходящим по кругу вокруг него.

<ItemImage id="horsepowered:grindstone" scale="4" />
</Row>

## Настройка

1. Поместите точильный камень для лошади на свободное пространство размером не менее 7x7 вокруг него.
2. Ведите лошадь (или другое допустимое существо) поводком.
3. Щелкните правой кнопкой мыши по точильному камню, удерживая поводок, чтобы прикрепить существо.
4. Существо ходит кругами, приводя в действие точильный камень.

## Проверка рабочей зоны

**Shift+Щелкните** правой кнопкой мыши по точильному камню пустой рукой, чтобы визуализировать необходимую рабочую область. Зеленый = ясно, Красный = затруднено.

## Использование

1. Щелкните правой кнопкой мыши по предметам, чтобы вставить их в точильный камень.
2. Прикрепленное существо автоматически измельчает предметы.
3. Щелкните правой кнопкой мыши, чтобы извлечь элементы вывода.

## Примечания

- Щелкните правой кнопкой мыши пустой рукой, чтобы отпустить прикрепленное существо обратно на поводок.
- Если существо умирает или убегает, поводок выпадает.
- Пол под дорожкой влияет на скорость работы, допускается наличие небольшого количества препятствий (сундуков, бункеров и т. д.). См. [Путь и скорость лошади](horse_path.md).
- Допустимые рабочие по умолчанию: лошади, ослы, мулы и ламы. Дополнительные существа могут быть добавлены через конфигурацию.
