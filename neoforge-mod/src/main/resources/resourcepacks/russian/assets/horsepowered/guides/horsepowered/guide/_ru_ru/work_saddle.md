# Рабочее седло

Рабочее седло захватывает действующего рабочего (лошадей, ослов, мулов, лам, лам торговцев) в переносной предмет, а затем отпускает его в другом месте при щелчке правой кнопкой мыши.

</Row>

## Использование

1. **Захват**: возьмите пустую рабочую седло и щелкните правой кнопкой мыши действительного рабочего. Моб хранится на седле.
2. **Отпуск**: щелкните правой кнопкой мыши любую грань блока с седлом для переноски, чтобы создать рабочего на этом блоке. Седло снова становится пустым.
3. **Подсказка при наведении**: седло для переноски показывает, какого моба оно в данный момент держит.

## Примечания

- Захваченные мобы сбрасываются с любого пассажирского сиденья и отсоединяются от любого поводка во время захвата.
