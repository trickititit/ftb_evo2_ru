# Путь и скорость лошади

Каждый блок с лошадиной силовой установкой (точильный камень, измельчитель, пресс, генератор) нуждается в рабочей зоне 7х7 вокруг себя. Рабочий идет по круговому пути по внешнему кольцу этой области, и блоки, которые пересекает этот путь, могут ускорить или замедлить рабочего.

## Рабочая зона

- Кольцо 7x7 (центр 3x3 занят блоком и небольшим буфером) должно быть свободным на уровне блока и на один блок выше.
- Квадрат 7х7 на один блок ниже должен быть прочным полом. Грязевые дорожки и любой другой блок, указанный в конфигурации скорости пути, также считаются полом.
- Рычаги, расположенные внутри кольца, всегда разрешены, они полезны для размещения переключателей из красного камня прямо на полу (удобно для генератора).
- Shift + щелкните правой кнопкой мыши любой блок с лошадьми пустой рукой, чтобы визуализировать область. Зеленый = ясно, Красный = затруднено.

## Толерантность к препятствиям

Небольшое количество несменных блоков (сундуки, бункеры, трубы, шестеренки и т. д.) могут находиться внутри кольца, не нарушая валидацию. Допуск по умолчанию составляет **2 блока**, настраивается в `config/horsepowered-common.toml` под `[horse_path]`.

## Скорость пути

Каждый из блоков пола под круговым путем рабочего вносит свой вклад в множитель скорости. Конечный множитель — это среднее значение для уникальных блоков на пути, и он масштабирует скорость перемещения рабочего, что напрямую влияет на скорость выполнения рецептов.

По умолчанию: грязь, трава, крупная грязь и въевшаяся грязь с коэффициентом 0,5x; грунтовые дороги проходят со скоростью 1.0x; паковый лед работает со скоростью 2,0x. Все остальное по умолчанию равно 1.0x. Смешанные пути усредняются.

Записи скорости и множитель по умолчанию настраиваются в `config/horsepowered-common.toml` под `[horse_path]`.

## Примечания

- Множитель скорости пересчитывается при каждом проходе проверки (примерно каждые 11 секунд), поэтому вы можете менять блоки под бегущим рабочим, не прикрепляя лошадь повторно.
- Отбираются только блоки пола непосредственно под дорожкой.
