# <a name="horse-path-&amp;-speed" />Путь и скорость лошади

Каждой машине на конной тяге (точильному камню, измельчителю, прессу и генератору) нужна рабочая зона 7x7. Существо ходит по кругу вдоль внешнего кольца этой зоны; блоки под ногами могут ускорять или замедлять его.

## <a name="working-area" />Рабочая зона

- Кольцо 7х7 (центр 3х3 занят блоком и небольшим буфером) должно быть свободным на уровне блока и на один блок выше.
- Под зоной 7x7, на один блок ниже машины, должен быть сплошной пол. Тропинки и любые блоки, указанные в настройках скорости дорожки, также считаются полом.
- Внутри кольца разрешены блоки, через которые может пройти моб: факелы, рычаги, кнопки, таблички, цветы, редстоуновая пыль, открытые калитки и т. д. Можно осветить зону или разместить редстоуновые переключатели прямо на полу — это удобно для генератора.
- Нажмите Shift + ПКМ пустой рукой по машине на конной тяге, чтобы увидеть границы зоны. Зелёный цвет обозначает свободное место, красный — препятствие.

## <a name="obstruction-tolerance" />Допустимые препятствия

Внутри кольца допускается небольшое количество непроходимых блоков: сундуков, воронок, труб, шестерён и т. д. По умолчанию разрешено **2 блока**; значение задаётся в файле `config/horsepowered-common.toml`, в разделе `[horse_path]`.

## <a name="path-speed" />Скорость пути

Каждый блок пола под круговой дорожкой вносит вклад в множитель скорости. Итог — среднее по всем различным позициям блоков на пути. Множитель меняет скорость ходьбы существа, а вместе с ней — скорость обработки рецептов.

По умолчанию земля, дёрн, каменистая земля и корнистая земля дают 0,5x, тропинки — 1,0x, плотный лёд — 2,0x. Для остальных блоков используется 1,0x. На дорожке из разных блоков значения усредняются.

Записи скорости и множитель по умолчанию настраиваются в `config/horsepowered-common.toml` под `[horse_path]`.

## <a name="worker-speed" />Рабочая скорость

Сила прыжка существа также влияет на скорость его ходьбы. У большинства мобов она равна 0,42, что соответствует обычной скорости. Отклонение от этого значения линейно меняет скорость: лошадь с силой прыжка 0,7 ходит примерно со скоростью 1,3x, а с силой 1,0 — примерно 1,6x.

Множители перемножаются: лошадь со скоростью 1,6x на дорожке 2,0x работает со скоростью 3,2x. Jade показывает силу прыжка и скорость как при осмотре машины с прикреплённым существом, так и при осмотре самого подходящего для работы моба.

Базовое значение задаёт `workerJumpSpeedBaseline` (по умолчанию 0,42), а масштаб — `workerJumpSpeedScale` (по умолчанию 1,0) в разделе `[horse_path]`. Установите масштаб в `0`, чтобы все существа ходили с одинаковой скоростью.

Авторы сборок могут задать фиксированную силу прыжка для любого типа существа через карту данных `horsepowered:horse_engine_jump_strength` в файле дата-пака `data/<namespace>/data_maps/entity_type/horse_engine_jump_strength.json`:

```json
{
  "values": {
    "minecraft:cow": 0.6,
    "#horsepowered:valid_worker": 0.5
  }
}
```

Это значение заменяет собственный атрибут моба. Оно считывается при прикреплении существа к машине, поэтому после изменения файла прикрепите его заново.

## <a name="notes" />Примечания

- Множитель скорости пересчитывается при каждом проходе проверки (примерно каждые 11 секунд), поэтому вы можете менять блоки под бегущим рабочим, не прикрепляя лошадь повторно.
- Отбираются только блоки пола непосредственно под дорожкой.
