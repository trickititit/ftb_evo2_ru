# Разделочная колода

Рубящая колода — это станция ручной обработки для рубки бревен и других предметов с помощью топора.

</Row>

## Использование

1. Поместите разделочную доску.
2. Щелкните правой кнопкой мыши бревном или другим рубимым предметом, чтобы поместить его на блок.
3. Щелкните правой кнопкой мыши топором, чтобы разрубить предмет.
4. Щелкните правой кнопкой мыши, чтобы собрать выходные данные.

## Стоимость голода

Каждый удар топора требует небольшого базового количества голода (настраивается). Некоторые рецепты также добавляют дополнительную стоимость голода сверх базовой, и эту стоимость оплачивает только плаха. Конный измельчитель игнорирует это. JEI показывает строку «Голод» в рецептах, в которых он есть, так что вы можете сразу определить дорогие рецепты.

## Примечания

- Топоры могут получить урон от прочности при рубке (настраивается).
- Работает с теми же рецептами, что и Лошадь Чоппер, если рецепт не помечен только для лошадей.
- Для ручной рубки требуется больше ударов по рецепту, чем для рубки лошади с помощью настраиваемого множителя; JEI отображает фактическое количество отбивок.
- Доступные рецепты нарезки можно найти в JEI/EMI.
