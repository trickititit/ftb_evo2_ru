# <a name="horse-powered" />Конная тяга

Добро пожаловать в HorsePowered! Этот мод добавляет разнообразное оборудование с приводом от лошади для обработки предметов, не требующее электричества или топлива — только мощь вашего верного скакуна.

## <a name="features" />Особенности

- **Ручная обработка**: используйте ручной точильный камень и разделочную колоду для обработки предметов вручную.
- **Автоматическая обработка**: прикрепите лошадь или другое существо, чтобы автоматизировать точильный камень, измельчитель или пресс.
- **Несколько рецептов**: измельчите пшеницу в муку, нарежьте бревна на доски и прессуйте предметы в жидкости.

## <a name="getting-started" />С чего начать

Начните с создания [Ручной точильный камень](hand_grindstone.md) для ручного измельчения или сразу переходите к автоматизации с помощью [Точильный камень на конной тяге](horse_grindstone.md).

## <a name="tips" />Советы

- Лошадей и других существ можно прикрепить к блокам с лошадиным приводом, ведя их поводком и щелкнув блок правой кнопкой мыши.
- Машины на конной тяге требуют вокруг них свободной рабочей зоны размером 7x7 с прочным полом под ними.
- Внутри кольца допускается небольшое количество препятствий (сундуки, воронки, шестерни); подробности см. [Путь и скорость лошади](horse_path.md)
- Любой блок, через который может пройти моб (факелы, рычаги, кнопки, знаки, цветы, пыль из красного камня, открытые ворота и т. д.), разрешен внутри рабочей зоны, поэтому вы можете зажечь его или разместить переключатели из красного камня прямо на полу (полезно для генератора)
- Блоки пола под дорожкой увеличивают скорость рабочего: земля и дёрн замедляют его, тропинки дают обычную скорость, плотный лёд удваивает ее. См. [Путь и скорость лошади](horse_path.md) для получения полного списка и конфигурации.
- Нажмите Shift + ПКМ на блок с лошадиным приводом пустой рукой, чтобы увидеть необходимую ему рабочую область.
