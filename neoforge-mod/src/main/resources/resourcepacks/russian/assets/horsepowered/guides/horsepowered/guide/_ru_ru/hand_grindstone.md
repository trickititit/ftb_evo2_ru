# Ручной точильный камень

Ручной точильный камень — это блок ручной обработки, который позволяет шлифовать предметы вручную. Отличный вариант для начала игры, пока у вас нет лошадей для автоматизации.

## Использование

1. Поместите ручной точильный камень.
2. Щелкните правой кнопкой мыши элемент, чтобы вставить его во входной слот.
3. Щелкните правой кнопкой мыши пустой рукой, чтобы повернуть точильный камень. Каждый ход воспроизводит скрежетающий звук и вращает предмет на камне.
4. Точильный камень обрабатывает предмет за несколько оборотов. Выходной сигнал появляется на шлифовальной поверхности рядом с входным.
5. Щелкните правой кнопкой мыши пустой рукой по выходу, чтобы собрать его.
6. Подкрадитесь + щелкните правой кнопкой мыши, чтобы вытащить нефрезерованный ввод обратно.

## Стороны дисплея и захвата

Предметы, отображаемые на поверхности точильного камня, выравниваются по той стороне, которая их поднимает, в зависимости от того, каким образом был расположен блок:

- **Вершина (вращается)**: ввод, обрабатываемый при каждом повороте.
- **Левая сторона игрока**: входной слот, подкрадитесь + щелкните правой кнопкой мыши здесь, чтобы вернуть необработанный ввод.
- **Правая сторона игрока**: основной вывод, щелкните здесь правой кнопкой мыши, чтобы собрать
- **Спереди (сторона игрока)**: вторичный выход (когда он создается по рецепту).

## Стоимость голода

Каждый ход требует небольшого базового количества голода (настраивается). Некоторые рецепты также добавляют дополнительную стоимость голода сверх базовой, и эту стоимость оплачивает только ручной точильный камень. Лошадь Гриндстоун игнорирует это. JEI показывает строку «Голод» в рецептах, в которых он есть, так что вы можете сразу определить дорогие рецепты.

## Примечания

- Для пакетной обработки можно вставить несколько элементов.
- Работает с теми же рецептами, что и точильный камень для лошадей, если рецепт не помечен только для лошадей.
- Доступные рецепты измельчения можно найти в JEI/EMI.
