  # <Color id="light_purple">Магия</Color>

  <ItemImage id="arsmagicalegacy:spell_book" scale="2"/>

  Магические уровни из каждого магического мода в наборе, а не только Ars Magica. Ритуалы, обряды, отвары, работа души и зачарование — все имеет значение, так что выбирайте ту школу, которая вам нравится.
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

> <Color id="yellow">Примечание</Color>: Ars Magica: Наследие имеет свой собственный уровень магии и очки навыков для частей заклинаний. Это отдельная система. Каждый раз, когда оно поднимается на уровень выше, Магическое дерево также получает XP.
