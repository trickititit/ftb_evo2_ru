# <a name="energy-meter-interface" />Интерфейс счетчика энергии

На этой странице описаны все настройки, которые можно настроить для <ItemLink id="meter" components="rarity=epic"/>. Чтобы получить доступ к настройкам, поместите блок и взаимодействуйте с ним, чтобы открыть его пользовательский интерфейс. Интерфейс разделен на два раздела. Левая панель является глобальной и всегда видна. Правая панель зависит от выбранной в данный момент вкладки на верхней панели вкладок.

<br/>

## <a name="global-panel" />Глобальная панель

<FloatingImage src="assets/global_panel.png" align="right"/>

Глобальная панель расположена в левой части интерфейса. Он остается видимым даже при переключении вкладок. Эта панель содержит текущие значения измерений и статус. Он также включает в себя сетку ввода-вывода и возможность сброса общего количества измеренной энергии.

### <a name="measurements" />Измерения

Измерения включают текущий расход и общее количество измеренной энергии. Общее значение можно сбросить с помощью кнопки под сеткой ввода/вывода.

Значения текущих измерений обновляются один раз за настроенный интервал. Единственное исключение — достижение [допуск](interface.md#tolerance). См. этот раздел для получения дополнительной информации.

### <a name="status" />Статус

Статус обновляется всякий раз, когда изменяется параметр или состояние, которые могут на него повлиять. Сюда входит текущий расход, изменения в соседних блоках, а также изменения в конфигурациях ввода и вывода.

Статус **Отключен** указывает на то, что необходимые настройки для выбранного в данный момент режима не настроены. В большинстве случаев это означает, что вход или выход отсутствуют. **Неактивный** означает, что все настройки настроены правильно и счетчик энергии ожидает передачи энергии. Окончательный статус зависит от выбранного [режим передачи](interface.md#transferring) и указывает, что
<ItemLink id="meter" components="rarity=epic"/> в настоящее время обрабатывает запросы и работает правильно. **Заблокировано** означает, что
Функция [Управление](interface.md#function) Redstone в настоящее время блокирует передачу.

### <a name="i/o-grid" />Сетка ввода/вывода

Этот раздел используется для настройки сторон блока. Каждую сторону можно настроить как вход, выход или отключить для запросов энергии. Лицевую сторону настроить невозможно, поскольку она зарезервирована для отображения расхода на блоке. Стороны можно настроить с помощью щелчка левой или правой кнопкой мыши. Также можно мгновенно сбросить одну сторону или сбросить все стороны одновременно. Более подробную информацию можно найти во всплывающих подсказках соответствующих кнопок.

Возможность настройки стороны как входа или выхода зависит от выбранного [режим передачи](interface.md#transferring).

## <a name="configuration-panel" />Панель конфигурации

<FloatingImage src="assets/configuration_tab.png" align="right"/>

Панель конфигурации, доступная при выборе вкладки **Конфигурация**, позволяет настраивать параметры, связанные с режимами и измерениями.

### <a name="modes" />Режимы

В этом разделе с помощью переключателей можно выбирать различные режимы. Одновременно можно выбрать только одну опцию для каждого раздела.

#### <a name="transferring" />Перенос

Режим передачи определяет, как запросы энергии, поступающие на стороны, сконфигурированные как входы, пересылаются на выходные стороны. Режим по умолчанию — **Разделить**.

В режиме **Разделить** входящие запросы распределяются равномерно по всем выходам. Сначала система пытается разделить энергию поровну на количество выходов, чтобы каждый выход получил одинаковую долю. Если один из выходов принимает меньше расчетной доли, оставшаяся энергия перераспределяется на другие выходы. Поэтому энергия не обязана делиться строго поровну. Если выходов больше, чем доступной энергии, остаток отправляется на случайно выбранный выход.

Режим **Передача** — это особый режим. Он изменяет поведение сетки ввода-вывода и позволяет назначать приоритеты выходам. Выходы с более высоким приоритетом всегда получают передаваемую энергию первыми. Затем энергия передается в порядке убывания приоритета. Выходы с более низким приоритетом получают энергию только в том случае, если выходы с более высоким приоритетом не могут принять всю доступную энергию.

Режим **Потребление** используется для тестирования настроек. Вместо пересылки энергии этот режим безвозвратно удаляет всю поступающую энергию. Этот режим также изменяет поведение сетки ввода-вывода, запрещая выходы. Обычно он используется для измерения количества энергии, которое может поступить через все входы, особенно когда нормальный поток ограничивается выходами.

#### <a name="measuring" />Измерение

Режим измерения определяет, как рассчитывается расход за интервал. Режим по умолчанию — **Мгновенный**.

В режиме **Мгновенный** учитываются только сохраненные значения, измеренные в течение текущего интервала. Предыдущие интервалы игнорируются. Этот режим полезен, когда требуются точные значения.

Режим **Сглаженный** изменяет расчет, включая предыдущий интервал. Вместо использования только измерений текущего интервала скорость потока корректируется с использованием предыдущего интервала. Это обеспечивает более плавный график и снижает влияние внезапных скачков скорости потока. Этот режим полезен для наблюдения за средним поведением в течение более длительных периодов времени.

<br/>

### <a name="settings" />Настройки

Параметры в этом разделе представляют собой текстовые поля, которые изменяют определенные настройки <ItemLink id="meter" components="rarity=epic"/>, влияющие на измерения и поток энергии. Эти текстовые поля также имеют несколько особых свойств.

По умолчанию поля всегда отображают текущее значение. При редактировании значения отображаемое значение не обновляется. Вместо этого кнопка с правой стороны становится активной. Нажатие этой кнопки применяет введенное значение. Альтернативно измененное значение можно подтвердить с помощью клавиши **Enter**.

Текстовые поля также поддерживают несколько интеллектуальных функций, включая проверку ввода. Если ввод недействителен, например, из-за неверного числа, поле становится красным, и значение невозможно применить.

Все текстовые поля также поддерживают математические выражения. Поддерживаемые операции включают сложение, вычитание, умножение, деление, возведение в степень и скобки. Если обнаружено математическое выражение, в текстовом поле отображается небольшое всплывающее окно с вычисленным результатом, который можно применить. Поскольку все настраиваемые значения являются целыми числами, результаты математических выражений автоматически округляются до ближайшего целого числа. Недопустимые символы также предотвращаются при вводе математических выражений. Например, закрывающую скобку можно вставить только в том случае, если существует соответствующая открывающая скобка.

Числа можно сокращать с помощью суффиксов единиц: `k` (тысяча), `M` (миллион), `G` (миллиард), `T`, `P` и `E`, каждый из которых в 1000 раз больше предыдущего. Суффикс не чувствителен к регистру и должен следовать непосредственно за числом, например `100k`, `1.5M` или `2k * 3`. Большие значения, такие как лимит передачи, также отображаются в этой краткой форме, когда это возможно.

#### <a name="limit" />Лимит

Лимит передачи определяет, сколько энергии <ItemLink id="meter" components="rarity=epic"/> может передать за тик _(1 секунда = 20 тактов)_. Все входные данные накапливаются и ограничиваются этим значением. Таким образом, ограничение применяется глобально, а не для каждого входа. Любая энергия, превышающая лимит, возвращается отправителю.

#### <a name="interval" />Интервал

Интервал определяет время в тактах _(1 секунда = 20 тиков)_, после которого выполняется новое измерение. В течение интервала все соответствующие значения записываются и сохраняются. По окончании интервала эти значения используются для расчета текущего расхода и обновления общей измеренной энергии.

По умолчанию это значение составляет **5 тиков (0,25 секунды)**. Это значение по умолчанию можно изменить в конфигурации мода. Из соображений производительности значение никогда не может быть ниже 5 тиков.

Относительно небольшое значение по умолчанию позволяет <ItemLink id="meter" components="rarity=epic"/> быстро реагировать на изменения. Это особенно полезно, когда вы хотите немедленно увидеть, когда подача энергии прерывается. Однако это может привести к тому, что значения будут колебаться, что приведет к изменению среднего значения. Увеличение интервала может сгладить колебания, но приведет к менее частым обновлениям расхода.

#### <a name="tolerance" />Допуск

Допуск является нишевым вариантом и требуется редко. Это дополнительная опция, которая уточняет интервал и определяет, сколько тиков _(1 секунда = 20 тиков)_ уровень энергии может оставаться нулевым до сброса интервала.

Во время интервала подача энергии может временно прекратиться. В этом случае скорость потока устанавливается на ноль только по истечении всего интервала. Это затрудняет обнаружение прерываний при использовании длинных интервалов. По умолчанию допуск составляет **5 тиков (0,25 секунды)**. Это означает, что допустимо, чтобы поток энергии через <ItemLink id="meter" components="rarity=epic"/> был равен нулю в течение 5 тиков. Если на 6-м тике энергия не передается, интервал заканчивается раньше. Поэтому эта опция полезна только в том случае, если интервал превышает 5 тиков.

Значение допуска является инклюзивным. При значении 5 допустимо отсутствие энергии в течение 5 тиков. Только 6-й тик сбрасывает интервал.

Эта опция полезна для очень длинных интервалов, когда вы хотите заранее обнаружить потерю потока энергии. Например, если интервал установлен на **400 тиков (20 секунд)**, может быть полезно установить допуск на **50 тиков (2,5 секунды)**. Это позволит вам обнаружить перебои в подаче электроэнергии уже через 2,5 секунды вместо 20 секунд. Это особенно полезно при использовании **Сглаженного** [режим измерения](interface.md#measuring), поскольку в этом режиме расходу требуется больше времени, чтобы достичь нуля.

## <a name="graph-panel" />Панель графика

<FloatingImage src="assets/graph_tab.png" align="right"/>

Доступ к панели графиков можно получить, выбрав вкладку **График**. Он отображает графическое представление последних 10 интервалов.

Данные отображаются в простой системе координат. **ось X** представляет самые последние интервалы, а **ось y** показывает средний поток энергии каждого интервала. Максимальное значение оси Y всегда на **10 % выше** значения наибольшего интервала, чтобы облегчить интерпретацию точек графика.

Если существуют данные менее чем для 10 интервалов, отображаются только доступные интервалы. Во время текущего интервала отображается только горизонтальная линия. Точка графика появится, как только станет доступен результат интервала.

Для **Аналоговый** и **Порог** [функции красного камня](interface.md#function) нижняя и верхняя границы показаны пунктирными линиями, поэтому вы можете видеть, где находится скорость потока относительно них. Верхняя граница отображается зеленым цветом, а нижняя – серым. Вместо этого граница над видимым диапазоном отображается в виде маркера со значением на верхнем крае.

Чтобы упростить проверку данных, график можно приостановить с помощью небольшого значка паузы в правом верхнем углу. Пауза только останавливает графическое представление графика. Внутри продолжают обрабатываться новые данные, и счетчик энергии продолжает работать. Метка внутри графика указывает на то, что он приостановлен, а значок превращается в значок воспроизведения. Нажмите ее еще раз, чтобы возобновить график.

## <a name="redstone-panel" />Панель редстоуна

<FloatingImage src="assets/redstone_tab.png" align="right"/>

Доступ к панели красного камня можно получить, выбрав вкладку **Redstone**. Это позволяет <ItemLink id="meter" components="rarity=epic"/> излучать сигнал красного камня в зависимости от текущей скорости потока или включаться и выключаться с помощью сигнала красного камня.

Редстоун по умолчанию отключен. Выберите функцию, отличную от **Выкл.**, чтобы активировать ее. Пока он активен, красная пыль соединяется со всеми сторонами <ItemLink id="meter" components="rarity=epic"/>, кроме передней части дисплея. Сигнал слабой мощности, поэтому не проходит через сплошные блоки рядом с <ItemLink id="meter" components="rarity=epic"/>. Сигнал обновляется один раз в [интервал](interface.md#interval).

### <a name="function" />Функция

Функция определяет, как скорость потока преобразуется в сигнал. Одновременно может быть активна только одна функция.

- **Выкл.** не излучает сигнал, и красная пыль не подключается.
- **Аналоговый** сопоставляет скорость потока между нижней и верхней границей с уровнем сигнала от 0 до 15. Скорость потока, равная или ниже нижней границы, выдает 0; расход, равный или превышающий верхнюю границу, выбрасывает 15.
- **Порог** выдает полный сигнал, как только скорость потока достигает верхней границы **(Вкл. при)**, и сохраняет его до тех пор, пока скорость потока не упадет ниже нижней границы **(Выкл. ниже)**. Зазор между обеими границами предотвращает мерцание сигнала, когда скорость потока колеблется вокруг одного значения. Если обе границы равны, сигнал переключается на это значение.
- **Управление** считывает сигнал красного камня со всех сторон, кроме передней, и блокирует всю передачу энергии при включении. Рычаги, кнопки, пыль из красного камня, блоки из красного камня и блоки с мощным питанием рядом со счётчиком <ItemLink id="meter" components="rarity=epic"/>. Эта функция сама по себе не излучает сигнал, поэтому красная пыль, ведущая в <ItemLink id="meter" components="rarity=epic"/>, не может поддерживать свое питание. Во время блокировки на [статус](interface.md#status) отображается **Заблокировано**, а скорость потока падает до нуля со следующим интервалом. [поведение](interface.md#behavior) определяет, блокирует ли сигнал передачу или постепенно масштабирует ее.

### <a name="scale" />Масштаб

Масштаб применяется только к функции **Аналоговый**:

- **Линейный**: каждый уровень сигнала охватывает один и тот же диапазон скоростей потока. Чтобы получить один уровень сигнала за шаг, установите нижнюю границу на `0`, а верхнюю границу на `15 x step`. Например, нижняя граница `0` и верхняя граница `150k` добавляют один уровень сигнала на 10 тыс. FE/t.
- **Логарифмический**: каждый уровень сигнала умножает расход на один и тот же коэффициент. Это полезно для охвата большого диапазона скоростей потока. Например, нижняя граница `1` и верхняя граница `1000T` _(10^15)_ добавляют один уровень сигнала на коэффициент 10. Нижняя граница `0` рассматривается как `1`.

### <a name="behavior" />Поведение

Для функции **Управление** раздел масштаба заменяется разделом поведения:

- **Переключатель**: любой сигнал блокирует передачу.
- **Ограничение потока**: уровень сигнала уменьшает [лимит передачи](interface.md#limit) на 15 ступеней, поэтому схема красного камня может регулировать количество передаваемой энергии. Сигнал 15 блокирует передачу. Ограничение потока также действует в режиме **Потребление**.

При лимите передачи 15 тыс. FE/t эффективный лимит выглядит следующим образом:

| Сигнал | Нормальный | Перевернутый |
|--------|---------|----------|
| 0      | 15k     | 0        |
| 5      | 10k     | 5k       |
| 15     | 0       | 15k      |

Для ограничения потока необходимо задать лимит передачи. Без него сигнал может блокировать передачу только при полной силе _ (или при нуле при инвертировании) _, а в противном случае передача не ограничена.

Например, компаратор, считывающий хранилище энергии за <ItemLink id="meter" components="rarity=epic"/>, замедляет передачу по мере заполнения хранилища и останавливает его, когда хранилище заполнено.

### <a name="settings" />Настройки

**Нижняя** и **верхняя** границы — это скорости потока в FE/t. Оба используются функциями совместно, поэтому при переключении функции значения сохраняются. Если нижняя граница не ниже верхней границы, функция **Аналог** действует как пороговое значение на верхней границе.

Границы не применяются к функции **Управление**.

**Инвертировать** переворачивает сигнал. Инвертированный **Аналоговый** сигнал выдает 15 на нижней границе и 0 на верхней границе. Инвертированный сигнал **Порог** горит, когда скорость потока низкая. Вместо этого инвертированная функция **Управление** блокирует передачу при отключении питания. При использовании **Ограничение потока** инвертированный сигнал обеспечивает ограничение передачи, а не уменьшает его. Поскольку <ItemLink id="meter" components="rarity=epic"/> без какого-либо расхода имеет расход, равный нулю, инвертирование сигнала можно использовать в качестве аварийного сигнала при прекращении подачи энергии.

### <a name="output" />Выход

В разделе вывода отображается мощность сигнала, излучаемого в данный момент, а для функции **Аналоговый** — насколько должен измениться расход, чтобы сигнал изменился на один уровень. Для функции **Управление** он заменяется разделом ввода, в котором отображается самый сильный полученный сигнал и разрешена или заблокирована передача в данный момент. При использовании **ограничения потока** вместо этого отображается эффективный предел передачи. Он отображается красным, если лимит передачи не установлен.
