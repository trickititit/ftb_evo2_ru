# Компьютер

Компьютер — это размещаемый блок, который предоставляет вам терминальный интерфейс для наблюдения и управления вашими логистическими сетями. Добавьте его в свою базу, используйте **Вторичное взаимодействие (по умолчанию: щелчок правой кнопкой мыши)**, и вы получите полноценную панель мониторинга: перечислите каждую сеть, посмотрите живую пропускную способность для каждого активного канала, перейдите непосредственно к конфигурации любого узла и массово переключите видимость узла.

![Диспетчер сети — состояние ожидания без подключения сети](images/network-manager-idle.png)

## Открытие компьютера

Используйте **Вторичное взаимодействие** на размещенном блоке компьютера, чтобы открыть экран **Диспетчер сети**. Если где-то в вашем инвентаре есть [Гаечный ключ](../wrench/index.md), компьютер временно перемещает один гаечный ключ в слот внутреннего отсека для дисковода в правом верхнем углу. Ключ невозможно вытащить из этого слота. Закрытие экрана автоматически возвращает обновленный ключ в ваш инвентарь.

Слот отсека для диска доступен только на странице сетевого каталога. Если вы переключитесь на представление «Монитор ввода-вывода» или «Таблица узлов», вы не сможете прикоснуться к гнезду для гаечного ключа, пока не отступите.

## Три подсистемы

Выбрав сеть из каталога, вы можете перейти к любой из двух подсистем. Описаны в отдельных главах:

- [Сетевой каталог](network-directory.md) — список сетей слева; поиск, закрепление, монтирование сети.
- [Монитор ввода-вывода](io-monitor.md) — пропускная способность в реальном времени для всех девяти каналов, а также какие именно предметы и жидкости движутся.
- [Таблица узлов](node-table.md) — каждый узел в смонтированной сети, сгруппированный по метке, с действиями для каждой строки.

См. [Сохранение и загрузка сетей](save-load.md), чтобы создать резервную копию конфигураций узла или загрузить их в ключ компьютера.

Если установлен CC: Tweaked, см. [КомпьютерКрафт](../integrations/computercraft.md), чтобы прочитать те же данные из сценариев Lua и мониторов.

Пока сеть не подключена, на правой панели отображается сообщение **Сеть не подключена**. Выберите один из каталога, и кнопки подсистемы разблокируются.

## Помеченные сети

Каждая сетевая запись в каталоге имеет небольшой значок **звездочки** справа. Используйте **Основное взаимодействие (по умолчанию: щелчок левой кнопкой мыши)**, чтобы закрепить эту сеть в верхней части списка. Закрепленные (помеченные) сети сортируются в первую очередь; далее следуют незакрепленные сети. Звездное состояние хранится в самом блоке «Компьютер» — оно сохраняется между сеансами и для каждого компьютера (два компьютера могут иметь разные избранные).

На каждом компьютере указан список сетей, к которым текущий игрок может получить доступ, в соответствии с настройкой сервера **Доступ к узлу**. См. [Доступ к сети](../index.md#network-access).
