# Таблица узлов

Представление для каждого узла смонтированной сети. Перечисляет каждый узел, принадлежащий сети, с указанием типа блока, местоположения и пары кнопок действий для перехода к нему в мире или удаленного редактирования его конфигурации.

Откройте его с кнопок подсистемы после монтирования сети. Чтобы вернуться, нажмите **EXIT** в левом верхнем углу.

## Стол

![Таблица узлов, показывающая четыре строки — Сундук, Бочка, Бочка, Сундук.](../computer/images/node-table.png)

В каждой строке показан один узел сети. Столбцы:

- **Устройство** — значок элемента для блока, к которому прикреплен узел, а также отображаемое имя этого блока (`Chest`, `Barrel`, `Furnace` и т. д.).
- **Местоположение** — координаты размера и блока. Измерение использует короткий код (`OVR` = Overworld, `NTH` = Пустота, `END` = Конец, пользовательские затемнения показывают собственный короткий код). Координаты следуют как `X, Y, Z`.
- **Действия** — две кнопки со значками справа от каждой строки.

![Детализация строки с одним узлом — Сундук в обычном мире на 29,-60,70 с кнопками подсветки и настроек.](../computer/images/node-row.png)

### Действия со строками

- **Выделение** (значок лампы) — используйте **Основное взаимодействие (по умолчанию: щелчок левой кнопкой мыши)**, чтобы включить светящийся контур узла в мире, чтобы его было легче найти. Контур остается включенным до тех пор, пока вы снова не воспользуетесь основным взаимодействием с лампой или не закроете экран компьютера.
- **Настройки** (значок шестеренки/терминала) — открывает экран полной конфигурации узла **удаленно**, где бы вы ни находились. Вам не нужно стоять рядом с узлом, чтобы редактировать его каналы или фильтры.

Используйте **Вернуться к таблице** после редактирования, чтобы восстановить подключенную сеть, положение прокрутки, расширенные группы, выбор и ожидающий текст метки. Открытие фильтра с этими настройками сохраняет тот же путь возврата.

## Группировка меток

Узлы с меткой группируются под этой меткой. Имя метки отображается в виде строки заголовка; используйте «Основное взаимодействие» в заголовке, чтобы свернуть всю группу в одну строку, а затем используйте его снова, чтобы развернуть. Узлы без меток отображаются в нижней части списка.

Состояние свертывания запоминается для сеанса — разверните группы, над которыми вы работаете, и сверните остальные, чтобы таблица оставалась читабельной в больших сетях.

Метки устанавливаются из поля [Заголовок → Установить метку](../nodes/header.md) на каждом узле или копируются автоматически при вставке с помощью [Гаечный ключ → Копировать/Вставить](../wrench/copy-paste.md).

## Выбор и групповые метки

Используйте флажки строк для выбора узлов. Флажок группы выбирает каждого участника; его частичное состояние означает, что выбраны только некоторые члены. **Тот же блок** выбирает узлы, прикрепленные к тому же типу блока, что и выбранный источник.

Введите метку и примените ее к выделению. Существующая метка содержит текущие настройки группы. Для нового ярлыка выберите источник настроек из вашего выбора. Общие макеты обновлений требуют физических обновлений из вашего инвентаря или связанного хранилища; недостающие припасы оставляют выбранные узлы без изменений. Примените пустую метку, чтобы разгруппировать их.

## Массовое отображение/скрытие

Две кнопки в правом верхнем углу таблицы узлов:

- **SHOW** — включает **видимость рендеринга** для каждого узла в подключенной сети. Все узлы рисуются в мире с полной непрозрачностью, независимо от того, держите ли вы в руках гаечный ключ или нет.
- **HIDE** — **отключает** видимость рендеринга для каждого узла в подключенной сети. Узлы рисуются только тогда, когда вы держите гаечный ключ, с уменьшенной непрозрачностью.

Чтобы узнать, что делает переключатель «Видимый» для каждого узла, см. [Заголовок → Видимый](../nodes/header.md).

## Пагинация

Количество видимых строк адаптируется к доступной высоте. Для местоположений используется отдельная строка, чтобы обеспечить читаемость полных координат. Прокрутите колесо мыши, чтобы просмотреть более крупные сети.

## Полезно знать

- Таблица узлов активна. Добавленные, удаленные или переименованные узлы появляются/исчезают без необходимости повторного открытия компьютера.
- Удаленные настройки открывают полный экран узлов, который вы видите в мире — фильтры, обновления, каждый канал. Изменения фиксируются так же, как если бы вы стояли перед узлом.
- Контуры выделения отображаются на стороне клиента и видны только вам, а не другим игрокам на сервере.
