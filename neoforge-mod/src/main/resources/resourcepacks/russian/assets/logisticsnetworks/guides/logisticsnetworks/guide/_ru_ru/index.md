# Logistics Сети

Logistics Networks — это мод передачи предметов, жидкости и энергии, построенный на узлах и каналах.

## Основные понятия

- **Узлы** – это небольшие объекты, размещенные в блоках с возможностью хранения (сундуки, резервуары, машины и т. д.).
- **Сети** – это логические группы узлов, которые совместно используют ресурсы.
- **Каналы** определяют, что делает узел — каждый узел имеет 9 настраиваемых каналов.
- **Фильтры** точно контролируют, что передается

## Первые шаги

1. Создайте [Гаечный ключ](wrench/index.md) и [Logistics Узел](nodes/index.md).
2. Разместите узел на любом блоке с инвентарем, резервуаром или хранилищем энергии.
3. Используйте **Вторичное взаимодействие (по умолчанию: щелкните правой кнопкой мыши)** на узле с помощью гаечного ключа, чтобы открыть конфигурацию.
4. Назначьте узел сети (или создайте новый)
5. Настройка каналов для импорта или экспорта ресурсов

## Понимание переноса

Сами по себе узлы ничего не передают. Узел просто прилипает к блоку. Настоящая работа происходит внутри **каналов** узла.

У каждого канала есть направление:

- **Отправитель** — забирает ресурсы **из** блока, к которому привязан узел.
- **Получатель** — помещает ресурсы **в** блок, к которому привязан узел.

Сеть — это группа узлов, которые могут общаться друг с другом. Каждый узел имеет 9 слотов каналов, пронумерованных от 1 до 9. **Отправитель общается с Получателем только по одному и тому же номеру канала** во всей сети.

Таким образом, отправитель на канале 3 отправляет только получателям на канале 3. Отправитель на канале 7 отправляет только получателям на канале 7. Номера каналов действуют как помеченные каналы — совпадающие номера соединяются, а разные номера — нет.

### Простой пример

1. Поместите узел на сундук, полный железа. Установите для **канала 1** значение **Отправитель — элементы**.
2. Поместите узел в печь. Установите для **канала 1** значение **Получатель — Товары**.
3. Поместите оба узла в одну сеть.

Оба узла используют канал 1, поэтому они связаны. Отправитель достает железо из сундука. Сеть передает его Получателю на канале 1. Получатель отправляет утюг в печь.

Вот и вся передача: Отправитель извлекает, Получатель на том же канале вставляет, и сеть соединяет их.

## Доступ к сети

Владельцы серверов выбирают, кто может использовать узлы другого игрока, с помощью настройки **Доступ к узлу**. По умолчанию используется **Команды**, что соответствует членству в командах FTB, если этот мод доступен. **Все** позволяет каждому игроку, а **Союзники** — товарищам по команде и союзным командам FTB. Без команд FTB Teams остается только владельцем, и Allies не добавляет дополнительных игроков.
