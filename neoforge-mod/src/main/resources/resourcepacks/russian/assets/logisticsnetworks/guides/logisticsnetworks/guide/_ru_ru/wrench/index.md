# Гаечный ключ

Гаечный ключ — это инструмент, который вы используете для всего, что связано с узлами: открытия их конфигурации, их удаления, копирования настроек между узлами и одновременного массового размещения множества узлов.

Он имеет три режима. Удерживайте **R**, удерживая гаечный ключ, чтобы открыть колесо режимов, наведите курсор на режим и отпустите его, чтобы выбрать его. Отпустите кнопку в центре или нажмите Escape для отмены. Переназначьте колесико в меню управления Minecraft.

Вы также можете переключать режимы с помощью **Кнопки-модификатора 1 (по умолчанию: Shift) + Колесо мыши**. HUD рядом с панелью быстрого доступа показывает активный режим: синий для гаечного ключа, зеленый для копирования/вставки и золотой для массового размещения.

## Обзор режимов

- [Гаечный ключ](wrench-mode.md) — значение по умолчанию. Открывайте или удаляйте узлы, размещайте узлы и связывайте сети AE2 или Refined Storage.
- [Копировать/Вставить](copy-paste.md) — клонировать всю настройку узла — каналы, фильтры, обновления, метку — на другой узел. Поддерживает массовую вставку в каждый подключенный узел одного и того же типа блока.
- [Массовое размещение](mass-placement.md) — выберите область с двумя углами, выберите тип целевого блока, затем разместите настроенные узлы на соответствующих блоках с помощью **Основного взаимодействия (по умолчанию: щелчок левой кнопкой мыши)**.

## Настройки гаечного ключа

Нажмите **G**, удерживая гаечный ключ, чтобы открыть настройки. Каждый гаечный ключ имеет свои собственные настройки, поэтому один гаечный ключ может отображать всю базу, а другой фокусируется на одной сети.

**Цвета** позволяет изменить цвет корпуса и экрана ключа.

**Линии потока** управляют линиями, рисующимися между отправителями и получателями, пока вы удерживаете гаечный ключ.

- *Просто*:
  - включить или выключить линии
  - показывать только некоторые типы ресурсов (предметы, жидкости, энергия)
  - показывать только некоторые каналы (1–9)
  - ограничить линии одной ближайшей сетью
  - выберите, будут ли узлы, находящиеся за пределами экрана или слишком далеко для рендеринга, получать линии. Это достигает каждого узла, который отслеживает ваша игра, примерно 64 блока.
- *Дополнительно*:
  - выберите стиль линии: **Маршрутизированная** (сгруппированные прямоугольные пути) или **Прямая** (прямая линия от каждого отправителя к каждому получателю).
  - установить толщину, скорость, непрозрачность и импульсы
  - выбрать, будут ли линии отображаться сквозь блоки
  - установить цвет каждого типа ресурса

Нажмите **Применить**, чтобы сохранить. **Сброс** восстанавливает настройки по умолчанию для вкладки, на которой вы находитесь.

## Краткий справочник

| Режим | Вторичное взаимодействие (по умолчанию: щелчок правой кнопкой мыши) | Ключ-модификатор 1 + Вторичное взаимодействие | Ключ-модификатор 2 (по умолчанию: Ctrl) + Вторичное взаимодействие |
|------|-------------|---------------------|--------------------|
| Ключ | Открыть конфигурацию узла | Удалить узел, разместить узел или переключить ссылку на хранилище | — |
| Копировать/Вставить | Копировать узел → буфер обмена (или открыть редактор буфера обмена в прямом эфире) | Вставить буфер обмена → узел | Вставить в каждый подключенный узел того же типа блока |
| Массовое размещение | Установите углы области (или откройте меню размещения в прямом эфире) | Открыть меню размещения | — |

## Использование этикеток с помощью гаечного ключа

Этикетки очень хорошо сочетаются с гаечным ключом. Когда вы вставляете настройку в узел, метка источника также копируется, поэтому вставленный узел немедленно присоединяется к этой группе меток и остается синхронизированным со всеми остальными узлами, разделяющими эту метку.

Типичный рабочий процесс:

1. Настройте один узел так, как вам хочется.
2. Дайте ему ярлык (см. [Заголовок → Установить метку](../nodes/header.md)).
3. Скопируйте его конфигурацию в буфер обмена.
4. Вставьте (или разместите массово) на все остальные узлы, которые должны использовать эту настройку.

Каждый узел теперь имеет одну и ту же метку. Последующие изменения любого из них автоматически распространяются на всю группу. Вам не нужно повторно копировать-вставлять при настройке.
