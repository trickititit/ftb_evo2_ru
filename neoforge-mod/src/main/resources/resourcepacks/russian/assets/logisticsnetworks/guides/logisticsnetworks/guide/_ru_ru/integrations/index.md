# Интеграция модов

Logistics Networks работает вместе с несколькими другими модами. На этих страницах описаны те, которые меняют ваш стиль игры — каждая интеграция включается только после установки этого мода.

- [КомпьютерКрафт](computercraft.md) — чтение сетей, узлов, графа узлов и телеметрии ввода-вывода в реальном времени из скриптов и мониторов Lua.
- [Строительные гаджеты](building-gadgets.md) — перемещайте узлы с помощью гаджета «Вырезать и вставить» и копируйте их настройки с помощью «Копировать и вставить» и шаблоны.
