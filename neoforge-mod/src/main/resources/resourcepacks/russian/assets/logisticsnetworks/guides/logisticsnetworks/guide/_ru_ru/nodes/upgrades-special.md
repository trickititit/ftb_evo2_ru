# Специальные обновления

Специальные обновления не меняют ограничения пропускной способности узла. Пространственное обновление открывает возможность межпространственной передачи, а обновление сети открывает доступ к сети хранения данных; оба могут быть объединены с помощью [повышение производительности](upgrades-performance.md) в одном узле. Элементы обновления «Химический химикат» и «Источник» сохранены для будущей совместимости, но в настоящее время неактивны.

Слоты для улучшений находятся на панели [Фильтры и обновления](filters-upgrades.md). Дубликаты отклоняются, но разные активные обновления могут использовать эти четыре слота совместно.

## Размерное обновление

**Открывает возможность передачи данных между измерениями.** Без этого обновления узел может общаться только с узлами в том же измерении. Установите Пространственное обновление, и узел сможет перемещаться между узлами в других измерениях — между Верхним миром и Незером, Краем и Верхним миром или любым модифицированным измерением.

**Он должен быть установлен на обоих концах.** И на узле отправителя, и на узле получателя необходимо установить Размерное обновление. Установить его только с одной стороны недостаточно — движок проверяет оба узла, прежде чем разрешить перескок между измерениями.

Внутри одного и того же измерения апгрейд не делает ничего лишнего — обычные переносы работают и без него.

## Химическая модернизация Меканизма

Этот элемент сохранен для будущей совместимости. В настоящее время он не разблокирует химические каналы или передачи. Его рецепт появляется только при загрузке Меканизма.

## Обновление сети

**Открывает прямой доступ к сети хранения.** Узел с этим обновлением на Applied Energistics 2 или усовершенствованном интерфейсе хранения перемещает предметы и жидкости напрямую через всю подключенную сеть хранения, как описано в [Настройки канала](channel-settings.md). Без него интерфейс представляет собой просто еще один инвентарь, и узел видит только то, что хранится в самом интерфейсе.

Каждому узлу интерфейса, который должен подключиться к сети, требуется собственное обновление сети. Нодам на других блоках это не нужно.

Есть два рецепта, по одному на каждый мод хранилища. Каждый из них появляется только при загрузке этого мода.
