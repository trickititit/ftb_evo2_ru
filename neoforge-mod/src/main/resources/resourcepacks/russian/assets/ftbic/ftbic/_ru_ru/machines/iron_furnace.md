# <Color id="gold">Железная печь</Color>

<Column alignItems="center" fullWidth={true}>
  <ItemImage id="iron_furnace" scale="2" />

  Неэлектрическая печь, которая выжимает **12 предметов на уголь**, на 50 % больше, чем ваниль.
</Column>

<ItemImage id="minecraft:air" scale="0.25"/>

<RecipeFor id="iron_furnace" />

<ItemImage id="minecraft:air" scale="0.25"/>
***

* Использует любое ванильное топливо для печи.
* Существует специально для того, чтобы преодолеть разрыв с электричеством. Как только у вас появится <ItemLink id="powered_furnace" />, железная печь устареет. Ему не нужна ни сила, ни прогресс.
* Невозможно принять обновления.

Перетащите элемент из **JEI** во входной или топливный слот, чтобы установить постоянный фильтр призраков. Призраки не создают предметы. При пустом курсоре щелкните правой кнопкой мыши пустой призрак или щелкните правой кнопкой мыши Shift правой кнопкой мыши по заполненному заблокированному слоту, чтобы удалить фильтр. Сопоставление включает данные об элементах, и бункеры также подчиняются этим фильтрам.
