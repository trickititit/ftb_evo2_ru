# Солнечная панель из сплава Eclipse

Солнечная панель, генерирующая Forge энергию.

Максимальная скорость FE по умолчанию: **11520**

**Условия по умолчанию:**

- Больше солнечных панелей рядом с другими, больше будет производиться
- Высокий/низкий уровень Y увеличит множитель, средний уровень Y уменьшит множитель.
