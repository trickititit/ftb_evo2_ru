# Продвинутая палочка времени

Обновленная версия <ItemLink id="justdirethings:time_wand"/> с большей емкостью и режимами для настройки действия по щелчку.

Режимы по умолчанию:

_можно изменить/отключить в конфигурации!_

- Нормальный:

Работайте так же, как и обычный <ItemLink id="justdirethings:time_wand"/>

- Скорость 2x:

Нажмите действие, работайте 2x -> 4> 16> 64> 256.

- Скорость 4x:

Нажмите действие, работайте 4x -> 16> 256.

- Максимальная скорость:

Нажмите действие, чтобы оно срабатывало 8 раз, поэтому оно будет каждый раз 256 раз.
