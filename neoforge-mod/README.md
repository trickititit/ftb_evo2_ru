# FTB Evolution 2 — мод русской локализации

**Версия мода 1.0.0**, тексты выпуска r4. Только для **FTB Evolution 2 1.4.0** (pack 135 / version 100566), **Minecraft 26.1.2**, **NeoForge 26.1.2.121**, **FTB Quests / FTB Library 26.1.2.9**, **Stellaris 2.0.8**. Это неофициальное дополнение. Сама сборка и JAR других модов не распространяются.

## Установка

1. Закройте Minecraft и штатно остановите выделенный сервер.
2. Если установлен старый комплект r1–r4 с `Install.cmd`, выключите его ресурс-пак и выполните `Rollback.cmd` из того комплекта. Сохраните свои правки отдельно: откат защищает изменённые файлы и восстанавливает состояние до первой установки русификатора.
3. Положите **основной JAR мода** в `mods` клиента. Для полной локализации на выделенном сервере положите тот же JAR в его `mods`.
4. Запустите игру и выберите **Русский (Россия)**. Ресурсы мода подключаются автоматически; отдельно включать ресурс-пак и запускать установщик не нужно.

Для одиночной игры достаточно JAR на клиенте. В сетевой игре для предметов и руководств мод нужен каждому игроку. Подстановка FTB Quests работает на клиенте при получении исходных английских таблиц; серверный JAR нужен для вики Stellaris. Рекомендуется одинаковая версия мода на клиенте и сервере.

Если сохранить старую установку, её переводы могут иметь приоритет: конфигурационные русские таблицы FTB Quests и отдельные ресурс-паки мод не удаляет и не заменяет. Поэтому для перехода на мод рекомендуется откат старого комплекта.

## Что входит

- 4178 записей FTB Quests, включая описания, заголовки и подписи наград.
- 45 437 языковых записей: 43 973 добавленных/отличающихся от английского значений; остальные — технические обозначения и имена собственные.
- 894 файла Patchouli, 748 страниц GuideME (включая 75 страниц Nodeworks) и 197 страниц Oracle Index.
- 135 буквальных языковых ключей Modonomicon и 61 страница вики Stellaris.

Ресурсы Chisel исключены. Основная часть перевода выполнена автоматически с выборочными ручными правками; сплошная литературная редактура не проводилась. Сохраняются имена API, команды, идентификаторы и примеры кода. Не переведены текст внутри изображений, внешние сайты, встроенная справка ComputerCraft и жёстко заданные строки без механизма локализации.

## Как работает мод

Мод содержит клиентские ресурсы и данные вики Stellaris. Mixin перехватывает только чтение текста FTB Quests; таблицы, определения заданий, прогресс и сохранения не изменяются. Подстановка выполняется для `ru_ru` и только когда SHA-256 исходной английской записи совпадает с ожидаемым для сборки 1.4.0. Русский текст, уже заданный в конфигурации или присланный сервером, сохраняет приоритет.

Вики Stellaris синхронизирует текст с сервера без выбора языка страницы для каждого игрока. На сервере с модом её страницы будут русскими у всех игроков. Остальные языковые ресурсы выбираются по языку клиента.

Мод проверяет `config/metadata.json` и откажется загружаться в другой сборке или версии. Наличие этой проверки не означает совместимость с изменёнными наборами модов.

## Удаление

Закройте игру/остановите сервер и удалите только JAR этого мода из `mods`, затем запустите снова. Мод не создаёт переводов в `config`, `kubejs`, мирах или настройках игроков, поэтому отдельный откат для него не требуется. Файлы прежнего установочного комплекта удаляются его собственным `Rollback.cmd`.

## Сборка из исходников

Требуется JDK 25. Gradle Wrapper скачивает Gradle и зависимости при первом запуске.

```powershell
.\gradlew.bat build
```

Если репозиторий FTB недоступен, используйте JAR установленных FTB Quests и FTB Library из своей сборки:

```powershell
.\gradlew.bat build '-PmodpackDir=D:\Prism\instances\FTB Evolution 2\minecraft'
```

Путь должен указывать на папку с `mods`. Зависимости используются только для компиляции и не включаются в итоговый JAR. Результат — `build/libs`; файл `-sources.jar` предназначен для разработчиков, а основной JAR — для установки и загрузки на CurseForge.

Сведения о фактически выполненных проверках находятся в публикационном комплекте и отчёте. Успешная серверная проверка не заменяет визуальную проверку клиентских интерфейсов.

Для повторения проверки всех записей на реальных классах FTB Quests после сборки можно использовать Python 3 и установленную серверную сборку с библиотеками Minecraft:

```powershell
python .\tools\check_overlay.py --pack-dir 'D:\Servers\Evolution2'
```

Скрипт не запускает игру и не меняет файлы сборки: результаты компиляции и временные данные сохраняются в `build/overlay-checks`. Для отдельных библиотек клиента есть параметр `--libraries-dir`, для выбора JDK — `--java-home`.
