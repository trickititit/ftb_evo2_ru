# Публикация на CurseForge

Создайте проект **Minecraft → Mods**, загрузчик **NeoForge**, версия игры **26.1.2**. Загрузите основной файл `ftb-evolution-2-russian-neoforge-26.1.2-1.0.0.jar`; не загружайте вместо него `-sources.jar`, исходный ZIP проекта или старый Client.zip.

Название: **FTB Evolution 2 - Russian Localization**.

Краткое описание (Summary):

> Unofficial Russian quest, book and guide localization for FTB Evolution 2 1.4.0.

Основное английское описание подготовлено в `CURSEFORGE-DESCRIPTION.md`. В качестве исходников укажите репозиторий проекта, а в Issue tracker — его раздел Issues. Категория: локализация/Utility, если соответствующий вариант доступен в форме; не отмечайте несвязанные категории.

Укажите необходимые зависимости FTB Quests, FTB Library и Stellaris. Эти моды уже входят в FTB Evolution 2. Сам модпак не входит в JAR и должен быть установлен отдельно. Совместимость ограничена версиями, указанными в README.

Для первого выпуска рекомендуется **Beta**, пока не проверено отображение в игровом клиенте. CurseForge может не показывать Beta пользователям, которые разрешили только Release. После визуальной проверки можно выпустить Release с точным описанием выполненных проверок.

Для аватара подготовлена квадратная обложка `logo.png`. Дополнительно приложите настоящие скриншоты переведённых заданий и руководств из игры; обложка не доказывает корректность отображения.
